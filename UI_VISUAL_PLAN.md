# План визуальной переработки интерфейсов

Документ является постоянной очередью интерфейсной миграции. Каждый этап завершается визуальным эталоном, автотестами, patch-версией и публикацией в GitHub.

## Художественный контракт

- Эталон — стартовый экран и рюкзак: резное дерево, пергамент, латунь, ткань и неброские растительные детали.
- Все runtime-элементы собираются из независимых PNG или nine-patch; соседние ячейки атласа не должны попадать в спрайт.
- Базовый viewport `1152×648`, сетка отступов `8 px`, минимальная интерактивная область `48×48 px`.
- Фокус подсвечивает изображение изнутри, а не рисует внешнюю жёлтую рамку.
- Длинные переводы, мышь, клавиатура, геймпад, тачскрин и reduced motion входят в обязательный контракт.

## Критерий завершения экрана

1. Геометрия и hit-зоны берутся из одного источника.
2. Все иконки центрируются в safe-area без искажения пропорций.
3. Ни один декоративный элемент не масштабируется целиком там, где требуется nine-patch.
4. Экран остаётся читаемым во всех локалях и режимах управления.
5. Есть screenshot-эталон и тесты поведения/геометрии.

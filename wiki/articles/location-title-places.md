## Условия подключения

`map.*` — только успешное прибытие на существующую карту. `atlas.*` — будущая авторская граница; они не превращаются в игровые карты от регистрации в этом документе. Инейный хребет следует IDEA-171. Ферма — отдельная будущая область внутри overworld, не новое название всей домашней деревни.

`home` плюс `ivy/copper/root/salt/camp` дают шесть поселений. Нынешние market/garden/river/workyard/orchard — компактные районы home. Бродячий Двор имеет один place ID на всех стоянках; смена стоянки не сбрасывает первое посещение.

Три срезки получают понятные игроку локализованные названия путей после утверждения владельцем UNDERWAY; I/II/III — текущие названия атласа, не обязательная финальная экранная нумерация. Восемь комнат эха имеют одно полное вступление в комплекс; внутренние комнаты — компактные авторские имена без спойлера решения. Сны показывают название только при входе в написанный эпизод, не при каждом сне героя. Глубины требуют профиля каждого нового самостоятельного крыла, когда оно действительно определено.

Новые сюжетные карманы/NPC-локации регистрируются владельцем истории: approved display key, родитель, граница, статус наличия. Малое помещение наследует компактное семейство родителя, основная новая область получает отдельную строку. Не выводить ID как fallback и не импортировать непроверенные карты из открытых PR. Общие системы `global` не имеют географического титра. Реестр расширяется отдельным принятым изменением, без автоматической генерации мира.

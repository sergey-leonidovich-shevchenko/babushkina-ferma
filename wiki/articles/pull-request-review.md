# Как проходит ревью PR

С 23 октября готовую реализацию передаём через GitHub Pull Request: Developer Agent публикует ветку и передаёт Tech Lead Agent ссылку, точный SHA и результаты проверок.

Tech Lead Agent проверяет корректность, читаемость, структуру, форматирование, стоимость выполнения и качество тестов. Замечания оставляет у конкретных строк PR; сводку получает Team Lead Agent, который возвращает Developer Agent доработки по приоритету. После исправлений проверяется новый SHA.

До одобрения текущего SHA, прохождения обязательных проверок и решения Team Lead Agent слияние в `main` не выполняется. Карточка остаётся «В работе» с URL PR; только готовность к ревью не делает зависимые задачи готовыми. Ветки для ревью публикуются сразу; старый прямой пакетный push `main` не используется для обхода PR.

Для согласованной задачи музыку и звуки заказываем Music Agent. В задании описываем сцену/событие, характер, длительность, зацикливание, начало и конец, варианты, формат и ограничения громкости. Полученные файлы подключаются и проверяются в игре. Музыкальный заказ сам по себе не расширяет приоритет первой локации.

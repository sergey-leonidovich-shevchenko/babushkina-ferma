# IDEA-310 — Лаборатория признаков — узнать эликсир, не выпивая его

**Предложение proposed, игровая реализация не выполнена.** Группа «Предметы и снаряжение». [Свой эпик](#/development/epics/idea-310--IDEA-310) · [Обзор](creative-review-2026-10-30.md).

## Суть, польза и участники

Определить учебный эликсир по результатам трёх безопасных вымышленных проб. Сравнивать признаки, исключать варианты и честно оставлять «неизвестно», пока данных недостаточно.

Даёт алхимии удовольствие открытия и ясной дедукции. Помогает почувствовать себя исследователем, а не перебирать готовые рецепты или пить случайное зелье ради скрытого свойства.

**Проектный взрослый NPC:** Дейра, взрослая хранительница учебных эликсиров (`deyra_samples`). Пока не добавлен в runtime-реестр.

## Пошаговый игровой сценарий

1. Дейра замечает стёртую этикетку на учебной склянке и даёт таблицу шести возможных профилей.
2. Выбрать пробу: рунический свет, глиняное кольцо или бумажная звезда. Результат — понятное да/нет с символом и текстом.
3. Отметить совместимые профили; таблица объясняет исключённые варианты по конкретному результату.
4. При одном кандидате предложить название; при нескольких сохранить неопределённость и сделать оставшуюся пробу.
5. Подписать образец и услышать маленькую историю владельца. При желании взять другой учебный случай; награда за повтор одинаковой склянки не выдаётся.

## Правила, числа и исключения

Гипотеза шесть профилей/до 3 проб, первый случай 3–5 минут. Четверо из пяти будущих читателей объясняют, почему оставшийся вариант единственный, трое хотят второй случай без предметной награды. Если выбирают только по подсветке, дать сначала ручное исключение с доступной проверкой, не скрывать таблицу. **Числа и будущая малая проба — гипотезы, результатов участников ещё нет.**

- Шесть вымышленных профилей: Фонарь 110, Роса 010, Тихая смола 101, Искра 100, Туман 011, Песнь 001. Биты соответствуют трём названным руническим пробам; совпадений полного вектора нет. Это данные игры, не руководство с реальными веществами.
- Одна проба возвращает фиксированное значение своего профиля. Порядок не влияет; повтор показывает прежний receipt без нового расхода. Шума/скрытой ложной реакции в первом выпуске нет.
- Достоверная подпись доступна, только если множество совместимых профилей размера 1. Не надо выполнять третью пробу, если две уже дают уникальный ответ. При 2+ кандидатах можно записать гипотезу, но не выдать её за новый открытый рецепт.
- Образцы принадлежат учебному стенду, не Inventory potion. Выпить, продать, выбросить или залить в настоящую боевую склянку нельзя. Связь с реальными неопознанными экземплярами — отдельный поздний PACK-этап.
- В MVP три случая, каждый с постоянным case_id/profile_id и одной личной репликой. Не выбирать новое скрытое свойство после load ради рыбалки на хороший результат.
- Одна revision принимает пробу/таблицу/подпись. Два клика во время анимации не показывают противоречащие реакции; закрытие UI сохраняет принятые наблюдения, не завершает классификацию автоматически.
- Неверная гипотеза ничего не взрывает/не дамажит. Дейра объясняет противоречащий признак. Награда — знание/одно сюжетное наблюдение без XP за каждое нажатие и без бесплатной продукции.
- Save: case_version, case_id, profile_id из принятого authored набора, test_mask/results, label/confidence и receipt. Значения валидируются до мутации; старый/неизвестный профиль предлагает безопасный архивный просмотр, не превращается в случайный ItemData.

**Состояния:** `unknown → testing/ambiguous → identified/tentative → recorded`.

**Один record:** `lab_version, case_id, authored_profile_id, tested_mask[0..7], results[3], proposed_label, certainty_enum, case_receipt`. Принятый будущий адаптер IDEA-232-04 поверх AdventurePolish/quest_memory владеет эффектами/receipt. Его пока нет как готового общего формата. Renderer/проекция/UI не сохраняют независимые копии. Версия/revision/context проверяются перед единичным commit, отказ не мутирует живую игру; старый слот без record означает «не начато».

## Интерфейс, обучение, графика и звук

Матрица 6×3 со словами/значками, результаты зафиксированы рядом с пробой. Подсветка поясняет правило, не нажимает ответ за игрока. Длинные названия и клавиатурный фокус остаются видимыми; звук реакции короткий, его отсутствие не скрывает исход.

Первое действие показывается без необратимого расхода, с доступным повтором. Принимать шесть локалей, клавиатуру/геймпад/touch, масштаб UI и reduced motion в настоящем HUD; браузерная Wiki390px не принимает игровой ввод. Мягкая живописная сцена A и VART-008 остаются эталоном. Мебель/аппараты имеют только влево, вправо и вниз к игроку, с сеткой/пропорциями SPRITE_STANDARD; вращение детали UI не новый ракурс мебели. Макеты отдельно от runtime. Аудио сейчас ТЗ: будущий исполнитель после одобрения передаёт Music Agent событие, длительность, начало/конец, loop/варианты/формат/громкость и проверяет полученные файлы в игре. Звуки не заказываются ради неутверждённого внедрения.

## Риски и способы проверки

Риск незаметно переопределить настоящие свойства зелий и заменить исследование автоматическим решателем. Dataset учебного case отделён от боевых recipes; renderer выводит known observations и не открывает hidden profile в подсказке/tooltip. До 6×3 сравнений по изменению данных, не тяжёлый runtime solver каждый кадр.

Проверить успех/отказ/повтор/отмену, смену карты/слота, новую игру, focus и missing resource. Все данные ограничены ID/enum/числами/короткими массивами, без Node/Resource/Texture/Callable. После отказа загрузки прежний save и живая игра побайтно/поведенчески прежние. Общий GameClock/pause остаётся единственным владельцем времени мира; локальная учебная последовательность не меняет его. Настоящая награда/улов использует принятую общую вместимость и pending receipt, без удаления при полном рюкзаке/обязательного E. Планы PACK/171/спутников не выдаются за существующие реализации. До/после сверить HP, энергию, предметы, основные quests, NPC-расписания и старые слоты. Native стоимость принимается собственным адресным профилем; headless счётчик не доказывает FPS/GPU.

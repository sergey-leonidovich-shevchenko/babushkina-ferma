# Wiki «Лунная долина»

Отдельный сайт игры на Vue 3, TypeScript и Vite. Содержит персонажей и их анимации, миссии, здания и станки, все рецепты и предметы, растения, локации, таланты, рыбалку и инструкции. Сведения о контенте берутся из действующих игровых каталогов; руководство и управление становятся читаемыми HTML-статьями.

## Открыть сайт

На macOS дважды нажмите **«Лунная долина Wiki.app»** рядом с **«Бабушкина ферма.app»** в папке игры. У wiki отдельный значок с книгой и луной. Каждый запуск:

1. Находит Node.js, в том числе runtime настольного Codex. Если его нет, скачивает официальный Node 24.19.0 в `wiki/.runtime` и сверяет SHA-256 с контрольными суммами Node.js.
2. При первом запуске устанавливает зависимости по закреплённому `pnpm-lock.yaml`. Глобальные npm-пакеты не устанавливаются.
3. Импортирует ресурсы Godot, выгружает актуальные каталоги и позы, проверяет TypeScript и собирает HTML.
4. Публикует готовую сборку в `wiki/dist`, запускает локальный сервер и открывает браузер. Обычный адрес — `http://127.0.0.1:4174/`; если порт занят, выбирается следующий свободный.

Первому запуску может понадобиться интернет для Node или зависимостей. После их установки обычная пересборка работает локально. Godot берётся из той же установки, что использует игра. Wiki не открывает слоты игрока и не меняет инвентарь, миссии или сохранения.

На Windows: установите Node.js 22.12+ и Godot для игры, затем откройте `Запустить Wiki.cmd` внутри этой папки. Можно указать движок через `WIKI_GODOT_BIN` или `FARM_GODOT_BIN`.

## Пользоваться справочником

- Поиск сверху работает по именам, описаниям, ингредиентам, наградам, требованиям, действиям и внутренним ID. `Ё` и `е` считаются одинаковыми. `Cmd/Ctrl+K` переводит фокус в поиск; Enter сразу открывает результаты.
- Разделы и фильтры помогают выбрать жителей, врагов, сюжет, побочные поручения или определённый тип ремесла. Адрес содержит выбранную страницу и запрос: работают закладки и возврат браузером.
- На странице персонажа нажмите **«Смотреть анимации»**. Доступны его реальные действия и ракурсы, пауза, скорость, ползунок и отдельные кадры. Направления без нарисованных кадров недоступны. У героя есть инструменты и оружие; у босса — все атаки стадий; у призывов — появления, движение, атака и поражение.
- На странице станка можно выбрать уровни 1–3, увидеть цены, материалы и три ракурса с видимой рабочей стороной, включая строительную кучу.
- На странице рецепта задайте число партий: ингредиенты, выход и побочные продукты пересчитываются. Это базовый рецепт; эффекты талантов конкретного героя не применяются.
- Ссылки соединяют предметы с рецептами, миссии с заказчиками, растения с урожаем, а районы — с дорогами и жителями. Статьи можно распечатать штатной печатью браузера.

## Разработка

Используется обычный стек [Vue 3 с TypeScript](https://vuejs.org/guide/typescript/overview) и [Vite](https://vite.dev/guide/). Отдельная библиотека компонентов не требуется. Шрифт Alice хранится локально с OFL-лицензией; оригинальные ресурсы остаются в папке игры.

```sh
cd wiki
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm start
```

Для команд нужен Node.js 22.12+ и pnpm 11.19.0. Лаунчер самостоятельно находит pnpm в runtime либо запускает закреплённую версию через стандартный npm. `WIKI_NODE_BIN` выбирает Node, `WIKI_GODOT_BIN` — Godot, `WIKI_PNPM_BIN` — pnpm. `WIKI_NO_OPEN=1` отключает открытие браузера при тестовом запуске. Остановить принадлежащий проекту сервер: `node scripts/launch.mjs --stop`.

`pnpm dev` обновляет Vue/CSS на лету. После изменения игровых данных заново выполните `pnpm prepare:content` или перезапустите приложение wiki. `pnpm build` пересоздаёт весь каталог перед TypeScript-проверкой и сборкой.

`scripts/export_catalog.gd` запускается явно, несмотря на `.gdignore`: Godot не сканирует сайт и `node_modules` как игровые ресурсы. Модули `export_actors`, `export_content`, `export_world` используют настоящие каталоги и библиотеки поз. Все PNG, JSON, шрифт, зависимости и сборка создаются в игнорируемых папках; игровые исходники не копируются и не редактируются.

Предметные статьи, результаты рецептов и растения получают окончательный пакет `VisualAssetSystem.item_visual`: рисунок и реальная модуляция игрового материала. Это сохраняет цвета трав, порошков, руды и деталей, а выбранный новый PNG имеет тот же приоритет, что в игре. Ревизия всего художественного каталога находится отдельно в `docs/concepts/visual-polish-2026-10-13/v1`.

Кадр содержит URI изображения, исходный прямоугольник, опору стоп, масштаб и зеркальность. Имена PNG основаны на SHA-256 содержимого. Просмотрщик использует общую рамку всех фаз и отменяет устаревшую загрузку при быстром выборе ракурса. Таймеры отменяются при закрытии окна; скрытая вкладка приостанавливает анимацию.

Проверка каталога останавливает сборку при пустой статье, неполном реестре, повреждённой ссылке, отсутствующем материале, пустой анимации, неверном FPS или кадре за пределами текстуры. Любая ошибка Godot блокирует выгрузку. HTML руководств создаётся с отключённым исходным HTML. Прежний каталог и сборка заменяются только после успеха; неудачный запуск сохраняет последнюю рабочую версию.

Сервер слушает только `127.0.0.1`, отдаёт только `dist`, проверяет символические ссылки и выход из папки. Повторный запуск проверяет принадлежность сервера этому проекту и использует его снова. Чужие процессы не останавливаются. Двойной щелчок защищён блокировкой сборки; остановка требует локального токена из `wiki/.cache/server.json`.

Проверки: TypeScript, production-сборка и `tests/*.test.mjs` для полноты/спрайтов, поиска/количеств, HTTP/портов, сохранения рабочей версии и bundle macOS. CI запускает тот же `pnpm check`. До commit и push дополнительно обязательны игровые `tools/check_architecture.sh` и `./run_tests.sh`.

SVG значка — `public/wiki-icon.svg`, версия для Finder — `../Лунная долина Wiki.app/Contents/Resources/AppIcon.icns`. Для изменения значка: `node scripts/build-icon.mjs`; требуется `sharp` (в рабочем runtime Codex он уже есть). Контейнер ICNS включает PNG 128, 256, 512 и 1024 без зависимости от внешнего iconutil.
## Производственные цепочки

Страницы рецептов используют общий игровой граф. Можно выбрать число партий, задать собственные запасы и варианты промежуточной обработки. Выводятся внешнее сырьё, реальные источники и порядок полных партий с переиспользованием остатков и побочных продуктов. Топливо и строительство отдельно; навыки браузерного примера базовые. Сложные циклы требуют внешний исходный предмет, превышение бюджета не выдаётся за полный план.

`pnpm check` дополнительно сравнивает TypeScript с 333 свежими эталонами Godot. Эталоны сохраняются в отдельном `public/generated/production-cases.json` и не загружаются приложением. Граф находится в основном каталоге и формируется из реестров игры. Публичные материалы и сгенерированная сборка остаются производными файлами.

# Авторские исходники графики

Новые мастер-исходники, послойные файлы и промежуточные экспорты хранятся здесь по семействам. `.gdignore` закрывает всё дерево от импорта Godot. Концепты и художественные сравнения остаются в `docs/`, снимки разработки — в `assets/generated/`.

В `assets/game/` переносится только подготовленное игровое семейство. Исторические исходники сохраняют прежние пути, закрытые отдельными барьерами. Действующие листы актёров с именем `master` являются исключением по назначению: игра реально использует их; переименовывать или скрывать их по одному имени нельзя.

Правила и воспроизведение: [разделение исходников и runtime](../../docs/ASSET_PIPELINE.md).

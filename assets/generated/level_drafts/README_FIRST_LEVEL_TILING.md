# Нарезка стартовой локации (первый этап)

`first_level_fairytale_master_v1.png` нарезается на базовую сетку 32×32 для создания базового пайплайна.

## Быстрый запуск

```bash
python3 scripts/split_fairytale_level_tiles.py
```

## Что получится

- `assets/generated/level_drafts/first_level_tiles_32/raw/`
  Полный сеточный экспорт всех тайлов (пока это 1536 штук из 48×32).
- `assets/generated/level_drafts/first_level_tiles_32/grid/`
  Те же тайлы, но с компактным индексом уникальных изображений.
- `assets/generated/level_drafts/first_level_tiles_32/first_level_fairytale_master_v1_grid.png`
  Мастер с нарисованной 32×32 сеткой (для проверки реза).
- `assets/generated/level_drafts/first_level_tiles_32/first_level_grid_index.json`
  Карта тайлов с координатами (`row`/`col` → `unique id`) для быстрой сборки уровня.

Каталог содержит `.gdignore`: отдельные PNG нужны для ручной правки и анализа,
но не импортируются Godot. В рантайме используется единый мастер-атлас, поэтому
тысячи мелких файлов не замедляют запуск редактора и сборку игры.

## Важно для следующего шага

- Сейчас это «чистая» нарезка: мы ещё не делали переиспользуемый набор травы/воды/дорог,
  чтобы не потерять художественную цельность.
- Следующим шагом удобнее сделать вручную 3–6 авторских тайл-сетов:
  - основа земли/травы,
  - дорога и грунтовая тропа,
  - вода + берега,
  - заборы и задвижки,
  - декор (камни/пни/кусты),
  - крупные объекты в отдельных спрайтах.
- После этого добавить отдельный слой коллизий (пустые тайлы с проходимостью `true/false` + спрайты).

## Игровое подключение

Первая игровая версия уже использует мастер как атлас. `FirstLevelArtSystem` берёт
центральные 48×24 ячейки по 32×32 и выводит их как 48×24 тайла по 50×50.
Получается ровный мир 2400×1200 без изменения пропорций исходного изображения.
Верхние и нижние четыре ряда остаются в исходнике как художественный запас лесной рамки.

Для быстрого просмотра используйте:

```bash
tools/Godot.app/Contents/MacOS/Godot --path . -- --first-level-preview
```

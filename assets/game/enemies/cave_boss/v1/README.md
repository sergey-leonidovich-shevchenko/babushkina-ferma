# Спрайты боя с Хранителем

Созданы встроенным `image_gen` 11 октября 2026 года. Исходные мастер-файлы сохранены в каталоге генератора; PNG здесь — их копии без изменения пикселей. [Точные промпты и пути оригиналов](generation.json).

Шесть прозрачных атласов содержат **89 отдельных кадров**:

| Атлас | Строки |
|---|---|
| [guardian.png](guardian.png) | тяжёлый удар, взмах, рывок, призыв — по 4 кадра |
| [skeleton.png](skeleton.png) | появление из земли, ходьба, меч, распад — по 4 кадра |
| [zombie.png](zombie.png) | выход из грязи, ходьба, бросок мухи, смерть — по 4 кадра |
| [vampire.png](vampire.png) | мышь → вампир, ходьба, взмах плаща, вампир → мышь — по 4 кадра |
| [effects.png](effects.png) | земля (4), кристаллы (5), обвал (4), лунный огонь (4) |
| [flyers.png](flyers.png) | муха и летучая мышь — по 4 кадра полёта |

[frames.json](frames.json) задаёт точные области и опоры для независимой нарезки. Реальные размеры мастер-файлов не кратны сетке: области округляются один раз при подготовке метаданных. Во второй строке эффектов генератор нарисовал пять кристаллов; они сохранены как пять настоящих кадров. Игра использует области исходной текстуры и кэширует шесть ресурсов, без анализа пикселей в кадре.

Персонажи нарисованы с одного ракурса RPG-камеры. Это отдельные игровые элементы, которые можно повторно использовать в других комнатах, а не фон локации. Контактные тени, зоны опасности и свечение рисуются игровым renderer независимо от PNG.

У четвёртого кадра призыва хранителя область в `frames.json` сужена слева на 16 пикселей: исключён край свечения соседнего кадра. Горизонтальная опора компенсирует нарезку, поэтому тело не смещается; исходный PNG не менялся.

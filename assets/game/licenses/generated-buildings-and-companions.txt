Все семь атласов созданы специально для «Бабушкиной фермы: Тайна Лунной долины» встроенным генератором изображений OpenAI 2 августа 2026 года. Сторонние персонажи, логотипы и защищённые игровые образы в запросах не использовались.

Исходные запросы задавали оригинальный уютный fantasy pixel-art, прозрачный игровой фон после chroma-key обработки и фиксированную сетку: 4×2 для восьми зданий, 3×1 для трёх напарников, 3×1 для жителей и 2×1 для зверей.

Новые запросы задавали режим создания (`mode: generate`) и три фиксированные сетки без текста: 5×3 для семейств «хищное растение / орк / скелет / проклятый рыцарь / кристальный хранитель» с рангами «обычный / ветеран / элита»; 3×3 для «ядовитый плющ / колючий цветок / кактус» в тех же рангах; 4×4 для героя с колонками уровней 1–5, 6–10, 11–15, 16–20 и строками направлений вниз, влево, вправо, вверх. Итоговые PNG очищены от chroma-key, получили прозрачный фон и приведены к целочисленному размеру ячеек атласа.

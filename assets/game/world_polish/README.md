# Village polish atlas

`village_polish_atlas.png` — единый прозрачный атлас 5×4 с ячейкой 128×128 для интерьеров, деревенских событий, оружия и эффектов.

Создан 5 августа 2026 года встроенным генератором изображений по проектному запросу: «32-bit fantasy farm RPG, exact 5x4 atlas; bed, shop counter, guild desk, forge/anvil, chest; market stall, festival feast, night-trader wagon, raid barricade, rune gate; forest sword, crystal sword, bow, arrow, magic orb; dust, leaves, splash, stone shards, wood chips; flat #FF00FF chroma, no text/shadow». Фон удалён локальным chroma-key инструментом; сетка нормализована до 640×512 RGBA.

Лицензирование: сгенерированный специально для проекта оригинальный ассет; внешние изображения не использованы.

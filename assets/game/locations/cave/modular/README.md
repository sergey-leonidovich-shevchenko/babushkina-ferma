# Модульный набор Кристальных пещер

Набор из 20 самостоятельных PNG нарезан из [согласованного концепта](../../../../../docs/concepts/cave-location-2026-10/v1/sprite-kit.png). Стены, вход, добываемые жилы и мелкий декор остаются отдельными объектами; изображение всей карты в игре не используется.

Каждый PNG имеет нижнюю центральную опору, прозрачное поле и native-разрешение вдвое больше runtime-размера. Размеры, опоры и основания находятся в [центральном каталоге](../../../../../scripts/systems/world_visual_profile_system.gd), выбор текстур — в [CaveAssetSystem](../../../../../scripts/systems/cave_asset_system.gd). Координаты исходной нарезки и размеры сохранены в [sprite-source.json](sprite-source.json).

Пол создан отдельно встроенным image_gen.imagegen по виду утверждённой пещеры; [финальный промпт](floor-prompt.json) сохранён рядом. Стены и жилы не запечены в покрытие пола. Исходный альфа-канал спрайтов сохранён; свечение при сборке сцены рисуется отдельно.

Проверки набора находятся в [CaveAssetsSuite](../../../../../tests/suites/cave_assets_suite.gd). Старые ресурсы остаются доступны остальным локациям.

# Оригинальные сгенерированные атласы

Файлы в этой папке созданы встроенным режимом ImageGen специально для проекта, затем однотонный фон удалён локально с мягкой альфой. Они не происходят из стороннего бесплатного набора.

## Сезоны

`seasonal_environment_atlas.png`: строгая сетка 4×2. Столбцы — весна, лето, осень, зима. Верхний ряд — одно узнаваемое плодовое дерево в четырёх состояниях; нижний — цветы и побеги, трава и ягоды, листья с грибами и орехами, сугроб с морозной травой. Исходный запрос требовал уютный hand-painted pixel-art-inspired стиль, одинаковый масштаб и основание дерева, нейтральный свет, изолированные объекты без текста на сплошном фоне `#ff00ff`.

## Лунное затмение

`eclipse_event_atlas.png`: строгая сетка 4×2. Верхний ряд — портал, лунный цветок, кристальная жила и алтарь; нижний — лунный призрак, страж затмения, спектральный белый олень и сундук. Исходный запрос требовал уютный магический, но не хоррорный стиль, читаемые силуэты, локальное бирюзово-фиолетовое свечение, изолированные объекты без текста на сплошном фоне `#ff00ff`.

Оба исходника имели размер 1254×1254. Обработка выполнена `remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 10 --opaque-threshold 90 --edge-contract 1 --force`; тест проверяет размер, прозрачные углы и наличие видимых пикселей.

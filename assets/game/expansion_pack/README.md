# Атлас расширения фермы

`expansion_atlas.png` — прозрачный атлас 5×4 с ячейкой 128×128 для животноводства, музея, календаря, фоторежима, мебели, головоломок и рейдового капитана.

Исходник создан встроенным ImageGen в режиме генерации нового изображения по промпту: «32-bit pixel-art farming RPG production atlas, exact 5×4 grid; chicken, cow, sheep, feeding trough, product sparkle; museum pedestal, encyclopedia, trophy, birthday calendar cake, camera; table, chair, rug, potted fern, wardrobe; rune, pressure plate, lever, treasure statue, orc raid captain banner; flat magenta background, no text, no shadows». Фон удалён штатным скриптом `remove_chroma_key.py`, затем изображение нормализовано до 640×512.

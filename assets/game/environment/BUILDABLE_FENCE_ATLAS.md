# Атлас строящихся заборов

`buildable_fence_atlas_v1.png` — строгий RGBA-атлас 8×5 с ячейкой 64×64.

Строки: дубовый, белый садовый, каменный, кованый и живой забор. Столбцы:
одиночная опора, горизонталь, вертикаль, угол, Т-соединение, перекрёсток,
закрытая и открытая калитка.

Исходный художественный лист создан встроенной генерацией изображений 14 августа
2026 года для проекта «Бабушкина ферма» в 32-битном сказочном пиксельном стиле.
Финальный атлас воспроизводимо нормализуется командой:

```bash
python3 tools/build_fence_atlas.py
```

Игровая геометрия использует базовую ячейку 24×24. Обычный сегмент занимает одну
ячейку, а калитка — две соседние ячейки; рисунок может выходить выше footprint,
но его опора и коллизия всегда остаются кратны общей сетке.

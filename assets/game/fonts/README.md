# Шрифты проекта

`Alice-Regular.ttf` используется для титульного экрана и системных меню. Alice разработан Ксенией Ерулевич и Cyreal, содержит кириллицу и распространяется по SIL Open Font License 1.1. Оригинальный файл и метаданные семейства взяты из официального репозитория [Google Fonts](https://github.com/google/fonts/tree/main/ofl/alice); полный текст лицензии сохранён рядом в `Alice-OFL.txt`.

`menu_font.tres` добавляет системный fallback из `ui_font.tres`, поэтому китайский перевод и отсутствующие специальные символы продолжают отображаться.

На macOS китайские символы берутся из `Hiragino Sans GB`, на Linux — из `Noto Sans CJK SC`. Для локального Linux-окружения нужен пакет `fonts-noto-cjk`; GitHub Actions устанавливает его вместе с зависимостями проверок. Основной шрифт выбирается из `Arial`, `Noto Sans` и `DejaVu Sans` в указанном порядке.

# Небесный круг

Три прозрачных слоя 512×512: `sky.png` вращается; `landscape.png` и `frame.png` неподвижны. Солнце и луна с фазами рисуются отдельно. Только эти текстуры используют линейную фильтрацию; фильтрация мира не меняется.

Оригиналы, точный запрос и проверка: [макет v2](../../../../docs/concepts/day-night-dial-2026-10/v2/README.md). Подготовка: `res://tools/assets/authoring/prepare_celestial_dial.gd`; очистка служебного края и уменьшение Lanczos сохраняют исходники нетронутыми.

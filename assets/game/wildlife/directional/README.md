# Направленные животные

Пять атласов созданы для проекта через OpenAI ImageGen на основе локальных исходных образов оленя, лисы, кабана, летучей мыши и лугового листохвоста. Режим: генерация нового production-атласа с референсом идентичности.

Общий контракт промпта: 32-битная пиксельная стилистика фермерской RPG; восемь строк направлений `south → southwest → west → northwest → north → northeast → east → southeast`; шесть столбцов `idle → movement A → movement passing → movement B → hurt → death`; один полный объект в ячейке; плоский magenta chroma-фон; без текста, теней и окружения. После генерации фон удалён, а 48 кадров каждого семейства нормализованы в сетку 6×8 с ячейкой 128×128 и единым нижним якорем.

Файлы предназначены для использования только внутри «Бабушкиной фермы» и её производных сборок.

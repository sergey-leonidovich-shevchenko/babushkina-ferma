# Проверки часов погоды

`review.gd` запускает реальные физические сценарии из `weather_visual_clock_suite.gd`: пауза, окна, фокус, редактор, reduced motion, reference, вход/выход дома, загрузка, чужой владелец, недопустимые данные и ограниченная память. Отдельный OS userdata подтверждается до запуска; обычные слоты не используются.

`collect` разрешён только на удалённом Linux X11 и требует чистый exact head в `VWEATHER_EXPECTED_HEAD`. Настоящие Git-экспорты базы и кандидата сохраняют production без renderer-оверлеев. Единственный QA-наблюдатель переключается между полным кадром и вызовом того же `AtmosphereRenderer` на том же canvas. Это не новый production-проход. Календарные дни дают естественные ясную погоду, дождь, снег и грозу. Системное ожидание разделяет кадры ручной паузы, физический callback проверяет отсутствие продвижения, затем штатный delta возобновляет движение. Есть два нативных окна 1152×648 и 1280×720 с принятым zoom 120%, настоящие независимые SubViewport и переход дома. PNG читаются из RenderingServer, не создаются PIL.

`verify --output <каталог> --expected-head <SHA>` проверяет полный список источников/артефактов, Git blobs, реальные argv/журналы/userdata, размеры, callbacks, сохранения и RGBA. Масштаб проверяется по локации:120% на overworld,100% в cottage_interior. Новый кадр, который только объявляет замороженную фазу, но продолжает двигаться в PNG, не проходит. Baseline должен воспроизводить прежнее движение во время паузы; его отказ не заменяется синтетическим рисунком.

`archive --archive <оригинальный ZIP> --expected-head <SHA>` вызывает тот же semantic verifier через новую временную папку. ZIP остаётся неизменным; дубликаты, symlink и выход из каталога отвергаются. `--check-current-candidate` требует чистого Git и сверяет текущие runtime/QA с captured head, разрешая только SemVer-метаданные. Четырнадцать `test_reader` портят копии настоящего диагностического CI1; его исходный статус failure не меняется.

Десять часов в профильном тесте — 36 000 разрешённых модельных шагов часов, **не** длительный аппаратный игровой прогон. X11/llvmpipe CPU не принимает GPU/FPS/Retina или VMAP-003. Подробности и фактические результаты принадлежат [плану VWEATHER-001](../../../../docs/reports/visual-overhaul/vweather-001/PLAN.md). Полный нативный результат пока не получен.

# Реестр технического долга

Последний полный аудит выполнен 12 августа 2026. На момент релизного прохода открытого P0/P1-техдолга нет: все обнаруженные нарушения либо устранены, либо превращены в автоматически проверяемый архитектурный контракт.

## Текущее состояние

| Область | Фактическое состояние | Автоматический критерий |
|---|---|---|
| Композиция | `game.gd` — одна исполняемая строка; жизненный цикл вынесен в `game_core.gd` | core ≤ 1200 строк, context ≤ 350, renderer ≤ 700 |
| Системы | 74 узких модуля правил, состояния и представления | запрет `draw_*` в фасаде и документация каждого метода |
| Состояние | `GameState` и типизированные player/inventory/world/storage/forge/contracts-модели | round-trip save v2, миграция v1 и backup-тесты |
| Контент | data-driven каталоги с единым владельцем | `ContentRegistry.validate()` при старте и в тестах |
| Ввод | централизованный `InputMap`, удержание, геймпад и тач | input suites и проверка обязательных actions |
| Навигация | единый `NavigationSystem` с кодом причины блокировки | мосты, вода, интерьеры, динамические объекты и F11-overlay |
| Анимации | backlog движущихся типов пуст | 8 направлений и 3–5 кадров через `AnimationAssetRegistry` |
| Тесты | 26 suites, 214 сценариев, 2673 утверждения | `./run_tests.sh`: только 0 failed считается успехом |
| Репозиторий | генераторы переносимы, производные тайлы и концепты игнорируются | тест отсутствия `/Users/` и правила `.gitignore` |

## Закрыто этим проходом

- Устранён абсолютный пользовательский путь из `generate_level_concepts.py`; оба генератора работают из корня любого клона.
- 6148 воспроизводимых файлов нарезки (около 28 МБ) и промежуточные концепты исключены из Git. Master первой локации, документация и контрольный игровой снимок остаются версионируемыми.
- `game_core.gd` добавлен в обязательный архитектурный лимит, поэтому тонкий `game.gd` больше не позволяет скрыть рост композиционного слоя.
- Реестр обновлён с устаревших 5 suites и 581 проверки до фактических 26 suites и 2673 утверждений.
- Полностью закрыт прежний backlog направленной анимации: герой, NPC, спутники, мобильные враги и животные зарегистрированы и проверяются машинно.
- Навигация получила единый диагностический контракт `walkability_reason`; F11 показывает тот же результат, который используется реальным движением.
- Устранены невидимые коллизии старого слоя первой локации, расширены проходы мостов, а старый foreground больше не подменяет master-арт при приближении.

## Осознанные ограничения, не являющиеся активным долгом

- Godot 4.7 не предоставляет достоверное встроенное line/branch coverage для GDScript. Проект не публикует выдуманный процент: используются 2673 поведенческих утверждения, content validation, архитектурный gate и ручной QA.
- Golden screenshots не входят в обязательный CI до появления фиксированного software-renderer: различия GPU-драйверов создают ложные падения. Для визуального контроля есть детерминированные preview-режимы и QA-маршруты.
- Каталоги остаются словарями с runtime-валидацией. Переход на custom `Resource` оправдан только при появлении редактора контента или внешнего designer workflow.
- Пул объектов не вводится без данных profiler: текущий профиль после прогрева удерживает целевые 60 FPS, а преждевременный pool усложнил бы жизненный цикл сущностей.
- Русские строки отладочных панелей F10/F11 намеренно не входят в пользовательскую локализацию: это внутренние инструменты команды. Игровые экраны используют `LocaleSystem`; полнота художественных переводов ведётся как контентный, а не архитектурный backlog.

## Правило нового долга

Новый TODO обязан получить владельца, риск, приоритет и проверяемый критерий завершения. Перед каждым commit и push выполняются `tools/check_architecture.sh` и `./run_tests.sh`; падающий gate означает открытый блокирующий долг и запрещает публикацию.

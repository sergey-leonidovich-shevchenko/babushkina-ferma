# Технический долг

Аудит: 2 августа 2026. Приоритет отражает риск для дальнейшего расширения игры.

## P0 — следующий архитектурный этап

- **Типизированное состояние вместо полей `game.gd`.** Системы сейчас отделены по ответственности, но получают фасад `Node` и меняют его поля. Ввести `GameState` с моделями `PlayerState`, `InventoryState`, `WorldState` и адаптером миграции сохранения v1 → v2. Это устранит неявные зависимости и позволит тестировать системы без сцены.
- **Разделить представление.** `RenderSystem` владеет порядком кадра, но графические примитивы пока остаются методами фасада. Перенести world/UI overlays в отдельные CanvasItem-компоненты после стабилизации сцены, сохранив один кадрный benchmark.
- **Измеряемое покрытие.** Сейчас 60–80% — политика по тестируемой логике, а не автоматически рассчитанный line coverage. Подключить совместимый с Godot 4.7 инструмент покрытия и падение CI ниже 60%.

## P1 — до массового добавления контента

- Перевести словари врагов, предметов, рецептов, квестов и локаций в типизированные `Resource`-данные с валидацией идентификаторов при старте.
- Заменить общий `tests/test_game.gd` отдельными наборами unit/integration/save/render-smoke; сохранить единый запуск `./run_tests.sh`.
- Добавить пул объектов для добычи и эффектов, если профилирование покажет аллокации при массовом спавне.
- Сделать миграции сохранений, атомарную запись во временный файл и резервную копию последнего рабочего сохранения.

## P2 — улучшения качества

- Локализация строк через таблицу переводов вместо текста внутри систем.
- Настраиваемая раскладка ввода через InputMap и отдельные профили клавиатуры, геймпада и touch UI.
- Визуальные regression-снимки для HUD, инвентаря, магазина и крафта.
- Статический форматтер/линтер GDScript в pre-commit и GitHub Actions.

## Уже погашено этим проходом

- Ферма, рыбалка, квесты, ресурсы, магазин, обучение и порядок отрисовки выделены из фасада.
- Каталог имён и цветов предметов централизован.
- Торговля стала data-driven и больше не содержит специальных веток для моркови/семян.
- Добавлены отдельные таблицы лута, цветные кристаллы и экипируемый клинок орка.
- Архитектурные границы закреплены автотестом.

## Обязательный анимационный backlog

Машинный реестр `scripts/systems/animation_asset_registry.gd` выявляет 17 движущихся типов, которые пока не соответствуют новому стандарту. Герой использует четыре ракурса без кадров шага в активном progression-атласе; спутники, ранговые враги и пираты — одну позу; олень, лиса, кабан, летучая мышь и листохвост — преимущественно боковые циклы. Процедурное дыхание и отражение больше не считаются завершённой направленной анимацией.

Для каждого типа нужны восемь отдельных направлений и 3–5 кадров шага на направление. Полный постоянный контракт описан в [стандарте спрайтов](docs/SPRITE_STANDARD.md); добавление нового движущегося типа без записи в реестре блокируется тестом.

## Следующий приоритет

1. Предметы рюкзака: большинство инструментов, еды, материалов, оружия и лута пока отображаются цветными кругами. В `assets/inbox/craftpix-net-994534-*` есть 258 лицензированных UI-иконок, которые нужно разметить и сопоставить с типами предметов.
2. Тайники: сундук, мешок и куча хлама всё ещё рисуются примитивами; полноценный спрайт есть только у груды костей.
3. Врата между локациями: сейчас это светящееся кольцо; желательно выбрать арку из ruins/guild/cursed наборов.
4. Инструменты в руках: мечи и лук рисуются линиями поверх героя. Нужны оружейные оверлеи для восьми направлений.
5. Поочерёдно закрыть анимационный backlog: герой → спутники → пираты → мобильные ранговые враги → животные; после ходьбы дорисовать attack/hurt/death.

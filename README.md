# Бабушкина ферма: Тайна Лунной долины

Уютная пиксельная ферма с RPG-приключением: выращивайте урожай, исследуйте семь локаций, выполняйте задания, сражайтесь, рыбачьте, добывайте ресурсы и развивайте ремёсла.

> Проект находится в стадии играбельного вертикального среза. Основной цикл и все перечисленные ниже системы уже доступны для проверки.

## Быстрый запуск

### macOS

Дважды нажмите **`Бабушкина ферма.app`** в корне проекта. Лаунчер откроет только игру и автоматически найдёт Godot в `tools/Godot.app` или `/Applications/Godot.app`.

### Через Godot

1. Установите Godot 4.7.1 или используйте версию из `tools/Godot.app`.
2. Откройте `project.godot`.
3. Нажмите **F6/F5** или кнопку ▶.

При первом запуске игра предложит выбрать язык. Доступны русский, английский, испанский, немецкий, французский и упрощённый китайский.

## Что уже можно делать

- выращивать культуры с четырьмя стадиями роста, повторным поливом и визуальным прогрессом;
- исследовать деревню, лес, каменистую область, руины, пещеры, проклятую землю и мастерскую;
- выполнять сюжетные и побочные миссии, пользоваться магазином и верстаком;
- сражаться оружием ближнего и дальнего боя, охотиться и собирать таблицы добычи;
- рыбачить, добывать камень и цветные кристаллы, искать случайные тайники;
- развивать уровень, характеристики и пять ремёсел, использовать еду и экипировку;
- управлять безразмерным рюкзаком и назначаемой панелью из десяти быстрых слотов;
- сохранять весь прогресс с миграцией старого формата и резервным восстановлением;
- проходить встроенное пошаговое обучение, охватывающее все игровые системы.

Одна реальная секунда равна одной игровой минуте. В тестовом балансе морковь созревает за 20 секунд: четыре стадии по 5 секунд, с обязательным повторным поливом после второй стадии.

## Основное управление

| Действие | Клавиатура |
| --- | --- |
| Движение | `WASD` или стрелки |
| Использовать предмет / взаимодействовать | `E` или `Space` |
| Атаковать | `F` |
| Выбрать быстрый слот | `1`–`0` |
| Открыть рюкзак | `Tab` или `I` |
| Журнал заданий | `J` |
| Развитие персонажа | `K` |
| Сохранить / загрузить | `F5` / `F8` |
| Включить или выключить звук | `F6` |

Действие и атаку можно удерживать одновременно с движением. Полная раскладка для клавиатуры, мыши, геймпада и сенсорного экрана приведена в [руководстве по управлению](docs/CONTROLS.md).

## Проверка проекта

```bash
tools/check_architecture.sh
./run_tests.sh
```

Quality gate проверяет архитектурные границы, русскую документацию методов, внутренние ссылки и 771 поведенческое утверждение. Те же команды выполняются в GitHub Actions на каждом push и pull request. Целевой диапазон покрытия тестируемой логики — 60–80%; правила и ограничения метрики описаны в [TESTING.md](TESTING.md).

## Технологии и ресурсы

- Godot 4.7.1 и GDScript;
- pixel-art с фильтрацией `nearest`;
- собственный процедурно созданный саундтрек и звуки действий;
- локальные и свободно распространяемые графические наборы с сохранёнными файлами лицензий.

Происхождение и статус недостающих изображений собраны в [SPRITE_AUDIT.md](SPRITE_AUDIT.md). Вода, рыба и всплески основаны на бесплатном наборе [Foozle Lazy River](https://foozlecc.itch.io/critters-lazy-river), опубликованном под CC0.

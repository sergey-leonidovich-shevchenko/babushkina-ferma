# Производительность

Замер выполняется встроенным autoplay-маршрутом по ферме, лесу и пещере при ограничении 60 FPS:

```sh
tools/Godot.app/Contents/MacOS/Godot --path . --max-fps 60 --quit-after 480 --print-fps -- --autoplay
```

Тестовый Mac: AMD Radeon Pro 5300M, Godot 4.7.1, OpenGL Compatibility.

| Версия | Результат |
|---|---|
| Исходная отрисовка тысяч объектов каждый кадр | до 1 FPS в худшем замере |
| После сокращения фоновых draw calls | 38–60 FPS |
| После разделения статического и динамического CanvasItem | стабильные 60 FPS / 16.66 мс |
| После SOLID-рефакторинга 02.08.2026 (104 теста) | стабильные 60 FPS / 16.66 мс |
| После миссий, двух NPC и пещерного босса (121 тест) | стабильные 60 FPS / 16.66 мс |
| После контекстного сканирования в радиусе трёх клеток (147 тестов) | стабильные 60 FPS / 16.66 мс |
| После 9 блуждающих/пугливых животных и анимаций (162 теста) | стабильные 60 FPS / 16.66 мс |
| После 19 случайных тайников, подсветки и коллизий (177 тестов) | 58 FPS на прогреве, затем стабильные 60 FPS / 16.66 мс |
| После RPG-уровней, 8 навыков и четырёх ресурсных полос (202 теста) | стабильные 60 FPS / 16.66 мс |

Статический фон хранит команды отрисовки и при движении меняет только transform. Динамический слой перерисовывает персонажа, культуры, врагов и UI.

Перед контрольным замером следует закрыть старые экземпляры игры: несколько одновременно открытых окон делят GPU и делают результат нерепрезентативным.

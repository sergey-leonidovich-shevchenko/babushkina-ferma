# Производительность

Замер выполняется встроенным autoplay-маршрутом по ферме, лесу и пещере при ограничении 60 FPS:

```sh
tools/Godot.app/Contents/MacOS/Godot --path . --max-fps 60 --quit-after 480 --print-fps -- --autoplay
```

Тестовый Mac: AMD Radeon Pro 5300M, Godot 4.7.1, OpenGL Compatibility.

| Версия | Результат |
|---|---|
| Исходная отрисовка тысяч объектов каждый кадр | до 1 FPS в худшем замере |
| После сокращения фоновых draw calls | 38–60 FPS |
| После разделения статического и динамического CanvasItem | стабильные 60 FPS / 16.66 мс |

Статический фон хранит команды отрисовки и при движении меняет только transform. Динамический слой перерисовывает персонажа, культуры, врагов и UI.

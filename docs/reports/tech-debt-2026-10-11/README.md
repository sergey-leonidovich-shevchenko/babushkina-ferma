## Проверка бюджета F10

Godot 4.7.1 Compatibility, AMD Radeon Pro 5300M, окно **1152×648**, VSync и предел 60 FPS. Каждый прогон содержит 1400 измеряемых кадров после 120 кадров прогрева, seed 20260908 и одинаковую физическую петлю по деревне без телепорта. Во всех файлах route_finished=true и user_saves_unchanged=true. Другой экземпляр игры и полный тестовый процесс во время замеров не запускались.

Основа: коммит 8397389 (0.0.101). Для кандидата временно изменялся только FRAME_BUDGET_USEC с 3000 на 1500. Порядок: normal → F10 с 1500 → F10 с исходными 3000. Затем настройка возвращена к исходной.

# WIKI-003 — выравнивание даты при раскрытых материалах

На финальном кадре head fc36fc1c заметно, что grid растягивает левую колонку даты на всю высоту длинного списка материалов: пояснение даты отдаляется от самой даты. Одна CSS-настройка align-self:start сохраняет дату и основание рядом. Статусы, сортировка, источники дат, API и игровой код не меняются.

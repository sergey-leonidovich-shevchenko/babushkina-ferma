## Фактический профиль

`python3 tools/run.py assets.migration.test_scanner_history` выполняет12 случаев в настоящем disposable Git с пробелами в пути. Старый producer исполняется из точных Git-байтов; его граф/ресурсы/неизвестные readers совпадают со свежим, кроме явно объявленного режима и подписи кода. Проверяются старый и новый success, отсутствие old commit в target repo, подмена подписи/режима, неизвестные режимы, недоступная история, чужие Git index/config и изменённые байты текущего инструмента. Реальный record-путь выполняет3 Git-read в отдельном проекте и останавливается явным QA-отказом до записи inventory/plan.

Импорты квалифицированы, единственный собственный ROOT получает общий source-root; функции и численные алгоритмы сравниваются по AST. Четыре mode сохранены, UID не перемещаются, root tools —509 вместо513. Cache нового пакета остаётся ignored. Три объявленных provenance-свидетельства закреплены прежним commit `d609ab4f…` и точными SHA, как принятый reader; все остальные поля политики прежние. Runtime продолжает читать прежние WAV.

Прежняя историческая карта относила также `import_pixabay_assets.py` к audio. Он обрабатывает изображения PIL и пишет предметные PNG; его фактический владелец — `assets/authoring`. Этот отдельный перенос остаётся следующему пакету обработки изображений, явно записан в карте и не считается выполненным. Историческая ведомость01 не переписывается.

Временный [preview](preview/result.json) предшествует изменениям проекта и остаётся помеченным prototype-only. Окончательный [профиль реальных файлов](profile.json) использует старые исходники из Git и перемещённые байты рабочего дерева. Одинаковые33 файла проходят201 измерение; семь массивов сигналов и PCM16-экспорт имеют одинаковые SHA. В обоих вариантах отклоняются четыре повреждения WAV и клиппинг при экспорте. Полный прежний список36 WAV, включая unused step и два preview, сравнивается с Git и после проверки. Временные проекты удалены. Настоящий audit CLI выполняется из чужой cwd с подставными PYTHONPATH/GIT_DIR только на принадлежащих профилю копиях: штатный audit пишет отчёт, поэтому оригинальный старый raw не перезаписывается. Общий generate main не запускается.

Профиль требует Python с NumPy; здесь использованы3.12.14/2.3.5 из установленного runtime. `profile.py --output /tmp/новое-имя.json` создаёт отдельный результат; прежние файлы и запись внутрь assets запрещены. Это проверка переноса, не выпуск новой музыки или измерение FPS. Обязательные architecture/Game/normal/F10/Wiki следующего кандидата сохраняются отдельно и не подменяются preview либо прежним зелёным359.

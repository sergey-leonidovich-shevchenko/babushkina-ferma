# Убрана постоянная рамка клетки перед героем

Из `FarmRenderer.draw` удалена одна команда рисования яркого квадрата. Выбор цели в `WorldFarmingSystem`, взаимодействия, сохранения и цикл культуры не менялись. Карточка посаженной культуры, прогресс роста, подсказка полива, угловая подсветка взаимодействий, строительная и диагностическая сетки сохраняются.

Нативные кадры Godot 1152×648: [до](before.png), [после](after.png), [посаженная и политая культура](after-crop.png). Кадры сняты без растровых правок в изолированном пользовательском каталоге. `tools/farm_cursor_review.gd` с `FARM_CURSOR_PHASE=before/after` воспроизводит их на соответствующей версии исходников.

Тот же стенд с `--headless` запускает существующий `WorldFarmingSuite`: допустимые покрытия, полный цикл культуры, расход энергии, редкие находки, сохранение и F10. Перед публикацией выполняются архитектурная проверка и полный `run_tests.sh`.

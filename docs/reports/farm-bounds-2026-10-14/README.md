# Грядки только на домашнем участке

Нативная сцена Godot, отдельный тестовый профиль, полный кадр1152×648 без обрезки и изменения масштаба. Слоты пользователя не открывались.

- [Дорога после попытки вспашки](road-blocked.png): поверхность цела, сообщение объясняет ограничение.
- [Работающая домашняя грядка](home-crop.png): вспашка, посадка и полив в исходном участке6×5.

Воспроизведение: `tools/Godot.app/Contents/MacOS/Godot --path . --script res://tools/farm_bounds_capture.gd`.

Профиль `farm_bounds_review.gd`: 556 проверок без ошибок. Покрывает полный цикл выращивания, все локации, отсутствие расходов при отказе, края широкой мотыги, перенос старых посадок и возврат при заполненной ферме, повторяющиеся старые записи, редкость находок, сохранение, удобрения, плодовый сад, таланты и животноводство.

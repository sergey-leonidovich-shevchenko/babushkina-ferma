# Дороги и физические проходы деревни

Ревизия карты 3 устраняет три препятствия: первый ствол справа от гильдии передвинут на 48 px; дорога к восточным воротам огорода обходит основание верстака; фонарь возле развилки в лес передвинут вверх на 24 px. Одинаковый чертёж используется рендером дорожек и определением поверхности. Коллизии объектов сохранены.

| Место | До | После |
|---|---|---|
| Фундамент гильдии — первый взрослый ствол | 36 px, без запаса для героя | 84 px |
| Дорога к огороду, путь 3 | 7 выборок внутри основания верстака | Ни одной заблокированной выборки; минимум 68 px |
| Дорога в лес, путь 5 | 4 выборки внутри основания фонаря | Ни одной заблокированной выборки; минимум 150 px |
| Остальные шесть дорог | Минимум 94–192 px | Проходы сохранены |

[До](clearance-before.json) и [после](clearance-after.json): поперечные пробы настоящим кругом героя радиуса 18 px с точностью 2 px, каждые 12 px вдоль всех скруглённых дорог. Из проверки исключены только подвижные враги, штатные объекты и мировая добыча остаются. Ширина считается как допустимая полоса центров плюс диаметр героя; измерение дискретное. Отдельный тест проходит каждый сегмент через NavigationSystem.move подшагами 3 px без помощи краю. Коридор гильдии пройден туда и обратно по трём полосам, ±12 px от середины.

[Сравнение игровых кадров](comparison.png), общие планы [до](before-overview.png) и [после](after-overview.png). Для сравнения использованы один seed мировой добычи 20261011, полдень первого дня, ясная погода, одинаковые герой и камера. Кадр «до» снят отдельным native-процессом из исходников коммита 064f774; ресурсы соответствующих деревьев/декора не менялись. PNG не увеличивались.

Загрузка старой карты второй ревизии переносит только дерево `tree_0`, если оно всё ещё стоит в прежней штатной позиции (2016,336). Рубка, здоровье и таймер роста остаются; пользовательская позиция дерева сохраняется. Старые сундуки и звери повторно не мигрируются. Свободный герой остаётся на месте; если новое основание перекрыло сохранённую позицию, выбирается ближайшее проверенное свободное место. Миграция прототипа ревизии 0/1 по-прежнему работает отдельно.

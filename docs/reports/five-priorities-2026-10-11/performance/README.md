# Производительность боя — 11 октября 2026

База: `572d5be`, 0.0.111. Измерения до и после идут последовательно на Godot 4.7.1 Compatibility / AMD Radeon Pro 5300M, окно 1152×648, vsync, 60 FPS и 60 физических тиков. Сцена прогревается 120 кадров, затем записывается 1400 реальных интервалов `Time.get_ticks_usec`. Это окно, а не прежний полноэкранный тест 3584×2240.

## Нагрузка

Третья стадия хранителя: все четыре настоящие атаки, четыре призванных существа, пик 25 снарядов. Герой движется физическими клавишами с обычными коллизиями. Только измерительный стенд восстанавливает HP, чтобы не завершить замер поражением; ИИ, урон, скорость мира и геометрия остаются игровыми. Пользовательские сохранения не читаются и проверяются по SHA256. Проверка деревни использует прежнюю физическую петлю с F10.

## Исправления

Каталог 89 кадров индексируется по строке/колонке один раз; Rect2 и опоры приготовлены заранее. Индекс хранителя кешируется с проверкой при перестановке/замене врагов. Неизменные основания декора пещеры готовятся один раз на комнату. Подвижные существа, ресурсы, печать и наградной сундук продолжают проверять живое состояние.

Пять независимых CPU-проходов по 44500 запросов кадров и 2880 навигационных проб: медианы 235994 → 49645 мкс (4,75×) и 429949 → 247340 мкс (1,74×). Сырые результаты: [до](cpu-before.json), [после](cpu-after.json). Эти показатели измеряют стоимость запросов, а не FPS.

## Воспроизведение

```sh
./tools/Godot.app/Contents/MacOS/Godot --headless --path . --script tools/boss_cpu_review.gd -- --output=res://docs/reports/five-priorities-2026-10-11/performance/cpu-repeat.json
./tools/Godot.app/Contents/MacOS/Godot --path . --resolution 1152x648 --windowed --script tools/cave_boss_frame_review.gd -- --report-dir=res://docs/reports/five-priorities-2026-10-11/performance/repeat
```

Для F10 добавить `--benchmark-debug-overlay` после `--`. JSON сохраняет все кадры, CPU monitors, фактическую нагрузку и неизменность сохранений. Микрозамер независим от vsync; нативный замер включает renderer и системный планировщик. Сравнение геометрии с полным обходом покрывает шесть комнат, углы и касания объектов. Тест кеша босса проверяет перестановку, замену и удаление массива.

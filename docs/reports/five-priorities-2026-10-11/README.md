Первые пять коммитов: `4f55953`, `4bde9f0`, `a995501`, `064f774`, `78abba8`. Последний из них прошёл 8317 поведенческих утверждений, 0 ошибок, архитектурный gate; он отправлен в origin/main. Каждый предыдущий коммит также прошёл полный набор своего состояния. Последующая полировка бокового лука проверяется отдельным коммитом.

После пяти основных изменений `tools/performance_gate.sh` дал средние 60 FPS в двух headless-сценариях по 480 кадров, с F10 и без него, при пороге 50. Это контроль скорости симуляции, не измерение GPU и не основание закрывать нативный долг.

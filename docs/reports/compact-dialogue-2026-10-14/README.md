# Компактный диалог Б

[Нативный кадр](runtime.png) снят после выбора и переноса светлого варианта. Окно832×176 занимает19,6% базового кадра1152×648. Нижняя панель инструментов прячется на время разговора. Мир сохраняет существующую остановку симуляции.

Проверены перенос длинных русских, китайских и немецких строк при масштабе90–120%, сохранение каждого символа, отсутствие уменьшения кегля, попадание мыши/тача и преобразование FullHD–4K, реальные подарки, закрытие и принятие миссий. Короткие реплики принимаются прежним нажатием, длинные сначала листаются; кнопка Далее не выдаёт миссию или награду. Экраны и сохранения пользователя не использовались.

Профиль: `tools/compact_dialogue_review.gd`; полный набор запускается перед публикацией hook-коммитом.

`tools/run.py` перенаправляет четыре прежние команды. Прежние импорты через `from tools.qa.world import …` получают те же объекты модулей, которыми пользуются текущие тесты. Прежние Godot URI сохранены однострочными входами. Все четыре UID закреплены за реализациями.

Сборщики лавок и улицы копируют реализации по известным текущим путям, записывая в пакет прежние логические ключи. Чтение истории использует закреплённый Git-коммит и учитывает исходный, промежуточный и текущий адреса. Когда в одном коммите есть промежуточный Godot-вход и текущий скрипт, вход должен содержать точный однострочный `extends` этого скрипта. Вход без реализации отклоняется. Карты REFACTOR-01, архивы VPROP-002 и VPROP-003 и игровые ассеты сохранены. Общие функции оград, улицы, камеры и наблюдения отрисовки остаются у своих владельцев.

## Проверки переноса

- Прежняя и текущая команды валидатора в корне и во внешней папке выдали побайтно одинаковую сводку. SHA-256 stdout `b955501e4d12f72d9746e290f696b4fe6868eb0bc4fd887edde0787fe09e7132`. Проверены 50 архивных PNG и 224 вызова отрисовки. Python-профиль прошёл 9 исходных тестов и 10 после переноса, включая реальную Git-историю и отказ при подмене входа.
- Настоящий генератор выполнил `--build` в копии с пробелом в пути. Три PNG, профиль, манифест и каталог совпали по SHA-256 между ступенями. Порча PNG отклонена с кодом 1. Сборщик отклонил существующий архив с кодом 1 и неизвестную фазу с кодом 2 в обоих расположениях.
- Godot review прошёл 24/24 до переноса и 24/24 по каждому URI после переноса. Оба захвата по обоим URI в headless вышли с кодом 2 без каталога результатов. Для проверки изображения использован принятый нативный архив.
- В отдельной копии проекта убраны оба пути галереи. Ранняя загрузка останавливалась на компиляции, итоговый скрипт компилируется, а фаза `before` доходит до штатного headless-отказа с кодом 2. Галерея загружается только для фазы `after`.
- Восемь скриптов прошли строгий анализ Godot. Проверка структуры tools и локальных ссылок прошла. Wiki собрана, 165 тестов прошли.

# Разработка новой интеграционной проверки

Два исходных запуска нового аудитора завершились отказом до принятия результата:

1. В минимальном временном снимке main не было `wiki/articles/index.json`, который штатно читает readPlanningCatalog. Исправлено добавлением принятых статей/индекса в изолированный Git archive; чужой checkout не использовался.
2. Снимок обзора24 хранит счётчики узлов, но не полные массивы dialogue, в отличие от снимка25. Проверка теперь сверяет старые статьи целиком с принятым Git blob, а новые — также по каждой написанной строке. Старая проверка не ослаблена и не переписана.

Последующий профильный запуск прошёл: объединённые записи/граф/статусы/таблицы и17305 исторических файлов сохранены. Это редакционный аудит, не будущие игровые сценарии и не исследование интереса аудитории.

Повторная сборка после правки оформления сначала остановилась до экспорта: в окружении команды не был передан `WIKI_GODOT_BIN`. Повторный полный `pnpm check` с установленным Godot 4.7.1 прошёл 135/0. Валидаторы и данные ради исправления окружения не менялись.

26 октября после смены сессии прежний процесс pre-commit и файлы `/private/tmp` оказались недоступны. Merge-коммит не был создан; этот незавершённый прогон не считается PASS. Python 3.11.17 / Pillow 11.3.0 восстановлены из официальных пакетов в игнорируемой среде `.godot/creative-runtime`; туда же перенесено временное хранение полного нового журнала. Полный неизменённый hook повторяется с начала. Только успешно завершённый повтор создаёт `gates.json` и сжатый журнал; прежние частичные счётчики не суммируются с новым запуском.

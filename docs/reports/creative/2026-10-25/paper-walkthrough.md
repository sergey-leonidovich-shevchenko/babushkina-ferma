# Редакторская читка переходов

Это собственная проверка будущего дизайна по написанным условиям, не игровой прогон и не малая проба пяти игроков. Наблюдений аудитории пока нет. Все механики остаются предложениями.

| Идея | Самостоятельный путь | Проверенный на бумаге край |
|---|---|---|
| 242 | Опора → совмещение → три операции → выбор ручки → одна бочка | Перехват не теряет шаг и не требует держать клавишу после загрузки |
| 243 | Три наблюдения/две версии в любом порядке → согласия → одна подпись | Вопрос о разрешении остаётся доступен после уже услышанной версии; публикация ждёт общего RELIC-09 |
| 244 | Вопросы → preview short/full → отдельное обещание → k целей → одно закрытие | min(20×k,payout) для k=0…5; обычный выход suspended, оплаченный досрочный итог не принимается повторно |
| 245 | offers confirmed → stop confirmed → показ пустой корзины при входе в need → needs confirmed → agree | Раньше needs можно было только observed; теперь есть прямое подтверждение. Вход показывает контекст даже при unknown, не требует переводчицу |
| 246 | Причина визита → четыре preview → confirm цены → applied → закрыть/один undo | Просмотр не списывает монеты; повтор undo не возвращает их дважды, старый appearance не переписывается |
| 247 | Согласие → безопасный герой → один mini-owner → коробочка → возврат → рассказ | Кресло резервируется; на границе Крош прекращает опыт, ни инвентарь, ни лечение героя не доступны |
| 248 | Видимое окно и герой в6 клетках → searching → следующий день спор → ещё день resolved | Большой пропуск не проигрывает три сцены; благодарность зависит от реального участия |
| 249 | Программы → схема прохода/Квит → один голос героя → подтверждение счёта → недельный результат | При Квите abstain+B героя счёт3:3; при Квите B и герое B счёт3:4; ничья заранее3 дняA/4B |
| 250 | Добровольное приглашение → повторяемая память → три разрешённых подписи → три формы прощания | Память можно спросить после согласия, но повтор согласия не сбрасывает этап; преувеличение отвергается до commit |
| 251 | Допустимый запасной axe → один owner loan → срок/recall → return_ready → auto PACK → returned | returned не заблокирован условием active: благодарность доступна после настоящей передачи, но не удерживает вещь |

Фактическая редакционная программа отдельно проверяет количество узлов/ответов, рейтинги, сохранность реестров и зависимости. Будущие шесть F-сценариев каждой статьи проверяются только при реализации.

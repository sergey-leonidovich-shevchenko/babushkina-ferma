# VCOMPAT-005 — Коллизии воды при смене графики

Парный сценарий в двух экземплярах `main.tscn` использует движок Godot 4.7.1, viewport 1152×648, масштаб 120%, камеру `(264, 144)`, seed `20261015` и одну фазу воды. В первом экземпляре применяется профиль `normal`, во втором — `static` с уменьшенным движением. Тест проверяет фактический материал реки перед повтором действий.

## Что сравнивается

- Каждый экземпляр загружает копию сохранения [v1-core](../../../../tests/fixtures/saves/v1-core.json). Герой начинает в клетке, затопленной в актуальной геометрии. Штатная миграция переносит его на сушу и сохраняет монеты и инвентарь. Переключение материала и камеры сохраняет полный снимок после загрузки.
- Движение через центр обоих настилов выполняется обычным методом с коллизиями. Реестр воды сохраняет поверхность под настилом. При таком же вводе на реке и у пруда тело героя останавливается на границе с причиной `water`.
- На мосту и рядом с прудом используется обычная удочка. Проверяются закреплённая точка поплавка вне настила, тип водоёма и расход одной наживки и единицы прочности. Заброс вне радиуса оставляет прежние расходники и состояние `idle`.
- В обоих профилях сравниваются итоговые координаты, игровые события, состояние удочки и полные снимки сохранения.

Результат профильного прогона — 35 проверок без ошибок. Исходные проверки топологии, навигации и рыбалки на `e79a3a870eb683e09e4ce3c5dfd02e6ea67e9777` прошли с результатами 576/0, 1750/0 и 1410/0. Новый сценарий входит в полный игровой набор.

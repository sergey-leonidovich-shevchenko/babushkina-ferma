# VRENDER-007 — настил и перила мостов

На обоих мостах первой локации настил находится на слое земли. Перила используют две боковые полосы той же текстуры. Проход мира рисует части перил по обе стороны отображаемой опоры героя. У южного выхода перила полностью уходят за героя, когда он проходит перед их опорами.

Текстуру и физический проход размером 96×192 берём из действующего плана. Перила используют существующий viewport мира и отсекаются по камере. Настройка сцены `split_bridge_rails` переключает разделение для сравнения.

## Нативная проверка

Кандидат **0.0.426**, Godot **4.7.1 Compatibility**, macOS и AMD Radeon Pro 5300M. Камера, игровой день, направление героя и масштаб 120% зафиксированы внутри каждой пары. Два видимых игровых viewport имеют размер 1152×648 каждый. [Конфигурация, хеши кадров и исходников](native/capture.json).

- Герой пересёк оба моста в обе стороны через штатный `NavigationSystem.move`. Слева и справа от полосы прохода на уровне русла навигация вернула `water`. У каждой позиции для сравнения навигация вернула `walkable`.
- В 13 парах кадров отличия ограничены полосами перил. Оба кадра по центру и оба кадра южнее опор попарно совпали. При проходе у южной опоры ближнее перило перекрывает часть руки и одежды. Отдельно проверены цельный кеш земли и прямой вывод. На каждом листе слева прежний кадр, справа новый. [Западный мост](bridge-1-comparison.png) · [восточный мост](bridge-2-comparison.png).
- После входа в пещеру и возврата кадр в границах моста точно совпал. При открытой через `MenuSystem` паузе визуальные часы остановились. Снимки 32 вызовов `Game._draw` совпали до и после вместе с позицией героя, камерой и локацией. Кадр второго viewport точно совпал после переключения слоёв и смены карт в первом. [Кадр после возврата](native/returned.png) · [пауза](native/pause.png).

Первое сравнение возврата захватывало и уведомление об открытии деревни. Оно изменило левую нижнюю часть кадра за пределами моста. Проверка возврата сравнивает полный прямоугольник моста, а парная проверка отрисовки при одинаковой камере сверяет весь экран, включая HUD, кусты и передний план.

Предкоммитный аудит обнаружил новый вызов нарезки. Запись в реестре фиксирует три полосы текстуры и целочисленную границу по высоте. [Реестр нарезки](../../../../tools/assets/slicing/slice_policy.json).

## Как повторить

В корне проекта выполните сценарий в видимом окне. Путь вывода должен указывать на новый каталог. Профиль отделяет данные проверки от сохранений игры.

```sh
"$FARM_GODOT_BIN" --path . --windowed \
  --script res://tools/qa/world/viewport/bridge_layers_capture.gd -- \
  --output="/absolute/path/to/new-bridge-capture" \
  --profile="Codex-VRENDER-007-review" \
  --base-commit=ccb8bf73e4ac9a4345dabccb683055adad8e4f7e
```

В `capture.json` должны быть пустой список `errors`, 13 пар с `other_pixels_equal: true` и проход в обе стороны для каждого моста. Сверьте хеши `sources` с байтами проверенного Git-коммита. Полные кадры обеих пар у опор, возврата и паузы приложены к отчёту. Остальные кадры создаёт тот же сценарий.

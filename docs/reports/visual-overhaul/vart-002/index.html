Это макеты выбора масштаба. Игровые ресурсы, физика и штатная камера сохраняют текущие настройки. Мир снят в остановленном состоянии с выключенными декоративными эффектами и мировыми подписями; HUD отрисован отдельным нативным проходом. На ферме подготовлены разные стадии моркови для оценки читаемости. Образцы поз прозрачные; число «фигура» измерено по альфа-каналу вида вниз. FPS и удобство живого боя этим сравнением не измеряются.

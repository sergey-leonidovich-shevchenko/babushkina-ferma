# VART-003 · Палитра материалов

16 октября 2026. Подготовлены два варианта палитры для принятого мягкого рисунка **VART-001 A** и масштаба **VART-002, вариант 3**. **Пользователь выбрал A — «Тёплая долина» прямым ответом в чате; VART-003 принята.** B сохранён как рассмотренная альтернатива. [Открыть стенд](index.html) · [Все цвета](palette.json) · [Происхождение](source.json).

## Варианты

- **A — Тёплая долина:** шалфейная трава, медовый дуб, тёплая земля и серый камень; спокойная бирюзовая вода и прохладное железо. Рекомендуемый вариант для уюта фермы.
- **B — Лунная прохлада:** более холодная зелень, приглушённое дерево, серо-голубой камень и синяя вода. Меняется палитра, степень мягкости рисунка остаётся A.

У каждого материала пять тонов: глубокая тень → тень → средний → свет → блик. Для дня и вечера шкалы заданы отдельно: всего **24 шкалы / 120 цветовых значений**. Полный источник — `palette.json`; HEX показаны на странице. Вечер сохраняет локальную окраску, охлаждает тени и уменьшает яркость среднего тона всех шести материалов. Направление света и геометрия падающих теней этим решением не утверждаются — это VART-007.

Не назначаем обязательный контраст 3:1 между любой парой природных материалов: часть средних яркостей близка, особенно вечером. Их различение опирается также на форму, масштаб деталей и кромку. [Измерения](measurements.json) сохраняют линейные яркости без заявления о цветовой доступности всей игры. При переносе отдельно проверяются реальные края дороги/травы, берега, лут, враги и состояния действий в смешанной сцене.

## Один рисунок, неизменная камера

Встроенным `image_gen` нарисован **один нейтральный RGBA-мастер 1536×1024** по стилевому референсу [модулей A](../vart-001/modules-a.png). [Точный запрос](prompt-material-master.txt) сохранён. PNG скопирован без изменения байтов; никаких дополнительных вариантов генерации или CPU-перекраски нет. Каждый материал имеет собственную измеренную область с запасом не менее 4 исходных пикселей при пороге alpha ≥ 26/255. Области не получены слепым делением нерегулярного листа.

SVG сначала получает яркостный сигнал `0.2126 R + 0.7152 G + 0.0722 B`, затем интерполирует каждый канал между пятью sRGB-ступенями на узлах 0 / .25 / .5 / .75 / 1. Для фильтра явно задан `color-interpolation-filters=sRGB`, альфа остаётся identity. Механика таблицы описана в [спецификации Filter Effects, feComponentTransfer](https://www.w3.org/TR/filter-effects-1/#feComponentTransferElement). Это способ просмотра палитры; финальные игровые PNG и шейдеры могут использовать другой согласованный производственный процесс. Исходный мастер остаётся неизменным.

| Материал | Source rect x/y/w/h | Рамка в мире | Центр стенда |
|---|---|---|---|
| Трава | 73 / 81 / 409 / 398 | 120×120 | 170 / 130 |
| Дерево | 567 / 124 / 403 / 322 | 144×120 | 480 / 130 |
| Камень | 1061 / 100 / 397 / 371 | 120×120 | 790 / 130 |
| Земля | 70 / 545 / 428 / 408 | 120×120 | 170 / 370 |
| Вода | 570 / 549 / 398 / 396 | 144×144 | 480 / 390 |
| Металл | 994 / 634 / 488 / 255 | 144×96 | 790 / 370 |

Каждый рисунок пропорционально вписан в свою рамку, без растягивания. Точная мировая геометрия — одна на все четыре сочетания палитры/времени. Поле **960×540**, центр **480/270**, выход **1152×648** даёт проекцию **1.2**. Для сравнения взята текущая поза героя вниз из нативного VART-002: clip 192×192 из листа 576×192, стопы в 96/160; на стенде стопы 480/270. Видимая высота около **97 px**. Изображение героя и его цвета в дневном/вечернем просмотре не меняются; оно служит масштабной линейкой. Общий режим «Без цвета» обезличивает и образец героя.

**Это стенд материалов с героем, а не дизайн карты, нативный кадр Godot или готовый набор тайлов.** Он сравнивает цвет при одной камере, не решает стыки, дорожные повороты, footprint, коллизии, свет или качество будущей анимации. Доски и наковальня смотрят вниз к игроку, оси прямые. Три ракурса предметов и правило сетки сохраняются; другие стороны этой партией не заказывались. Рябь воды здесь нарисована неподвижно, её динамика относится к VSHORE/WATER.

## Решение и перенос

Получен прямой ответ пользователя: **«A — Тёплая долина (рекомендую)»**. Решение записано в `palette.json`, ART_GUIDE, карточке и странице; по умолчанию открыт A, B остаётся среди макетов. Просмотр B не меняет принятый выбор. Согласование палитры завершено, подключение новых ресурсов в игру относится к отдельным карточкам. Требование проекта: [AGENTS.md](../../../../AGENTS.md) — «Сначала показывай варианты; перенос в игру выполняй после выбора пользователя».

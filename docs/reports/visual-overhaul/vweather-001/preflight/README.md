# Регрессия seed настоящего producer

[Результат](seed-regression.json) относится к headless-вызову настоящего `Cases.create`, а не к нативной картинке. Один и тот же [probe](seed-probe.txt) до исправления вернул случайный seed923694286 и exit1, после — закреплённый20261015 и exit0. Обычные userdata не менялись; собственный override удалён в обоих случаях.

[Исходник до исправления](scenarios-before.txt) взят из незакоммиченного подготовительного index, который совпадал с рабочим файлом во время отрицательного сценария. Он не выдаётся за код принятой main. SHA исходника до/после и одинакового probe сохранены в JSON. Исправление устанавливает `world_loot_seed` после `scene.set_script`, до входа сцены в дерево. Постоянный suite дополнительно проверяет настоящее создание сцены и её полный snapshot; native reader тоже требует этот seed.

Первый полный hook прерван во время quality после обнаружения риска. Завершены только подтверждённые собственные дочерние процессы; wrapper проверил сохранность обычных каталогов и удалил только свой override. Commit и публикации не было. Этот прогон не принимается; полный штатный hook должен пройти заново.

Настоящая нативная проверка baseline/candidate по-прежнему выполняется отдельно в CI/remote.

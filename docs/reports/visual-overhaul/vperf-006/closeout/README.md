## Решение

Штатный `StaticCover` остаётся рабочим вариантом для 14 неподвижных цветов. Общий MultiMesh ускорил первый короткий повтор на 2,38425 мс по p95 и уступил в двух следующих. Пространственные партии сокращают число поданных экземпляров с 14 до 3 на границе и с 14 до 0 в пустой области. В пустой области они сэкономили один draw call кеша. При полном обновлении они добавили девять, а в 600-секундном цикле оба MultiMesh уступили штатному режиму по p95. [Геометрия](../geometry-control.json) · [Протокол](../PLAN.md).

Серия использовала один Linux X11 runner с четырьмя логическими ядрами AMD EPYC 9V45. Профиль использовал Mesa llvmpipe, Godot 4.7.1, масштаб 120% и окно 1152×648. Траектория, камера и снимки слота совпали во всех парах. Во всех 46 парах PNG окна и кеша совпали все пиксели RGBA. Перекрытия героя лавкой и доской проверены по обе стороны линии глубины. [Сводка замеров](../native-ci-01/summary.json).

В каждом коротком прогоне кеш сохранял одну ревизию. В каждом длинном по сырым счётчикам подтверждено одно полное обновление кеша. Оно затронуло три измеренных интервала. Полная статистика включает эти интервалы, а распределение для готового кеша выводится отдельно. Время GPU и аппаратная частота показа в этой серии не измерялись.

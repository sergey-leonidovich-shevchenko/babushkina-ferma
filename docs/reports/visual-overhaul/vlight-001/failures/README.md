# Неуспешные и отрицательные проверки

Эти серии не являются нативной приёмкой. `raw.zip` сохраняет точные журналы, argv/exit receipts, manifest и замороженные QA-входы. Повторяющиеся JSON snapshots сжаты без изменения содержимого; PNG и disposable production/control проекты не включены. SHA256/размер каждого сохранённого файла — в `files.json`.

- `native-a`: первая диагностическая production-съёмка остановилась из-за конфликта имени `Projection` с builtin Godot. Частичный manifest остался `complete:false`. Имя заменено на `WorldSpace`.
- `preflight-negative`: настоящий `--check-only` против прежних ошибочных QA-входов A отклонён **до открытия native-окна**. Это проверка отказа, не удачная съёмка.
- `native-c`: полная серия прервалась на `1152-on` из-за runtime Array → Array[bool] в `_measure`. Logger вывел завершающий marker и launcher вернул0, но `SCRIPT ERROR` в настоящем журнале отклонён collector. CPU-наборов0, поэтому принятие запрещено. Массив исправлен типизированной инициализацией и отдельным reverse; collector также требует12 наборов и полные viewport-контроли.

Первый строгий semantic-прогон после A также обнаружил небезопасные Variant-присваивания; после явных type guards все пять GD прошли второй прогон. Успешный check-only сам по себе не гарантирует успешное выполнение `_measure`, что и показала C. Нужна свежая полная нативная матрица исправленного producer.

# PR77 P2 · Точная официальная сборка

На первом опубликованном head `1fc3379385cd68543a2aebf5ad136b6d1ee24298` независимый Tech Lead нашёл ложный PASS: префикс `4.7.1` принимал `4.7.10`, подстрока `official` принимала `unofficial`, а фактический заголовок `engine.txt` не сравнивался с `capture.engine`. [Исходное воспроизведение ревьюера](reviewer-reproduction.json) сохранено без изменений. Этот head не принят.

Исправленный reader требует точный `4.7.1-stable (official)` и единственный заголовок настоящего native-журнала `Godot Engine v4.7.1.stable.official.a13da4feb - https://godotengine.org`. Во всех шести исходных запусках записаны именно эти значения. Ограничения native display/Compatibility и остальные проверки архива сохранены.

Три новые проверки изменяют отдельные копии настоящей серии D и обновляют соответствующие SHA manifest: другая официальная patch-версия, unofficial, правильный JSON при журнале Godot4.8. Изменённые SHA не дают обойти содержательную проверку.

[До исправления](before.txt) · [После исправления](after.txt) · [SHA и результат](receipt.json) · [Точный сценарий](reproduce.py.txt).

Полный обновлённый набор reader также прошёл: [19 тестов, 0 ошибок](reader-19.txt). Прежние 16 случаев сохранены; три новых проверяют обязательное замечание P2. Штатный полный hook и независимое повторное ревью нового head остаются обязательными.

Сценарий запускается из корня проекта установленным Python с Pillow, без Godot, в **новый внешний каталог**:

```sh
python3 - /private/tmp/new-vlight-engine-regression < docs/reports/visual-overhaul/vlight-001/review-engine/reproduce.py.txt
```

Он читает настоящий прежний reader из Git, проверяет точные прежние зависимости анализа, запускает те же четыре unittest против старого и нового reader и сохраняет журналы/receipt. Подмена функции ограничена этим отдельным Python-процессом; исходники проекта и архив не меняются. В receipt совпадают все native SHA до и после, включая ZIP со 126 оригинальными PNG, manifest, overlays и 14 входов. Новая съёмка и игровой/FPS-допуск не заявляются.

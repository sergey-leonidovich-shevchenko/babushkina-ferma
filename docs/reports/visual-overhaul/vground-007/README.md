# VGROUND-007 · Огород и декоративная земля

Первая overworld использует новый материал почвы, горизонтальные борозды и различимые без красной капли состояния полива. Сохранены прежние 6×5 клеток по 48 единиц, начало (144,816), проходимость, семена, энергия, рост и урожай. Остальные карты и старые ресурсы сохранены. [Wiki](../../../../wiki/articles/garden-soil.md).

## Решение

- `GardenSoil` отделяет неподвижную подготовленную землю от обработанных клеток. Нетронутая почва не получает ложные борозды. Мягкое покрытие остаётся внутри осевого участка; влажность изменяет тон, не правила вспашки.
- Новый оригинальный [мастер](masters/garden-loam-v1.png), [промпт](prompts/garden-loam-base.txt) и [паспорт](art-source.json). В runtime только Godot RGBA8 / Lanczos 512²; рисунок не редактировался кодом. Горизонтальные неглубокие борозды и alpha — геометрия. UV зеркальные с периодом 384 мира, собственный linear+mipmaps/clamp CanvasTexture не меняет старые предметы.
- Общие геометрические ресурсы: одна основа 4 453 вершины и тридцать шаблонов по 625 вершин. У каждого CanvasItem не больше 30 текущих вариантов соседства. Они обновляются только при изменении контактов грядки, удерживаются самим владельцем, освобождаются с ним. Нет накопления вариантов за время сессии, новых узлов, render targets, таймеров или геометрии на неизменном кадре. Первый прогрев создаёт геометрию один раз; его стоимость ещё не принимается как бюджет VPERF.
- Соседи с одинаковым поливом закрывают внутренние края. Разные состояния и внешняя граница сохраняют мягкий переход. Флаг `WorldBackground.set_soft_garden(false)` возвращает прежние основу, клетки и капли без миграции слотов; обновляет только графический кеш первой карты.

## Фактическая приёмка

Основание Git `06cb4aa218c521d41d36ee98932d131bef4e6d2c`; версия 0.0.286, точные архивы исходников и артефактов в [native/source.json](native/source.json). Принята серия C: 70 PNG / 242 полных наблюдения настоящего production draw, окна 1152×648 и 1280×720, логический кадр 1152×648, zoom 1.2. Симуляция остановлена, фокус/размер/readback проверены в каждом случае.

Четыре календарных сезона, дождь, оба края огорода, три дорожных соединения, оба моста, настоящий вход и выход дома; смешанные состояния земли, пять стадий прежних растений, герой и настоящие предметы. Полные snapshots, геометрия, очередь и HUD не меняются от рисунка. Интерьер и три дорожных контрольных кадра совпадают точно. Холодный первый кадр равен прямому эталону. Прямой и тёплый кеш имеют прежние различия семплирования; они не объявлены равными.

На GPU-листе без растений сухая земля имеет яркость 88,07, влажная 50,88 (отношение 0,578). Общая альфа точна после смены цвета, в сечении 11 уровней, максимальный шаг 48/255. Кеш, счётчики и удержанные ресурсы неизменны за 120 callbacks. Draw calls в этих статичных кадрах 268→232 и 269→233; это не вывод об FPS или памяти.

[Профиль](review.txt): 32 / 0; полный цикл сельского хозяйства с обоими флагами, 1 200 проверок земли и восемь движений у мостов. `tools/test_garden_soil.py`: 12 тестов метаданных, отрицательных состояний и настоящих пиксельных контролей. Общий `TESTING.md`, полный игровой набор и Wiki check выполняются перед commit/push. Браузерная проверка записывается отдельно фактическим результатом.

## Отклонённые варианты

[Диагональные борозды](rejected/diagonal-furrows.png) не приняты после двух генераций; выбран ненаправленный материал, направления задаёт код. [Светлая сетка серии A](rejected/bright-grid.png) отклонена визуально, хотя числовой контроль проходил. Серия B обнаружила освобождение мешей, ещё видимых другому CanvasItem: [лог ошибки](rejected/shared-mesh-error.txt). Исправлено владение ресурсом, сборщик теперь дополнительно отклоняет любые ERROR движка. Только свежая серия C без таких ошибок принята; неуспешные серии не используются как доказательство готовности.

## Воспроизведение и границы

`python3 tools/garden_collect.py --output <новый каталог>` запускает два отдельных QA-профиля на настоящем дисплее. `--static-coexistence` разрешает только замороженный рисунок при явно записанном уже открытом Godot; другие процессы не закрывает и не является измерительным режимом. `python3 tools/garden_verify.py --output <каталог>` проверяет базу, точные архивы и SHA всех файлов. Обычный вызов проверяет сохранённую серию и наличие её файлов в Git index. Профиль: `Godot --headless --path . --script res://tools/garden_review.gd` в отдельном пользовательском каталоге.

Перенос визуального флага не меняет save schema и не активирует механику вне фермы. Новые культуры, рецепты, животные, станки, другие карты и новые интерьеры не входят в эту работу. Снег, новые берега, VPERF и итог первой карты VMAP-003 открыты. GPU timer null; Image-данные не RSS/VRAM. Принятый пилот не завершает графику всей карты.

# VFOLIAGE-006: объединение отрисовки после физики

В 0.0.330 центральный redraw переносится после физического catch-up. Каждый завершённый физический шаг ставит transient pending-флаг; `_process` объединяет его с прежним изменением интерполированной позы и запрашивает актуальную картинку. В `GameLoop` удалены девять отдельных `queue_redraw()`; остальное тело побайтно прежнее. Частота physics60/max8, порядок симуляции, интерполяция, F10, pacing, игровые ресурсы и сохранения не меняются.

## Функциональная и нативная проверка

Actual main в normal/F10 при искусственном cap10 и physics60/max8 проверяет world, pause, inventory, editor и resumed: один draw на устойчивых кадрах после catch-up, сохранённые физические delta, последнее UI и правильное течение/остановку времени. Все переходные кадры сохранены; первые два исключены только из устойчивых функциональных утверждений, не из FPS. На before оба контроля дали66 успешных/24 ошибочных условия; все ошибки — множественный draw. На after headless оба90/0.

Первоначальный native normal завершился без summary, а F10 получил100/0 CPU/nonempty условий при четырёх одинаковых устаревших pause PNG. Такая проверка была **отклонена**, все файлы сохранены. В [erratum](controls/native-freshness-erratum/focus-check.json) введены bounded ожидание `frame_post_draw`, счётчик `Engine.get_frames_drawn()` и уникальная полоса фазы в той же CanvasItem-команде после настоящего `_draw`. Обычный CLI и последующий bundle-запуск сохранили отсутствие новых present: окно видно, focus=false, counters=2. Это отдельное наблюдение о захвате, не объяснение всех прежних FPS.

Один заранее ограниченный normal/F10 контроль с QA-only `root.grab_focus()` на старте и перед захватом дал **105/0 в обоих режимах**. Во всех десяти PNG3584×2016 реальные present-счётчики продвинулись минимум на два, фокус/видимость=true и пиксельный маркер соответствует текущей фазе. Все десять изображений просмотрены: действительные пауза, рюкзак и редактор; world/resumed показывают мир/HUD со стартовым баннером, F10 сохраняется. Это проверка свежести, без физического ввода и без измерения50FPS. [Результаты и SHA изображений](controls/native-focus-visual-review.json).

Пользовательский временный запрет остановил собственный hook до запуска основной серии. После явного снятия запрета выполнены все18 случаев. История ограничения и прежний незавершённый checkpoint сохранены в controls; действующего запрета нет. Ни один отказ не удалён и основная FPS-серия не повторялась ради подбора успеха.

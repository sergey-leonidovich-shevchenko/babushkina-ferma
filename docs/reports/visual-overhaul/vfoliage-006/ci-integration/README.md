## Открытая локальная performance-диагностика

Исходный gate на F10 вернул средний FPS0 из-за отсутствия строк `Project FPS`, а не измеренного нулевого FPS. Повтор точной команды завершился кодом0 и не записал ни одного sample. `RenderPacingSystem.apply()` сбрасывает Engine.max_fps0 после CLI --max-fps60. Это объясняет возможность завершить короткий headless frame-limit до секундной выборки; runtime в этом изменении не исправлялся.

Отдельный временный QA-прототип восстанавливает cap60 после `super._ready()` на той же сцене и выделенном профиле. Samples появляются, но F10 этого опыта ниже прежнего порога50, поэтому опыт не принят за успешный gate и не подключён. Это не аппаратный/FPS-допуск. `performance-diagnostic/` сохраняет исходный отказ, точный сырой повтор, прототип/его данные и SHA. Пороги, performance_gate.sh, игровые scripts/assets не менялись. Находка передана Tech Lead для очереди Team Lead; локальный performance не заявляется зелёным. Новый CI и окончательное ревью обязательны.

# P2: ANSI и отступы перед ошибкой движка

Полное ревью60b3f882 вернуло [P2 events()](https://github.com/sergey-leonidovich-shevchenko/babushkina-ferma/pull/1#discussion_r4359311645). Цветная или отступная ERROR при exit0 могла пройти вместе с настоящим положительным trace. Экспорт, HUD, historical import fallback и прежние замечания полным ревью закрыты; эта доработка их не меняет.

В отдельном QA-изменении events() удаляет ANSI CSI/OSC и начальные пробелы только из копии текста для поиска ERROR/SCRIPT ERROR/Parse Error. Исходный raw, его SHA и строки JSON-протокола не нормализуются. Незавершённый OSC не может поглотить следующую строку ошибки. Нулевой exit status не перекрывает обнаруженную ошибку.

`tools/test_performance_gate.py` теперь содержит34 сценария: прежние28 сохранены, добавлены цветная ERROR, отступная ERROR, сочетания ANSI/CR/табуляции/старых видов ошибок, незавершённый OSC, строгий парсер ненормализованных protocol-строк, положительный цветной INFO и проверка driver: raw bytes/SHA неизменны, valid/budget_passed=false, average_fps=null при engine_error. Порча касается копий настоящего fixture.

`controls.json` и два входа сохраняют адресное воспроизведение: код60b3f882 принимал оба входа при55,5; исправленный код отвергает их как engine_error. Все24 случая двух прошлых полных серий повторно пересчитаны без изменения raw/SHA/result: они по-прежнему валидны, девять head-случаев ниже50. Ни один медленный опыт не исключён. Старый план, бюджет50, sampler, production, фикстуры и архивы не меняются.

Это только исправление обнаружения ошибок, не приёмка локального FPS. Следующий этап P1 требует отдельного заранее записанного плана причин разброса и совместного сбора frame-time/CPU/wall/стеков/own-process/focus/pacing. До этой серии собственные локальные QA-прогоны должны закончиться. Полные проверки текущего QA-коммита записываются после их фактического завершения; карточка in_progress, PR draft, main не сливать.

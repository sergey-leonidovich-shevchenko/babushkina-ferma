# VFOLIAGE-006 — воспроизводимый CI и точность длительностей

Новый GitHub run [39886206138](https://github.com/sergey-leonidovich-shevchenko/babushkina-ferma/actions/runs/39886206138) успешно получил полную историю и прошлые Git-базы, но job [120194860959](https://github.com/sergey-leonidovich-shevchenko/babushkina-ferma/actions/runs/39886206138/job/120194860959) остановился в `PerfContractTests.test_native_summary_reproducible`: побайтное сравнение вычисленной и сохранённой сводки отвергло последние разряды семи суммарных длительностей.

Ошибка отдельно воспроизведена на локальном Python 3.12.14; Python 3.9 воспроизводит прежнюю сводку точно. У Python 3.12 [изменён алгоритм суммирования float](https://docs.python.org/3.12/library/functions.html#sum). Максимальная измеренная разница — 4,092726157978177e-12 секунды на почти десятиминутном прогоне. Это не ускорение игры и не новые измерения.

Изменён только тест сравнения сводки. Он округляет восемь полей `runs/<id>/seconds` и `runs/<id>/render/seconds` до девяти десятичных знаков, то есть до наносекунды. Реальные часы записаны с микросекундной точностью. Все остальные поля сравниваются точно, исходные архивы/хеши по-прежнему проверяет неизменённый `perf_contract.verify`, а реальные пороги и решения приёмки не менялись.

Добавлены восемь регрессий: принимает только шум суммы; отвергает изменение на наносекунду и микросекунду, даже малую смену p95, один байт памяти, флаг принятия, пропажу секции и нечисловую длительность. Полный профиль содержит 45 тестов и проходит на Python 3.9 и 3.12. Полный пробный gate Python 3.12 отклонил ещё одну прежнюю точную сводку — VRENDER-002 grass_methods. Это сохранено в `python312-architecture-rejected.txt`; поддержка всего архива на 3.12 не объявляется.

Для общего CI фиксируются Python 3.11 через actions/setup-python и Pillow 11.3.0. Python 3.11 ещё [поддерживается до октября 2027](https://devguide.python.org/versions/). [setup-python рекомендует задавать версию явно](https://github.com/actions/setup-python). Итоговая локальная проверка использует отдельное окружение Python 3.11.17; системный Python не изменён. Старые архивы и строгий валидатор травы остаются неизменными.

Это отдельное адресное исправление блокировки CI в том же PR. Runtime, шейдеры, арт и предыдущая нативная серия не меняются; новая версия ветки — 0.0.318, версия нативного архива остаётся 0.0.317. После commit/push ревьюеру передаётся новый итоговый SHA. PR остаётся draft до успешных обязательных проверок; задача не влита в main.

Проба Pillow 12.3.0 также отвергнута строгой производной PNG лавочки: декодированные RGBA трёх видов совпадают побайтно, отличается только кодирование. Это зафиксировано в `pillow123-rejection.json` и `python311-pillow123-rejected.txt`. Pillow 11.3.0 повторяет принятые байты; ресурсы не пересобирались.

# Чистое окружение Linux: тестовые пути и диагностика

Run [39898154836](https://github.com/sergey-leonidovich-shevchenko/babushkina-ferma/actions/runs/39898154836), head `08b028c33b8f1bbc2d8d7db87b2b8e317ecb835c`: импорт, architecture и Wiki прошли. Игровой suite выявил macOS-пути `/private/tmp` в десяти тестовых файлах; на Linux каталога нет. Тестовые файлы теперь используют `OS.get_temp_dir().path_join(...)`, сохраняя уникальные имена, настоящую запись, все fault-injection стадии, проверки резервов и очистку.

Метод системного временного каталога описан в [официальной документации Godot](https://docs.godotengine.org/en/stable/classes/class_os.html#class-os-method-get-temp-dir). Изменения относятся к фикстурам, а не к игровому пути сохранения.

В том же run не совпали четыре подготовленных превью и проектный UI-аудит. Проверки дополнены диагностикой SHA, количества/амплитуды отличающихся байтов и конкретных UI issues. Требование точного RGBA и нулевого количества нарушений сохранено; допуска/пропуска по платформе нет. До исправления причин свежий CI и независимое ревью остаются обязательными. Это промежуточная диагностика, не приёмка задачи.


Локальный отдельный процесс с временным исключением доступного Arial воспроизвёл одно нарушение `locale.hud.ru.tutorial_fertilizer`; с обычным Arial нарушений нет. Файлы шрифтов/настройки игры не менялись. Выбор отсутствующего на macOS семейства включает доступный fallback и **не** принимается за точное измерение семейства Linux; краткий вывод — `font-probe.txt`.

В [реализации Lanczos Godot 4.7.1](https://github.com/godotengine/godot/blob/4.7.1-stable/core/io/image.cpp) используются float-коэффициенты и системная тригонометрия. Это возможная причина платформенного расхождения, пока не вывод: требуется диагностика источников и фактической разницы RGBA на Linux. Допуск не добавлен.

`mac-previews.json` содержит контроль четырёх исходников: SHA совпадают с паспортом, повторный прямой экспорт даёт 0 отличающихся RGBA-байтов. Текст стенда сохранён в `item-probe.gd.txt`; это диагностика, а не замена игрового suite.


В test job добавлен штатный Ubuntu-пакет [fonts-liberation](https://packages.ubuntu.com/noble/fonts-liberation), предоставляющий свободные шрифты с метриками Arial, который стоит первым в игровом SystemFont. Это зависимость окружения; игровые семейства, размеры и границы UI не подменяются. Реальный результат подбора fontconfig и UI-аудита подтверждается только свежим Linux CI.

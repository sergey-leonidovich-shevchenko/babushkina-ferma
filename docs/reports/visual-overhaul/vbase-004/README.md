## Условия и границы

Preset `village-static-noon-1152-v1` использует точку `overworld-entry-v1` из [VBASE-003](../vbase-003/camera-points.json). Герой `[432,672]`, фактическая камера `[0,348]`, направление вниз, день 1, 12:00, весна, ясно, seed `20261015`. Нативное окно, корневой viewport и PNG — 1152×648; масштаб 1, OpenGL Compatibility, VSync, русский язык, стандартный размер текста, reduced motion. Съёмка выполнена на AMD Radeon Pro 5300M, Godot 4.7.1.

Симуляция и игровой ввод остановлены стендом. Реальные GPU-перерисовки продолжаются: каждая временная пара разделена как минимум 2500 мс и 12 кадрами, на практике кадров больше. В каждую перерисовку проверяются реальные размеры и фокус; любой промежуточный отказ сохраняется в паспорте. Сохранения игрока не используются: отдельные процессы и новые профили `Codex-VBASE-004-*`.

Исходный commit — `39c3b42643e1ddbca332d56b78b48fb930cb95ba`. Добавленные в этой задаче инструменты и runtime на момент съёмки находились в рабочем дереве: паспорт содержит SHA256 **каждого игрового GDScript**, сцены, проекта и инструментов, а также точные команды. Последующее изменение документации, тестов и автоматический patch-bump не меняют снятый мир.

Режим `VisualReferenceMode` временно отключает водные пузырьки/рыб и рыболовные наложения, колебание и пульсацию декоративных растений, погодные детали фруктовых деревьев, атмосферный проход и боевые визуальные отклики. Кувшинки, камыши, деревья, вода, здания и геометрия остаются настоящими игровыми объектами. Статический материал воды и тени, уже нарисованные внутри ассетов, сохраняются. Отдельно нарисованный фон или монтаж вместо игры не применялись.

В режиме без HUD скрыты экранные панели и мировая подпись бабушки. Камера и масштаб не пересчитываются. Этот профиль проверен для закреплённого дневного участка деревни со свежим состоянием, а не для произвольной битвы, погоды или всех 30 карт. Он не является общим менеджером паузы/визуального времени. В обычном запуске метаданных режима нет, прежние эффекты включены; настройки и формат сохранений не изменены.

## Приёмка

Каждый запуск содержит девять framebuffer-снимков:

| Кадры | Проверка |
|---|---|
| `effects-0/1` | Обычные эффекты действительно меняют изображение через 2,5 секунды |
| `hud-0/1` | Эффекты выключены, HUD виден; пиксели совпадают |
| `clean-0/1` | Эффекты выключены, HUD скрыт; пиксели совпадают |
| `hud-restored` | Возврат HUD полностью воспроизводит `hud-0` |
| `restored-0/1` | После выключения эталонного режима эффекты снова движутся |

Сравнение выполняется по декодированным RGB-пикселям, не по заявленному флагу успеха. `hud-0` и `clean-0` совпадают между независимыми запусками. При скрытии HUD пиксели мира вне трёх закреплённых областей не изменяются: верхняя полоса `[0,0,1152,140]`, нижняя `[0,560,1152,88]`, подпись бабушки `[518,316,69,27]`. Маски нельзя автоматически растянуть до всего экрана ради зелёной проверки. Для временных и межпроцессных пар маски вообще не применяются: проверяется весь кадр.

Оба варианта просмотрены визуально: герой, NPC, дом, мост, деревья и грядки сохраняют исходные положения и масштаб, чистый кадр не содержит HUD и подписи. Старая пиксельная графика специально сохранена как исходный материал сравнения; её художественная приёмка не заявляется.

Профильный модельный набор: **89 passed, 0 failed**. `VisualStaticSuite` проверяет временность режима, отсутствие изменений сериализуемого состояния/камеры, восстановление, область действия и неподвижность растений при сохранении обычной формулы движения. В тестовой фикстуре перед контрольным снимком выполняется проверка проходимости: она лениво инициализирует реестр оград. Это подготовка теста, не изменение gameplay ради прохождения проверки.

10 Python-сценариев проверяют настоящую серию и отказы при сдвиге сцены, изменении размеров/фокуса, неполном наборе кадров, отсутствии прошедшего времени/перерисовок, движущемся пикселе, изменении мира при скрытии HUD, подмене масок, неработающем контрольном эффекте, headless и ложном допуске FPS. Полный игровой набор включает `VisualStaticSuite`; architecture gate включает Python-проверки. Перед публикацией действуют обязательные проверки [TESTING.md](../../../../TESTING.md).

**Это не замер производительности:** `simulation_frozen: true`, `performance_eligible: false`, отдельный тип `static-village-effects-off`. Анализатор живого baseline отклоняет этот паспорт. OPT-01 и общий визуальный эпик остаются открытыми.

## Повторение и откат

Нужны Python 3 с Pillow (`python3 -m pip install Pillow`, в Linux CI — пакет `python3-pil`) и нативное окно Godot. Не переключать фокус во время съёмки. Выходной каталог должен быть новым; неуспешные результаты сохраняются.

```sh
python3 tools/visual_static.py capture --output /private/tmp/farm-static-new
python3 tools/visual_static.py verify --output /private/tmp/farm-static-new
python3 tools/test_visual_static.py
```

Для проверки сохранённого репозиторного эталона достаточно `python3 tools/visual_static.py verify`. PNG и журналы находятся под `.gdignore`, не импортируются в игру. Новая версия точки камеры, UI-геометрии или источников требует осознанного пересмотра и повторной съёмки, а не автоматической перезаписи ожиданий.

Откат — отдельный revert коммита VBASE-004. Режим включается только стендом; удаления метаданных достаточно для возврата обычной отрисовки, миграции сохранений нет.

Следующий шаг — **VART-001**, два модульных варианта живописного оформления одного участка с той же камерой. Макеты сохраняются отдельно от игровых ресурсов; перенос начинается после выбора пользователя.

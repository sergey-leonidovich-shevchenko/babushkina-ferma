Одинаковый маршрут

Герой проходит от (556.25, 672.25) до (627.5, 672.25) с настоящими коллизиями. Камера пересекает границу слежения: X от 0 до 52. Измеренный pivot стоп совпадает с физической позицией; оконный ввод после преобразования Godot выбирает ожидаемую мировую клетку.

Godot 4.7.1 · AMD Radeon Pro 5300M · OpenGL compatibility. Ролики сжаты без изменения размера; браузер вписывает их в карточки. Мир остановлен, продвигается управляемый шаг героя. Указатель синтетический. 24 fps — шкала записи; это не замер производительности и не проверка физической мыши.

# VGROUND-002 — крупные цветовые пятна земли

Задача добавляет крупные спокойные цветовые пятна только в первую карту `overworld`. Поле вычисляется детерминированно в вершинах уже существующей удерживаемой mesh-сетки: на карте остаётся одна поверхность, без узлов, таймеров и `_process` на клетку. Текстура травы, UV, дороги, берега, навигация, вспашка и сохранения не меняются.

Шесть профилей тёплой усадьбы, рынка, лекарственного сада, прохладной речной травы, рабочего двора и сада остаются сравнительными образцами изолированного QA-стенда для будущих задач. Production использует только профиль `warm_valley`; пять отдельных `village_*` карт сохраняют прежний материал. Два низкочастотных поля смешиваются плавной интерполяцией; поэтому границы не проходят «под линейку». Четыре сезонных тона умножаются поверх того же стабильного поля.

Rollback: `WorldBackground.set_ground_color_patches(false)` выбирает нейтральные белые цвета вершин и пересобирает только графический кеш земли. Схема сохранения и игровой чертёж не меняются.

Девять готовых дорожных/площадных масок пересобраны штатными офлайн-компиляторами только для актуализации `source_sha256` после изменения двух входных файлов. Проверка свежей компиляции подтверждает 36/36: `mask_spec`, geometry, UV и colours побайтно совпадают с прежними ресурсами; frozen-отчёты не переписывались.

## Проверка

- `Godot --headless --path . --script res://tools/qa/ground/color_patch_review.gd` — профильные утверждения детерминизма, биомов, плавности, общего края, кеша, сезонов, 1 200 точек навигации/вспашки и полного save snapshot;
- `python3 tools/run.py qa.ground.test_compiled_sources` — 101 проверка provenance/tampering и 36 проверок свежих byte-equal масок;
- `python3 tools/run.py qa.ground.color_patch_collect --output <свежий каталог>` — два последовательных нативных окна 1152×648 и 1280×720 в новых профилях;
- `python3 tools/run.py qa.ground.color_patch_verify --output <каталог>` — одинаковые камера/поза/состояние до/после, четыре сезона, шесть биомов, прямой участок, T-стык, поворот, тупик и угол;
- общий `TESTING.md`, точный head CI и независимое ревью обязательны.

Удалённый exact-head workflow явно извлекает PR head и обязан сформировать 66 PNG и 240 полных снимков draw-trace в окнах 1152×648 и 1280×720: по четыре повторных прохода на каждое статическое состояние. Пять отдельных `village_*` карт должны попиксельно сохранить прежний материал при обоих значениях флага и совпасть между cached/direct путями; шесть будущих биомных профилей остаются на изолированном стенде, а production-изменение ограничено первой `overworld`. До загрузки принятого CI-артефакта пакет считается ожидающим проверку. `source.json` связывает каждый вход с Git blob проверяемого head, само дерево и каждый артефакт; локальный overlay считается только preflight. Захват получает настоящий код завершения первого процесса и убирает его до второго окна, останавливает симуляцию перед парами и не делает FPS-утверждений.

Первый локальный preflight до замечаний ревью подтвердил 46 PNG / 160 полных draw-trace и помог проверить художественное направление, но больше не является приёмочным пакетом текущего протокола. Повторный локальный preflight текущего кандидата подтвердил 66 PNG / 240 draw-trace, попиксельную сохранность пяти отдельных карт при обоих значениях флага, совпадение cached/direct и различимость шести стендовых профилей. Этот результат не подменяет повторный захват и performance gate точного опубликованного head в CI.

Локальный шестиоконный performance gate кандида также прошёл без прогрева и исключений: normal 58,8–59,9 FPS, F10 59,4–59,9 FPS, минимум 50 FPS во всех шести окнах. Это локальный preflight, а не замена exact-head CI.

Нативные кадры являются визуальной проверкой, а не FPS-допуском. `performance-investigation.json` отдельно сохраняет входящий разбор среды: принятый удалённый head прошёл шесть случаев с 60 FPS, а последующая локальная деградация воспроизвелась и на чистом base. Её нельзя приписать этому визуальному изменению. Обязательный performance gate точного head сохраняет прежний план, шесть запусков и бюджет 50 FPS без исключений, прогрева и waiver.

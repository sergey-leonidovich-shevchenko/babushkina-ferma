# VCOMPAT-010 — обратимый визуальный профиль

Задача в работе. Сравнительная база — принятая `main` `820b73b2ed59ce78639e87100bffe5d7b88274f9` (0.0.481); она закреплена для воспроизведения неработающего общего флага. Рабочая ветка дополнительно синхронизирована с принятой `main` `0effa1d3ecec8a28cade61c49a5a0ca4eb172005` (0.0.484), включая постановку RAIN из PR №86 и её принятый учёт PR №87. Полная цепочка VCOMPAT-001 → VRENDER-001 → VBASE-001 принята. До независимой приёмки текущего head задача остаётся `in_progress`.

В исходной версии есть адресные флаги грунта, воды, света, травы и объектного прохода. Общий флаг визуальной версии отсутствует: отключение узкого `pilot_object_pass_enabled` не возвращает грунт, предметы или освещение. Удаление отдельного композиционного стенда VRELEASE-002 также не является откатом обычной игры.

## Граница отката

Общий флаг `rendering/visual_overhaul/enabled` выбирает представление первой `overworld`. Его значение по умолчанию — `true`; временный флаг конкретного игрового владельца `visual_overhaul_enabled` позволяет проверять два независимых viewport. В JSON сохранения, пользовательский конфиг и опубликованные уровни этот флаг не записывается.

Запасной профиль использует сохранённые прежние пути и ресурсы поверх **текущих игровых данных**. Он не откатывает версию приложения, геометрию карты, коллизии, календарь или правила игры. Предметы и проходы не исчезают при отключении новой графики. Отдельные настройки компонентов сохраняются и восстанавливаются при возврате; скрытие всех эффектов диагностическим режимом съёмки не подменяет эту проверку.

## Проверки до приёмки

- Настоящие PNG обычной игры с одинаковыми камерой, вводом и seed; новая графика → запасная → новая, два окна и независимые viewport.
- Профильные SAFE/FARM/WORLD, копии старого JSON и настоящие чтение/запись пользовательского уровня в отдельном userdata; игровые поля и исходные файлы сохраняются.
- Отрицательные сценарии: неработающий общий флаг в базе, повреждённые настройки/доказательства, потерянные кадры, подмена исходников и чужой владелец.
- Полный штатный hook, post-bump Wiki, CI, независимое ревью точного head и решение Team Lead.

Нативная игра запускается только в CI/на удалённом стенде. Новые механики, карты, интерьеры, дождевой арт, снег, FPS и VMAP-003 этой карточкой не принимаются. Принятые определения, статусы и зависимости RAIN сохраняются.

## Текущий результат проверок

Профиль сохранений, редактора и переключателя выполнил 206 проверок без отказов. После исправления старой проверки форматирования реальный объединённый прогон оград и отката прошёл 271/0; он проверяет погодные правила, включая прежний зимний приоритет, вместо поиска пробелов в исходнике. Геометрия существующих погодных деталей сохранена. Строгая компиляция исправленных файлов прошла на свежей отдельной копии.

Python-проверки контракта и reader — 5 и 10 соответственно. Инвентарь Git теперь включает все `assets` и старые JSON, используемые при проверке. Настоящие данные из Git проходят экспорт, а изменение временной копии отклоняется; оригиналы не меняются. Тот же тест на точных сохранённых старых байтах контракта воспроизводит два отказа: слот и ресурс вне `assets/game` прежде не были учтены. [Результаты и SHA старого источника](failures/input-closure/regression.json) — тестовые доказательства, не нативные кадры.

Два полных hook пока завершились отказом. Первый прошёл quality 246/0, затем остановился на отсутствии Git templates у выбранного bundled Git; тот же серверный сценарий прошёл 16/0 с установленным системным Git. Повторный hook прошёл quality 246/0 и architecture 129 групп/1695 тестов, но Game дал 53964/1 из-за старого сравнения форматирования ограды. В обоих случаях пользовательские файлы сохранялись, собственный override удалён, коммит не создан; normal/F10 не достигнуты. Эти результаты не подменяют новый полный прогон исправленных исходников.

После исправлений отдельный штатный `run_tests.sh` прошёл Game 53968/0 и normal/F10 по 90/0. Он выполнен в новом подтверждённом userdata с отдельными каталогами redraw; обычные файлы не изменились, собственный override удалён. Новый полный commit-hook с quality и architecture ещё обязателен перед публикацией.

Следующий полный hook прошёл quality 247/0, затем остановился на лимите размера отформатированного `fence_building_suite`: 406 исполняемых строк при лимите 350. Лимит сохранён: атлас и погодные проверки выделены в `fence_visual_suite`, родитель вызывает их в прежнем порядке. Три затронутых файла прошли свежую строгую компиляцию, исходный префикс проверки размеров прошёл без исключений, тот же объединённый fence/rollback-прогон вновь дал 271/0. Новый полный hook ещё требуется; результаты до разделения не выдаются за проверку нового кандидата.

Wiki на принятой базе 0.0.484 повторно собрана и проверена в подтверждённом отдельном userdata: TypeScript/build и 167 тестов прошли, обычный каталог игры остался побайтно прежним. Настоящий браузер подтвердил RAIN-00 `done`, текущую VCOMPAT-010 `in_progress`, прежний прогресс 84/93, поиск и отсутствие переполнения при 1280/390 px. Эта проверка до bump не заменяет post-bump Wiki.

Первый вызов Wiki был ошибочно запущен без startup override. Проверка сохранности вернула отказ: headless-импорт ротировал два файла обычного журнала, остальные файлы прогресса и настроек не изменились. Отказ сохранён отдельно, журналы не восстанавливались; успешный изолированный повтор не переписывает этот результат.

136 полных PNG в двух физических окнах — пока матрица будущего удалённого прогона, не готовые доказательства. Синтетические PNG тестов проверяют только reader. До получения исходного CI-архива, проверки его Git-входов и самостоятельного просмотра кадров нативная приёмка остаётся открытой.

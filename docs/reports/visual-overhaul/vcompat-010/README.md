## Граница отката

Общий флаг `rendering/visual_overhaul/enabled` выбирает представление первой `overworld`. Его значение по умолчанию — `true`; временный флаг конкретного игрового владельца `visual_overhaul_enabled` позволяет проверять два независимых viewport. В JSON сохранения, пользовательский конфиг и опубликованные уровни этот флаг не записывается.

Запасной профиль использует сохранённые прежние пути и ресурсы поверх **текущих игровых данных**. Он не откатывает версию приложения, геометрию карты, коллизии, календарь или правила игры. Предметы и проходы не исчезают при отключении новой графики. Отдельные настройки компонентов сохраняются и восстанавливаются при возврате; скрытие всех эффектов диагностическим режимом съёмки не подменяет эту проверку.

## Проверки до приёмки

- Настоящие PNG обычной игры с одинаковыми камерой, вводом и seed; новая графика → запасная → новая, два окна и независимые viewport.

- Отрицательные сценарии: неработающий общий флаг в базе, повреждённые настройки/доказательства, потерянные кадры, подмена исходников и чужой владелец.
- Полный штатный hook, post-bump Wiki, CI, независимое ревью точного head и решение Team Lead.

Нативная игра запускается только в CI/на удалённом стенде. Новые механики, карты, интерьеры, дождевой арт, снег, FPS и VMAP-003 этой карточкой не принимаются. Принятые определения, статусы и зависимости RAIN сохраняются.

## История проверок до успешной второй нативной серии

Профиль сохранений, редактора и переключателя выполнил 206 проверок без отказов. Геометрия существующих погодных деталей сохранена. Строгая компиляция исправленных файлов прошла на свежей отдельной копии.

Настоящие данные из Git проходят экспорт, а изменение временной копии отклоняется; оригиналы не меняются. Тот же тест на точных сохранённых старых байтах контракта воспроизводит два отказа: слот и ресурс вне `assets/game` прежде не были учтены.

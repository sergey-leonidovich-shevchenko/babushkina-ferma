## Контракт

Для `d=(видимая_стопа−корень)/36` реакция `−8d(1−dot(d,d))²` внутри единичного диска, снаружи ноль. Нормализации нет. Центр имеет точное нулевое воздействие, края — нулевую производную; функция гладко проходит через корень со сменой стороны. Максимальная длина8×16/(25√5)≈2,29, вместе с ветром1,35 меньше3,65. Вес прежней сетки сохраняет корневые ряды неподвижными. Существующие PAD12/AABB9 покрывают этот изгиб.

`FoliageContact` читает неизменяемый PostMotionFrame после фактического движения и PresentationPose.ground. В GameCore._process подготовка Wind перенесена после PresentationPose.present. Так контакт не опережает изображение героя между тактами; ввод направления и желаемая скорость не используются. При невалидном кадре или переносе воздействие очищается. Пауза при валидной позиции держит прежний буфер. Разная сила от шага и бега принадлежит VFOLIAGE-005, мягкое восстановление после выхода — VFOLIAGE-006; временная интеграция и пружина здесь не добавлены.

На два прежних материала передаётся общий PackedVector2Array64. INSTANCE_CUSTOM.y содержит только точный целый номер слота0…7; мировые координаты не теряют точность при half-float хранении. Изгибы вычисляются только для восьми исходных опор, остальные элементы нулевые. Геометрия неизменна, нет узла на пучок, чтения GPU или записей в сохранения. Uniform обновляется при изменении видимой стопы, даже при тех же физических часах. При неизменном буфере повторного upload нет. Offscreen/low очищают CPU-буфер и помечают GPU как dirty: возврат явно очищает старые контакты, включая тот же clock. Отдельный flag `foliage_contact_enabled` false/неверный оставляет ветер; общий wind flag/low/reduced/reference сохраняют stationary fallback.

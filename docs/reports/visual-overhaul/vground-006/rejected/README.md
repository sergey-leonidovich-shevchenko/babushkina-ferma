# Отклонённая земляная кромка A

Первый нативный вариант использовал старую тёмную почву DIRT под площадью. Получился слишком заметный коричневый ободок. Он отклонён художественным просмотром независимо от численных проверок. Материал камня сохранён; финальная серия C использует светлый материал PATH для земляной кромки и меньшую контактную альфу. В отчёте сохранён кадр A; временные исходные файлы впоследствии стали недоступны. A не является финальной приёмкой.

Кроме художественного отказа, второе окно A самопроизвольно получило размер 3584×2240 вместо 1280×720. Валидатор отклонил эту серию; строки и кадры не обрезались. Финальный коллектор явно задаёт размер при создании окна и проверяет его устойчивость до съёмки; каждое наблюдение по-прежнему проверяет физический размер.

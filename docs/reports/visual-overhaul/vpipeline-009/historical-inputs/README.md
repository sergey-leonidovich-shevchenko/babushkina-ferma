# Точный исторический import-компаньон

`fd5557669eaa3a93d0630eadc770588b89ea0975d265870e986fba6ae9e01a15.import` — исходные байты `assets/generated/level_drafts/water_navigation_ingame_preview.png.import`. Этот файл попал в `fixture-sources.json`, но не в Git commit `1621d49502cd244c1036168f9d235561b708b33a`. Его локальный оригинал совпадает с уже закреплённым SHA256.

Файл сохраняется отдельно как вход исторического доказательства. Старые `proof.json`, `fixture-sources.json`, кадры, UID и измерения не переподписывались. Валидатор сначала читает точный checkout/Git baseline, затем может взять только `.import` из этого каталога с тем же SHA. Для PNG и кода этот fallback запрещён. Новый UID текущего автоматического импорта не изменяет прошлые доказательства; повреждённый или утраченный оригинал остаётся ошибкой.

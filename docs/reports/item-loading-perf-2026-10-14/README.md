# Исходники предметов по запросу · OPT-03 · 14 октября 2026

База: `747225c`, версия0.0.171 с уже опубликованными оптимизациями хранилищ и обработки прозрачности. Этот пакет меняет только регистрацию/загрузку предметных изображений. Исходные рисунки, размеры экранных текстур, выбранные замены и цвета материалов сохранены.

## Поведение ресурсов

`initialize_item_icons` регистрирует пути вместо немедленной загрузки220 оригинальных PNG. Ещё165 записей обслуживаются прежними специализированными регистрами; их дальнейшее разделение остаётся отдельной работой. `item_texture` и `item_visual` сохраняют прежний результат для явных запросов оружия, Wiki и сборщиков.

`item_draw_visual` сверяет путь, провайдера и окраску по описанию с подготовленным каталогом. При точном совпадении возвращает прежний атлас миниатюр64px либо превью160px с пределом16. Несовпадающая выбранная замена использует прежний маршрут оригинала, поэтому интерфейс не показывает старую картинку или цвет вместо нового выбранного ресурса. Сброс регистрации очищает связанные описания и пакеты. Неизвестные ID не расширяют новый кеш описаний.

Проверка доступности не загружает весь каталог: для имеющегося кешированного объекта проверяется тип, для растров — зарегистрированный путь, для нестандартных ресурсов остаётся явная проверка. `ResourceLoader.exists` с type_hint сам по себе не доказывает фактический тип: отдельный тест не позволяет выдать Font за Texture2D.

## Открытие и прокрутка шкафа

Нативный `storage/metrics.json`: обычный игровой скрипт, без CPU-инструментации, по600 кадров на шкаф/прокрутку/сундук. Фокус и окно3584×2240 сохранялись. После просмотра всех385 видов осталось **0 загруженных PNG из220 отложенных путей**, исходных записей165. Это не перенос задержки на первое открытие полного каталога.

Одна диагностическая пара первых/повторных показов: шкаф38,71/32,55мс, сундук36,58/20,26мс. p95 кадров:13,87мс,15,12мс,15,40мс. Короткий прогон не заменяет длинную приёмку всей матрицы. Проверенный до этого длинный проход хранилищ сохранён в [предыдущем отчёте](../storage-perf-2026-10-14/README.md).

## Проверка сохранности

`LazyItemIconsSuite` проверяет все385 видов в обоих размерах без загрузки отложенных оригиналов, совпадение провайдеров/цветов с прежним полным источником, предел16, загрузку отдельного оригинала по запросу, выбранную нестандартную замену, сброс, неизвестный ID и неправильный тип ресурса. Существующие ItemIconContractSuite, StorageGridSuite и StorageActionsSuite также проходят; Wiki сохраняет полный экспорт настоящих исходников.

```sh
./tools/Godot.app/Contents/MacOS/Godot --headless --path . --script res://tools/lazy_item_icons_review.gd
tools/check_architecture.sh
./run_tests.sh
```

Для нативной проверки использованы `tools/startup_review.gd` и `tools/lazy_item_storage_perf.gd` с отдельными userdata. Слоты пользователя не открывались. После новых предметов/арта остаётся обязательной пересборка подготовленных UI-текстур и контракт их исходных отпечатков.

OPT-03 и OPT-11 остаются открытыми: остальные preload, плато памяти30мин/2ч, физический ввод, устройства и полный экспорт не объявляются выполненными этой итерацией.

# Хранилища: первая итерация OPT-02 / OPT-04 · 14 октября 2026

Исходная версия: `9ad6dee`, 0.0.169. Изменения ускоряют существующие шкаф и сундук: сетки, количества, центральная карточка, сортировка, переносы и ракурсы предметов сохраняются. Новый дизайн не вводился.

## Что исправлено

- Рамки, миниатюры общего атласа и числа отправляются отдельными пакетами. Соседние ячейки не пересекаются, поэтому перестановка этих независимых слоёв сохраняет рисунок.
- `StorageViewCache` хранит последний снимок каждого из двух окон. Повторный кадр, движение выбора и прокрутка не обходят весь инвентарь. Точное сравнение количеств, слотов, запаса, старых флагов оружия, языка, сортировки, вкладки и запроса обновляет снимок при изменении. Чтение не основано на потенциально коллидирующем хеше; прямая запись старого состояния и загрузка также обнаруживаются.
- Быстрые кнопки используют те же количества; фактический перенос по-прежнему проверяет живое состояние через прежние системы. Снимок не участвует в сохранениях и ограничен двумя окнами, не историей поисков.
- Непрозрачные хранилища больше не рисуют скрытый HUD и мир. Общий экранный проход сохраняет диагностику, подтверждения, уведомления и обратную связь поверх окна. Закрытие сразу возвращает обычную отрисовку; редактор, фоторежим и чистый захват мира сохраняют прежний маршрут.

## Измерение

Mac / Radeon Pro 5300M / Godot 4.7.1 / OpenGL Compatibility. Физическое окно 3584×2240, дизайн-холст с сохранением пропорций даёт кадр 3584×2016. VSync запрошен. Измеряется `frame_post_draw`, а не пустые process-циклы или headless FPS. Внешняя загрузка GPU и питание отдельным датчиком не контролируются.

`before/metrics.json` и `after/metrics.json`: по три повтора трёх сценариев, по600 отрисовок. Оба используют одинаковый CPU-профилировщик. Исходная версия запускается из отдельного checkout; рабочие исправления не переключались туда-обратно в каталоге пользователя.

`after-long/metrics.json`: обычный игровой скрипт без CPU-профилировщика, три повтора по3600 кадров каждого сценария. Первый и повторный показ окна записываются отдельно до прогрева хранилища; последующие кадровые серии прогреты. Исходные открытия без инструментации находятся в `before-openings/metrics.json`.

Каждая серия сохраняет сырые интервалы, первые показы, фокус и размер на каждом draw, паузу часов, кеши и память. В `summary.json` статистика пересчитывается из сырых интервалов; короткие и инструментированные серии отделены от квалифицированных. Соблюдение одного кадрового бюджета не закрывает весь эпик: нужны остальные окна, ввод, длительная память, устройства и полная матрица OPT.

### Изображения

Нативные кадры до/после сверяются по всем каналам RGB; при сравнении RGBA нельзя проверять только нулевую разность альфы. В контрольных изображениях очищено временное сообщение в нижней строке. Общая геометрия, миниатюры, выбор, количества и тексты должны совпасть. Ранние `*-probe` сохранены как сырые диагностические данные без дублирующих PNG. Итоговое сравнение трёх пар кадров — полное равенство RGB, см. `pixel-comparison.json`.

## Проверки и границы

`StorageViewCacheSuite` проверяет отсутствие повторного обхода на60 кадрах, изменение фокуса/прокрутки, перенос с сохранением суммы, прямую запись словарей, старые флаги оружия, язык/поиск/порядок, изоляцию игровых моделей, состояние быстрых кнопок, выход из окна и независимые области пакетных слоёв. Он подключён к общему набору через `StorageForgeSuite`.

Пять Python-тестов анализатора не допускают приёмку неполной, короткой, инструментированной, фоновой, незапаузенной или зависшей трассы. Проверки хранилищ и UI остаются в прежних наборах; процент line coverage не заявляется.

OPT-02 и OPT-04 остаются открытыми до всей приёмки. Старт, загрузка оригинальных текстур, F10, рюкзак и остальные окна не объявляются исправленными этой итерацией. Новые игровые правила не вводились, поэтому отдельный новый шаг обучения не требуется.

## Воспроизведение

```sh
./tools/Godot.app/Contents/MacOS/Godot --headless --path . --script res://tools/dev_cabinet_review.gd
python3 tools/test_storage_perf.py
python3 tools/analyze_storage_perf.py
tools/check_architecture.sh
./run_tests.sh
```

Нативный профиль (отдельные userdata, без слотов игрока):

```sh
./tools/Godot.app/Contents/MacOS/Godot --path . --script res://tools/storage_perf_review.gd -- --report-dir=res://docs/reports/storage-perf-2026-10-14/recheck --frames=3600 --repeats=3 --variants=full --uninstrumented
```

Для сопоставимой CPU-диагностики убрать `--uninstrumented` и выбрать600 кадров; `--variants=full,ui-only,flat-ui` добавляет контрольные варианты только в измерительном скрипте. Они не включены в production. Сохранённые ранние пробы показывают, почему одного удаления мира либо изменения радиуса рамок недостаточно.

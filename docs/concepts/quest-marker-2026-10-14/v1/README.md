# Маркер действия без круга

Нарисован встроенным `image_gen`: [мастер из шести фаз](exclamation-six-frames.png), [точный запрос](prompt.txt). Прозрачный PNG1254×1254, без круглой подложки, белой обводки и текстового символа из шрифта. Рисунок сохранён без изменения пикселей. Реальные области кадров и опоры точки измерены отдельно в [source.json](source.json); лист не делится на предполагаемые равные ячейки во время показа.

В [анимированном просмотре](preview.html) доступны два варианта:

- **Один знак:** компактный золотой символ высотой24px с мягким парением на2px.
- **Три знака:** основной символ24px и два боковых по16px, движение с небольшой задержкой.

Цикл длится1,8секунды. Шесть нарисованных фаз плавно смешиваются между собой; синусоидальное движение не округляется к целым пикселям. Опора нижней точки стабильна во всех кадрах. Смешивание выполняется в отдельном прозрачном слое с суммированием взвешенной альфы, поэтому между фазами нет лишнего потускнения. Кнопка приостанавливает и продолжает движение; системное уменьшение движения по умолчанию включает паузу. Встроенные настройки позволяют примерить высоту18–32px и цикл1,2–3секунды.

Это макет, а не кадр работающей игры: для масштаба использованы существующие предмет древесины и трава. Сейчас сюжетный круг над ремонтом переправы рисуется в [FirstChapterRenderer](../../../../scripts/systems/first_chapter_renderer.gd). Перенос выбранного рисунка в игровые ресурсы выполняется после выбора пользователя по [AGENTS.md](../../../../AGENTS.md).

Исходники просмотра: [шаблон](preview-fragment.template.html), [сборщик](build_preview.py), [переносимый фрагмент](preview-fragment.html). Сборщик встраивает исходные PNG без обработки изображения:

```sh
python3 docs/concepts/quest-marker-2026-10-14/v1/build_preview.py
```

`preview.html` — самостоятельная оболочка, сформированная стандартным renderer навыка visualize. Встроенный в беседу просмотр использует тот же фрагмент. До1МБ, без сетевых запросов и зависимостей от игрового слота.

Проверка в отдельном headless Chrome: оба варианта меняются во времени; пауза замораживает кадр; продолжение возобновляет движение; при ширине360px нет горизонтального выхода; уменьшение движения даёт статичный кадр. Ошибок выполнения браузера нет.

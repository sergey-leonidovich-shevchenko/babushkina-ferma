# Круглые игровые часы

Выбран деревянный вариант на 96 px: пользователь поручил самостоятельно решить оставшиеся вопросы. Рамка и долина взяты из [первого макета](../v1/README.md). Новый [исходный диск неба](sources/sky.png) не содержит светил; [метаданные генерации](generation.json) сохраняют точный запрос.

В игре три независимых прозрачных слоя 512×512, прогретые при запуске. Небо поворачивается за 1440 игровых минут; неподвижные холмы скрывают заходящие солнце и луну. Светила находятся на противоположных сторонах одной орбиты, освещение луны рассчитывается по 28-дневному циклу. При остановке игрового времени весь циферблат неподвижен. Цифрового времени нет; календарь размещён под кругом и проверяется на шести языках при масштабе текста 120%.

[Лист положений и лунных фаз](clock-strip.png) снят игровым рендером в Godot. Снимки физических форматов: [16:9, русский](16x9_ru.png), [16:10, немецкий](16x10_de.png), [широкий, китайский](ultrawide_zh.png). Это реальные кадры, без увеличения готового PNG. Рамка в сравнительном листе показана также крупнее для осмотра деталей.

Подготовка ресурсов: `Godot --headless --path . --script tools/prepare_celestial_dial.gd`, затем импорт через редактор. Захват: `Godot --path . --windowed --resolution 1152x648 --script docs/concepts/day-night-dial-2026-10/v2/capture.gd`. Исходные изображения сохраняются отдельно от игровых ресурсов.

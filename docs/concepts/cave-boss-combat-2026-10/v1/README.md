# Бой с Хранителем — реализация

Кадры сняты из `main.tscn` настоящим Godot renderer. Используется действующее святилище лабиринта; варианты A/B прежнего макета остаются отдельными концептами.

## Три стадии

У босса 120 HP. Стадия 2 начинается при **80 HP**, стадия 3 — при **40 HP**. Перед каждой атакой предупреждение 0,9–1,2 секунды; после — восстановление 1,1–1,6 секунды. Переход стадии отменяет текущий удар и летящие снаряды босса, даёт 2,2 секунды передышки. Уже появившаяся нежить остаётся действовать.

| Стадия | Атака | Как реагировать |
|---|---|---|
| 1 | Удар землёй | Выйти из круга вокруг босса |
| 1 | Веер осколков | Пройти между пятью снарядами или уйти за спину |
| 1 | Каменный рывок | Выйти из отмеченного коридора |
| 1 | Разлом | Уйти с линии четырёх последовательных взрывов |
| 2 | Обвал | Покинуть три заранее выбранные точки падения |
| 2 | Кристальный залп | Пройти между восемью радиальными снарядами |
| 2 | Широкий взмах | Уйти из переднего сектора 120° |
| 2 | Клетка кристаллов | Выйти через незакрытый сектор до появления шипов |
| 3 | Крест разломов | Перейти в один из четырёх безопасных секторов |
| 3 | Спиральный залп | Уклониться от трёх повёрнутых радиальных залпов |
| 3 | Тройной рывок | Последовательно покидать три объявленных коридора |
| 3 | Лунная волна | Остаться в центре кольца или пройти сквозь него рывком |

Наведение фиксируется при начале замаха. Рывки проверяют скалы, снаряды — весь пройденный отрезок. Общая защита на 0,65 секунды после попадания препятствует мгновенному урону всей толпой.

## Призывы и мухи

Первая волна готова через 12 секунд; после появления следующая — не раньше 20 секунд. Призыв ждёт окончания текущей атаки и имеет собственное предупреждение 1,2 секунды. Максимум **четыре живых существа**, включая появляющихся.

- Стадия 1: два скелета, которые выбираются из земли.
- Стадия 2: зомби из грязи и вампир, прилетающий летучей мышью.
- Стадия 3: смешанная волна скелета, зомби и вампира.

Появление длится 1,25 секунды; в это время существо не атакует и не получает урон. Затем действует обычный бой: оружие с перезарядкой и критами, магическая стрела, ледяная волна, напарники, блок и уклонение. За бесконечные волны не выдаётся повторная добыча или опыт.

Вокруг зомби летают три отдельных мухи. Раз в 6 секунд он может замахнуться и бросить одну муху: предупреждение 0,65 секунды, прямой полёт 215 пикселей/с без наведения, ограниченная дальность. При попадании муха цепляется на случайные **2–5 секунд** и наносит **1 HP за каждую полную секунду**. Повторное попадание не складывает и не продлевает эффект. Блок отражает бросок за 1 силу, рывок позволяет его избежать.

Рюкзак, журнал, вкладка героя, карта и пауза останавливают бой и укусы. Выход из святилища, поражение и загрузка убирают временные угрозы. Сохранение удерживает HP, позицию и победу босса; загрузка живого босса начинает новый читаемый замах с передышкой. Старые сохранения переносят процент HP прежнего стража.

Воспроизвести кадры:

```sh
tools/Godot.app/Contents/MacOS/Godot --path . --rendering-method gl_compatibility --script res://docs/concepts/cave-boss-combat-2026-10/v1/capture.gd
```

Поиграть в бой без прохождения лабиринта:

```sh
tools/Godot.app/Contents/MacOS/Godot --path . -- --cave-boss-preview
```

Режим выдаёт копьё и яблоки, убирает стартовые диалоги. Сам по себе не сохраняет игру; клавиши сохранения продолжают работать как обычно.

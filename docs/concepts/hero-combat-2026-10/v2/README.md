# Боковой выстрел: подготовка к экранному размеру

В двух поздних боковых фазах лука большой мастер прежде уменьшался до промежуточной текстуры, затем ещё раз при отрисовке. Мелкие штрихи попадали в нерегулярные пиксельные ступеньки. Теперь `tools/extract_hero_combat_sprites.gd` готовит эту пару сразу к размеру 79×93 и 86×92 с Lanczos из исходной связной фигуры. Runtime рисует их в масштабе 1, остальные кадры сохраняют прежнюю подготовку. Опора стоп математически совпадает с исходной; округление габаритов не превышает 0.5 px.

[Витрина после подготовки](frames.png) и [исходный вид](../v1/frames.png) сняты одним игровым renderer. [Лук в настоящей сцене](bow-ingame.png), [меч](blade-ingame.png), [копьё](spear-ingame.png). [Захват](capture.gd) не подменяет текстуры или рендер. Исходные мастера, направления, таймеры, урон и физические координаты не менялись. Художественные детали большого исходника сохранены отдельно в [v1](../v1/README.md).

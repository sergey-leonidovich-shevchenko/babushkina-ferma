# Действия героя

Шесть семейств по 16 целых фигур: кирка, топор, лейка, удочка, молот и посох. Ракурсы: вниз, влево, вправо, вверх. Фазы: стойка, замах, контакт/выпуск, возврат. Исходные изображения созданы встроенным imagegen по уже принятому облику героя. [Точные промпты](prompts.json), [исходники](sources/), [измерения](regions.json).

Изначальный молот имел переставленные боковые строки; порядок исправлен метаданными. Первый лист посоха имел повтор правого ракурса: сохранён как draft, использован исправленный источник. Фронтальная зарядка отдельно перерисована с полным свечением и запасом прозрачности. Все первоначальные исходники сохранены.

Измерения выполняются только чтением пикселей. Выбираются 16 крупных связных целых фигур, затем два ботинка каждой. Равномерная сетка не используется для обрезки: длинная удочка или свечение могут пересекать её границу. Изображения нарезает и уменьшает `res://tools/assets/authoring/prepare_hero_actions.gd`; прозрачный край добавляется после нарезки. В runtime загружаются только 96 малых независимых PNG с draw_scale=1.0. Масштаб тела измерен по первой стойке; отдельная фронтальная зарядка посоха приведена к той же высоте по макушке и ботинкам.

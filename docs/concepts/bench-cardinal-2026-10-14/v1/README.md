# Лавочка: четыре прямых ракурса

Два варианта перерисовки лавочки от14октября2026. Выбор пользователя ожидается; игровые ресурсы и расстановка лавочек пока не изменены.

- [А — округлые металлические подлокотники](bench-a.png): ближе к прежней лавочке, тёплые дубовые доски и тёмный металл.
- [Б — прямые опоры](bench-b.png): более простой каркас и деревянные подлокотники.

В каждом листе сверху слева — вид вниз (передняя сторона), сверху справа — вид вверх (задняя сторона спинки); снизу слева — влево, снизу справа — вправо. Это отдельно нарисованные ракурсы с прямым расположением относительно сетки, без диагонального поворота предмета. Вид вниз добавлен для согласованности всего набора.

Оба листа сохранены как исходные RGBA PNG со встроенной прозрачностью. Это макеты: после выбора нужно нарезать отдельные ракурсы, убрать почти прозрачную пыль по контуру и проверить читаемость, пропорции, якорь и контакт с землёй в игровом масштабе. Тени остаются отдельной задачей отрисовки, а не частью фона листа.

Генерация выполнена встроенным `image_gen`; полные запросы и роли референсов — в [generation.json](generation.json). За основу взята [нынешняя лавочка](../../../../assets/game/locations/overworld/modular/prop_bench_v1.png), для стиля — [утверждённая дубовая мебель](../../../../assets/game/interiors/furniture_a/rustic_table_north.png). Макеты находятся под общим `.gdignore` каталога концептов и не импортируются игрой.

# Колодец и телега: прямые ракурсы

Два новых варианта нарисованы встроенным `image_gen` по текущим игровым исходникам. Сохранены синий цвет крыши, серый камень, дубовое дерево и урожай в телеге. Каждый мастер1536×1024 имеет настоящий альфа-канал; цвет, видимый под полностью прозрачными пикселями при просмотре некоторых редакторов, не является нарисованным фоном.

- [A — круглая крыша и цветы](variant-a.png): ближе к прежнему колодцу, больше декоративных деталей.
- [B — простая ремесленная конструкция](variant-b.png): двускатная синяя крыша, крупные камни и доски, минимум мелкого декора. Рекомендуемый вариант для игрового размера.

Верхний ряд каждого листа — колодец, нижний — телега. Порядок слева направо: вниз к игроку, влево, вправо. Задних и диагональных ракурсов нет. Боковая телега имеет горизонтальный борт и круглое колесо; передняя — два колеса и ручки вниз.

Это дизайн-макеты, игровые PNG и отрисовка не заменены. Перенос выполняется после выбора пользователя согласно [договорённостям](../../../../AGENTS.md). Тогда уточняются отдельные области нарезки, нижние опоры и три направления каждого объекта; мастер нельзя делить механически на шесть равных клеток, поскольку поля рисунков различаются. Для игрового импорта нужны небольшие подготовленные спрайты, а не целый лист.

Исходный колодец имеет120×120px, телега120×96px; контур старых картинок уже содержит жёсткие непрозрачные пиксели. Новые мастера перерисованы, а не увеличены из этих PNG. Полупрозрачность краёв проверена по альфа-каналу; нативный просмотр после выбора дополнительно проверит края на земле, мощении и при увеличении окна.

Точные запросы: [A](prompt-a.txt), [B](prompt-b.txt). Размеры, прозрачность и контрольные суммы: [source.json](source.json). Общее правило ракурсов закреплено в [стандарте спрайтов](../../../SPRITE_STANDARD.md).

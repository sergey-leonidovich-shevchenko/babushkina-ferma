# Прямая домашняя мебель — выбран вариант А

Пользователь выбрал простой дубовый набор А14октября2026. B — прежний резной вариант, сохранён для сравнения. Мастера не загружаются игрой: они остаются здесь отдельно от компактных игровых текстур.

- `house-props-a.png`: кухонный стол, прямоугольный ковёр, сундук; четыре стороны.
- `pottery-a.png`: домашний гончарный круг, три уровня × четыре стороны.
- `stairs-a.png`: варианты люка; в дом перенесён только прямой люк с крышкой на дальней стороне.

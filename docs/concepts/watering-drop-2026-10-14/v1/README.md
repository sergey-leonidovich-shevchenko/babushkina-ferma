# Компактная капля полива

Два варианта нарисованы встроенным `image_gen`: [коралловый мастер](coral-master.png) и [голубой мастер](blue-master.png). Точные запросы сохранены в [prompt-coral.txt](prompt-coral.txt) и [prompt-blue.txt](prompt-blue.txt). Оба исходника — прозрачные PNG1254×1254 с шестью фазами; мастера сохранены без изменения пикселей. Хеши, размеры и явные области кадров находятся в [source.json](source.json).

В [анимированном сравнении](preview.html) слева воспроизведён угловатый красный значок версии0.0.163 из [FarmRenderer](../../../../scripts/presentation/farm_renderer.gd), справа показан новый спрайт. На каждой стороне четыре соседние грядки с одинаковыми растениями и полосами роста. Это макет из существующих игровых текстур, а не снимок запущенной игры.

- **Коралловая:** мягкая форма и тёплый блик, сохраняет нынешний цвет напоминания о нехватке воды.
- **Голубая:** такой же компактный знак в цвете воды. Если выбран этот вариант, при переносе нужно также обновить упоминание красной капли в обучении на шести языках.

Высота по умолчанию12px вместо19px, без учёта старой пульсации. Шесть фаз плавно смешиваются за2,2секунды; лёгкое парение составляет0,55px. Соседние значки имеют небольшую задержку. Прозрачные кадры смешиваются во вспомогательном слое с суммированием взвешенной альфы, чтобы переход не давал лишнего потускнения. Настройка размера позволяет примерить8–14px.

Подготовка кадров выполняется [prepare_preview.gd](prepare_preview.gd) средствами Godot: явные области из метаданных вырезаются в компактные атласы [coral-preview.png](coral-preview.png) и [blue-preview.png](blue-preview.png). Каждый кадр нормализуется до высоты 56px с сохранением пропорций и общей нижней опоры. Ячейки 72×72, раскладка 3×2. Разные высоты фаз в исходнике не выдаются за готовый равномерный игровой атлас. Эти копии служат только просмотру; игровые ресурсы не менялись.

Кнопка «Полить» локально увлажняет почву и убирает капли. «Пауза» останавливает движение, «Продолжить» возобновляет его. При системном уменьшении движения просмотр изначально неподвижен. Проверка в отдельном headless Chrome подтвердила анимацию обоих вариантов, паузу, продолжение, полив, уменьшение движения и отсутствие горизонтального выхода на ширине320/360px. Ошибок JavaScript нет. Отдельно просмотрены кадры обоих цветов и политых грядок.

Исходники просмотра: [шаблон](preview-fragment.template.html), [сборщик](build_preview.py), [переносимый фрагмент](preview-fragment.html). Для повторной подготовки из корня проекта:

```sh
tools/Godot.app/Contents/MacOS/Godot --headless --path . --script res://docs/concepts/watering-drop-2026-10-14/v1/prepare_preview.gd
python3 docs/concepts/watering-drop-2026-10-14/v1/build_preview.py
```

Сборщик проверяет хеши мастеров и встраивает готовые PNG без изменения изображения. `preview.html` — автономная оболочка стандартного renderer навыка visualize; встроенный в беседу просмотр использует тот же фрагмент. Размер фрагмента меньше1МБ, сетевые запросы и игровые сохранения не используются.

Перенос выбранного цвета и растровой анимации в игру выполняется после выбора пользователя по [AGENTS.md](../../../../AGENTS.md). Существующая красная капля уже уменьшена до12px в общей визуальной ревизии, её движение замедлено; сами мастера этого макета ещё не подключены.

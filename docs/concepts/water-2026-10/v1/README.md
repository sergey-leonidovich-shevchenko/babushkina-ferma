# WATER: варианты береговой кромки

Созданы встроенным `image_gen` 15 октября 2026. Это макеты направления, отдельно от игровых ресурсов; большая картинка не станет фоном уровня.

- [A — земляной берег](a-earthen.png): небольшая травяная кромка, срез грунта и мягкая тень; для фермы/природы.
- [B — укреплённый берег](b-village.png): невысокая каменная кромка, мох и участки ограды; для деревенской переправы.

Рекомендация: использовать A за пределами деревни и B возле деревенских проходов; для пещеры отдельный каменный материал в общей системе. Выбор пользователя запрошен; подключение новой графики ожидает ответа. Макеты иллюстрируют материал и масштаб. Координаты русел/границы игровой сетки определяются WATER-03; их нельзя извлекать из перспективы большой картинки.

Перед нарезкой нужны отдельные tile-safe исходники для всех сторон/углов, прозрачные края и постоянный свет; концепты не являются готовым набором PNG. Движение поверхности будет проверено в настоящем renderer.

# Домашняя кухня и хозяйственный крафт

Окно использует существующий игровой каркас, самостоятельные иконки и одинаковый источник пищевых эффектов для карточки и употребления. Названия ингредиентов в списке переведены сокращённо, без обрезанных частей слов. Справа показаны назначение блюда, точные затраты и количество партий.

Нативные кадры Godot: [омлет](omelet.png), [блинчики](pancakes.png), [ткань](cloth.png), [увеличенный текст](large_text.png). Их воспроизводит `tools/cooking_capture.gd`; пользовательские слоты не записываются.

Иконки подготовлены ранее встроенным imagegen из [исходного листа](../farmyard-2026-10/v1/sources/icons.png), [запросы](../farmyard-2026-10/v1/prompts.json) сохранены вместе с ним. Повторная генерация для новых рецептов не понадобилась: используются уже созданные майонез, блинчики, каша, трюфельная похлёбка, пряжа и ткань.

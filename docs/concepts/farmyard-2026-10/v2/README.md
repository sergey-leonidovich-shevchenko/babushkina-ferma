# Просторный фермерский двор

Уточнение по обратной связи пользователя: уменьшить свинку и увеличить загоны. Площадь куриного двора увеличена в 2,29 раза, пастбища в 3,43 раза, свинарника в 1,88 раза относительно [первого игрового варианта](../v1/after-yard.png). Южный луг расширен на 168 px. Для коровы и овцы добавлено второе укрытие из того же самостоятельного спрайта. Между загонами сохранена дорожка 72 px; открытые калитки проверяются реальным физическим перемещением героя.

Свинкины кадры подготовлены заново из [того же исходника](../v1/sources/animals.png): исходная игровая ширина 72 px уменьшена до 50 px. Концепт-листы не используются как фон или атлас во время игры.

[Двор](after-yard.png), [общий план](after-overview.png), [ночь](after-night.png). Кадры снимает [capture_game.gd](capture_game.gd) непосредственно из Godot, без записи пользовательских сохранений. Камера опущена вслед за расширением луга; прежние кадры сохранены отдельно в v1.

# Лунная долина: поляны и дороги, v3

Это отдельный дизайн-макет; действующие сцены игры и её игровые ресурсы не заменены. Состав и расстановка объектов взяты из одобренного модульного макета v2. По пожеланию пользователя количество крупных деревьев сокращено с 44 до 22: оставлены небольшие группы с широкими просветами. Дома и предметы не перемещены; один открывшийся после прореживания папоротник перенесён из воды на берег. В макете осталось 155 объектов. Дома, деревья, растения и предметы остаются отдельными спрайтами.

`materials/grass.png` и `materials/path.png` — два оригинальных крупных материала, созданных встроенным imagegen. Финальные запросы сохранены в `prompts.json`. В макете травяная текстура повторяется через 768 мировых пикселей с непрозрачностью 0.72 поверх цвета `#879961`; земляной материал повторяется через 288 пикселей. У обоих исходников 1254×1254 пикселя. Строгая попиксельная бесшовность исходников не заявляется; стыки проверены на общем плане.

`overlays/clearing.png` и `overlays/grass_dense.png` — прозрачные пятна 512×384 для светлой поляны и более густой травы. Их можно перемещать, масштабировать и повторять поверх базового покрытия. Они экспортированы из геометрических переходов Godot с обычным, не предумноженным альфа-каналом.

`roads/` содержит шесть прозрачных PNG 384×384: горизонталь, вертикаль, поворот N/E, развилка N/E/W, перекрёсток и окончание N. Модуль занимает область 96×96 мировых пикселей (4×4 клетки по 24), тело дороги — 48 пикселей (2 клетки). Все соединения имеют одинаковую ширину 192 пикселя в исходнике. Поворотами и отражениями получается полный набор направлений. Земля в этих готовых модулях повторяется через 96 мировых пикселей. Для произвольных кривых макет использует тот же материал и `road.gdshader` поверх объединённой маски маршрутов: пересечения не темнеют от повторного наложения.

`layout.json` хранит отдельные покрытия, поляны, маршруты и объекты. `preview.gd` воспроизводит нативные снимки 1920×1080 и 3840×2160, затем экспортирует дорожные модули и переходы. Запуск из корня проекта:

```sh
./tools/Godot.app/Contents/MacOS/Godot --path . --rendering-method gl_compatibility --script docs/concepts/first-location-2026-10/terrain-v3/preview.gd
```

`terrain-board.png` показывает материалы, модули и пример соединения; `comparison.png` сравнивает покрытия v2 и v3. Архив `terrain-kit-v3.zip` содержит только новый набор покрытий и переходов с описанием и источниками; существующие дома и предметы берутся из проекта.

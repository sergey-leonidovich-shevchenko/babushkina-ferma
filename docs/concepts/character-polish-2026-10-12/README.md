# Люди и прозрачные края

Нативная отрисовка Godot 4.7.1 на AMD Radeon Pro 5300M, без увеличения спрайтов:

- [Персонажи до](before.png) и [после](after.png): синяя линия показывает физическую позицию; исходное смещение жителей вниз на 24 px удалено.
- [События и портал до](props-before.png) и [после](props-after.png): светлый фон показывает служебный пурпурный кант.

Новый арт не генерировался. Пять существующих листов из `assets/game/characters/directional` переиспользованы; оригиналы сохранены. [Измерения](regions.json) читают пиксели и выбирают 32 целые связные фигуры каждого листа. `res://tools/assets/authoring/prepare_character_walk.gd` нарезает их в маленькие безопасные атласы и удаляет только внешний служебный цвет. Production-набор — `assets/game/characters/walk_v2`.

У событий более тёмный ключ удаляется только на внешнем крае. У портала более широкий профиль не включён, яркое непрозрачное ядро и камень проверяются на точное сохранение пикселей. Исходные растры и остальные эффекты не меняются.

# Бэклоги разработки

Задачи ведём в репозитории. Исходный план сохраняет свои ID и число задач; дополнительные согласованные эпики оформляем отдельно. [Рабочий процесс](../BACKLOG_WORKFLOW.md): одна задача в работе, ветка с её ID, критерии, проверка, commit и push.

| План | Объём | Текущее назначение |
|---|---|---|
| [Базовый план октября](2026-10/README.md) | 6 эпиков / 50 задач | SAFE — 7/7 завершены; [проверки и ограничения](../reports/safe-2026-10/README.md). Остальные эпики сохраняют свои статусы |
| [WATER — русла, берега и анимация](../epics/water-2026-10/README.md) | Дополнительный эпик / 15 задач | WATER-01/03/07/11 завершены; художественный выбор WATER-02 ожидается |

Подготовка нового эпика может иметь ID `WATER-00`; это планирующая работа, а не незаметное закрытие первой игровой задачи. Каждая следующая задача использует свой ID в ветке и подтверждение выполнения в карточке.

История технических дефектов остаётся в [TECH_DEBT.md](../../TECH_DEBT.md). Если работа относится к нескольким планам, у неё одна ведущая задача и ссылки на соседние; не заводить два независимых владельца одной геометрии или два несовместимых формата измерений.

Подготовка нового эпика может иметь ID `WATER-00`; это планирующая работа, а не незаметное закрытие первой игровой задачи. Каждая следующая задача использует свой ID в ветке и подтверждение выполнения в карточке.

История технических дефектов остаётся в [TECH_DEBT.md](../../TECH_DEBT.md). Если работа относится к нескольким планам, у неё одна ведущая задача и ссылки на соседние; не заводить два независимых владельца одной геометрии или два несовместимых формата измерений.

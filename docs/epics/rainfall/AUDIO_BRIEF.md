# Задание Music Agent · дождь первой деревни

Исполнение — по карточке **RAIN-01** после назначения Team Lead. Документ готовит конкретный заказ; аудиофайлы ещё не получены. Снег не входит в заказ. [Общий дизайн](DESIGN.md) · [Карточки](backlog.json).

**Сцена.** Мягкая живописная RPG, первая деревня: грунт, каменная площадь, деревянные мосты, река, вход в дом. Дождь уютный и естественный, гроза ощутимая, без резких пугающих транзиентов. Музыка и полезные сигналы игры остаются впереди. Отдельную музыку вместо погодного ambience не сочинять.

| Файл первого пакета | Длина и формат события | Содержание |
|---|---|---|
| `rain_open_light` | 45–60 с, бесшовная stereo loop | Тихий открытый дождь, без грома, крупных близких ударов и заметного метрического рисунка |
| `rain_open_heavy` | 45–60 с, бесшовная stereo loop | Плотнее и шире обычного, без постоянного высокочастотного шипения; пригоден для смешивания с light |
| `rain_sheltered` | 45–60 с, бесшовная stereo loop | Приглушённый дождь за стеной/крышей, без отчётливых шагов и разговоров |
| `rain_drip_01…04` | 0,2–0,8 с, mono one-shot | Четыре тихих редких контакта; не обязательный звук каждой видимой капли |
| `thunder_far_01…03` | 4–8 с, mono/stereo one-shot | Три далёких мягких раската с естественным хвостом, без встроенной молнии и тишины до начала |

Поставка: мастер WAV PCM24, 48 kHz; интеграционные WAV PCM16, 48 kHz, без lossy-перекодирования. Если существующий импорт проекта требует иной режим, RAIN-02 явно фиксирует проверенное преобразование, оригиналы сохраняются отдельно от игровых ресурсов. Для каждого файла — авторство/лицензия, длительность, каналы, частота, разрядность, sample peak, RMS и loop markers в семплах. Никаких неустановленных заимствований.

**Начало/конец.** Loop воспроизводится без встроенного длинного fade: вход/выход делает игра. Стыки выровнены по уровню, без щелчка и внезапного исчезновения хвоста. One-shot начинается с полезного сигнала и естественно затухает, конец не обрезан. Light/heavy не обязаны быть фазово совпадающими, но их смешивание не должно давать провал или внезапный скачок уровня; это проверяется реальным кроссфейдом.

**Уровень.** Sample peak каждого файла не выше −3 dBFS, без clipping/DC-смещения. Начальная целевая средняя RMS петель −26…−22 dBFS; это ориентир подготовки, финальный уровень принимается в миксе. Тихий контакт не громче интерфейсного подтверждения на одинаковой дистанции, гром не перекрывает боевую опасность. Не компенсировать слабый мастер подъёмом общей громкости игры. Десять минут в наушниках без утомительного шипения и очевидного повторяющегося акцента — обязательное прослушивание.

**Интеграция RAIN-02.** До трёх выделенных ambience-голосов для плавного смешивания light/heavy/sheltered; ограниченный отдельный пул не более двух погодных one-shot. Не занимать постоянно шесть существующих голосов действий AudioSystem. Учитывать master, sfx, mute, настройки доступности и приоритет полезных сигналов. Переходы следуют одному снимку VWEATHER-009; это не музыкальная смена локации. На паузе тихо остановить/припарковать погодный слой по принятой политике, resume не перезапускает все звуки одновременно. При закрытой игре, потере мира и mute очередь старого грома очищается. Укрытие меняет смесь, а не создаёт второй дождь.

**Приёмка.** Проверить сами байты/metadata/лицензию, три последовательных стыка каждой loop и 10 минут реального микса. В игре проверить обычный дождь/гроза/дверь/пауза/mute/полный набор SFX и счётчики голосов. Пакет в RAIN-01 может быть принят отдельно; готовый звук в папке не закрывает его подключение RAIN-02 или дождевую приёмку RAIN-03.

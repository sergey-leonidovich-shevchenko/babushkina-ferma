# RELIC — будущая приёмка

**18 сценариев запланированы.** RELIC-00 проверяет постановку; игровые результаты появятся при реализации. Для каждого сценария нужны реальный результат, профильный снимок состояния и при необходимости нативный маршрут.

<a id="matrix"></a>

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| RELIC-QA-01 | Найти участок без знания координат | Край черепка и взаимодействие понятны, основной проход свободен |
| RELIC-QA-02 | Прервать каждый слой | Уже открытая земля сохраняется, предмет не возрождается |
| RELIC-QA-03 | Полный рюкзак у раскопа | Набор остаётся на своём месте до успешной выдачи |
| RELIC-QA-04 | Повторить получение/сменить день | Только один набор со своим экземпляром |
| RELIC-QA-05 | Очищать/закрыть/загрузить | Рисунок проявлен по прогрессу, важные линии не стираются |
| RELIC-QA-06 | Потратить активный набор | Обычная торговля/крафт/выбрасывание не уводят вещь из осмотра |
| RELIC-QA-07 | Собрать 5 частей с ошибками | Ошибки обратимы, есть допуск стыка, итог достижим |
| RELIC-QA-08 | Заполнить рюкзак перед завершением | Набор заменяется целым предметом без второй ячейки |
| RELIC-QA-09 | Сохраниться на всех переходах | Один владелец, точный прогресс, нет зависшей занятости |
| RELIC-QA-10 | Оставить себе/пожертвовать | Один предмет или одна музейная запись, рисунок доступен в обоих случаях |
| RELIC-QA-11 | Повтор сдачи и старый музейный жетон | Награда однократна, старые пороги не выдают жетон второй раз |
| RELIC-QA-12 | Старое/неполное сохранение | Без потери старой коллекции и автоматически выдуманных экспонатов |
| RELIC-QA-13 | Башня до и после тарелки | Факты соединяются в обоих порядках без повторной выдачи |
| RELIC-QA-14 | Гирька | Два клейма и иной способ восстановления, свой источник |
| RELIC-QA-15 | Свистулька | Видимый канал из 3 частей, звук дублирован текстом |
| RELIC-QA-16 | Межевой диск | Два кольца и фиксированная метка, верная историческая запись |
| RELIC-QA-17 | Клавиатура/контуры/размер окна | Полный цикл без точного пикселя, штрафов за помощь и потери выхода |
| RELIC-QA-18 | Коллизии, три ракурса, музей/услуги | Свободный подход, правильная сетка, прежние услуги доступны |

RELIC-10 принимает 01…12 и первый цикл; RELIC-16 принимает всю матрицу. Вспомогательные артефакты/музейные записи не подтверждаются только зелёным общим набором. Арт сверяется в нативном окне, не по одному исходному PNG.

## Проверка подготовки

RELIC-00: сверить 16 уникальных ID/веток/названий, 48 индивидуальных критериев, ацикличные внутренние блокеры и барьер RELIC-10, локальные ссылки/явные якоря, четыре разных источника и восемь проектных видов предметов. Все игровые статусы — backlog, подтверждения пусты. Выполнить существующие documentation/architecture gate и полный `./run_tests.sh` по `TESTING.md`. Нового инструмента, кода игры, ресурсов или тестов подготовка не добавляет; вики не меняется.

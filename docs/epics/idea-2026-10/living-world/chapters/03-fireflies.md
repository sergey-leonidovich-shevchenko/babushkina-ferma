## IDEA-002-021 — Ночные рои светлячков

**Статус:** backlog · **Приоритет:** P1 · **Объём:** M.

**Задача:** Задать несколько устойчивых мест ночного появления у влажной травы, зарослей и лесных троп. Днём рой отдыхает вне видимого полёта.

**Внутренние блокеры:** [IDEA-002-002](01-contracts.md#idea-002-002), [IDEA-002-004](01-contracts.md#idea-002-004), [IDEA-002-005](01-contracts.md#idea-002-005).

**Приёмка:**

- День и ночной переход не оставляют светящиеся точки в неподходящей комнате.
- Рой не создаётся под героем при пересечении границы ночи.

**Подтверждения / результат:** —; игровая реализация не принята.

<a id="idea-002-022"></a>

## IDEA-002-022 — Один рой — один цвет

**Статус:** backlog · **Приоритет:** P1 · **Объём:** M.

**Задача:** Цвет принадлежит всему рою: золотистый, зелёный, голубой или редкий сиреневый. Индивидуальная яркость допустима в пределах одного оттенка.

**Внутренние блокеры:** [IDEA-002-021](03-fireflies.md#idea-002-021), [IDEA-002-006](01-contracts.md#idea-002-006), [IDEA-002-009](01-contracts.md#idea-002-009).

**Приёмка:**

- Внутри одного роя нет радужной случайной смены цветов.
- Соседние рои разных цветов сохраняют принадлежность при сближении.

**Подтверждения / результат:** —; игровая реализация не принята.

<a id="idea-002-023"></a>

## IDEA-002-023 — Мягкое общее свечение роя

**Статус:** backlog · **Приоритет:** P1 · **Объём:** L.

**Задача:** Несколько огоньков дают небольшое общее освещение ближайшей земли и героя. Свечение не требует отдельной дорогой тени от каждой точки.

**Внутренние блокеры:** [IDEA-002-022](03-fireflies.md#idea-002-022), [IDEA-002-004](01-contracts.md#idea-002-004).

**Приёмка:**

- Стена обрывает свет, соседняя комната остаётся тёмной.
- Медленное изменение яркости не превращается в стробоскоп; доступен спокойный режим.

**Подтверждения / результат:** —; игровая реализация не принята.

<a id="idea-002-024"></a>

## IDEA-002-024 — Расступание роя перед героем

**Статус:** backlog · **Приоритет:** P2 · **Объём:** M.

**Задача:** При приближении светлячки слегка расходятся и снова собираются после ухода. Центр роя остаётся в своём месте обитания.

**Внутренние блокеры:** [IDEA-002-021](03-fireflies.md#idea-002-021), [IDEA-002-003](01-contracts.md#idea-002-003), [IDEA-002-023](03-fireflies.md#idea-002-023).

**Приёмка:**

- Герой не таскает за собой весь рой через карту.
- Группа не слипается в яркую точку и не исчезает одним кадром.

**Подтверждения / результат:** —; игровая реализация не принята.

<a id="idea-002-025"></a>

## IDEA-002-025 — Поимка светлячка сачком

**Статус:** backlog · **Приоритет:** P1 · **Объём:** L.

**Задача:** Взмах сачка ловит выбранного доступного светлячка при наличии пустой банки. Это осознанная поимка, общий магнит на живых существ не действует.

**Внутренние блокеры:** [IDEA-002-024](03-fireflies.md#idea-002-024), [IDEA-002-008](01-contracts.md#idea-002-008), [IDEA-002-185](19-journal-crafting.md#idea-002-185).

**Приёмка:**

- При отсутствии банки существо и материалы не исчезают, причина показана заранее.
- Один взмах передаёт ровно одного светлячка из роя в один экземпляр банки.

**Подтверждения / результат:** —; игровая реализация не принята.

<a id="idea-002-026"></a>

## IDEA-002-026 — Банка с пойманным светлячком

**Статус:** backlog · **Приоритет:** P1 · **Объём:** L.

**Задача:** Сохранить цвет, происхождение и содержимое банки. В руках и установленной банке видны огонёк и слабый свет; перенос идёт одним экземпляром.

**Внутренние блокеры:** [IDEA-002-025](03-fireflies.md#idea-002-025), [IDEA-002-007](01-contracts.md#idea-002-007), [IDEA-002-186](19-journal-crafting.md#idea-002-186).

**Приёмка:**

- Банка не светит одновременно в рюкзаке, на поясе и на земле.
- Разные цвета не смешиваются в одну стопку с потерей свойств.

**Подтверждения / результат:** —; игровая реализация не принята.

<a id="idea-002-027"></a>

## IDEA-002-027 — Отпускание светлячка

**Статус:** backlog · **Приоритет:** P2 · **Объём:** M.

**Задача:** Открытая банка освобождает светлячка на подходящей уличной опоре и возвращает одну пустую банку. Повторный осмотр не создаёт новую награду.

**Внутренние блокеры:** [IDEA-002-026](03-fireflies.md#idea-002-026), [IDEA-002-008](01-contracts.md#idea-002-008).

**Приёмка:**

- В закрытом каменном помещении отпускание предлагает подходящее место, без потери содержимого.
- Поймать и отпустить можно без удвоения существа и стекла.

**Подтверждения / результат:** —; игровая реализация не принята.

## IDEA-002-028 — Редкий цвет без обязательной лотереи

**Статус:** backlog · **Приоритет:** P2 · **Объём:** M.

**Задача:** Редкие рои — необязательное открытие дневника. Их цвет и квота фиксируются на цикл места, поздний маршрут даёт предсказуемую возможность увидеть вид.

**Внутренние блокеры:** [IDEA-002-006](01-contracts.md#idea-002-006), [IDEA-002-021](03-fireflies.md#idea-002-021), [IDEA-002-181](19-journal-crafting.md#idea-002-181).

**Приёмка:**

- Нужный для обучения светлячок гарантирован обычным доступным роем.
- Перезагрузка обнаруженного места не перебрасывает редкий цвет.

**Подтверждения / результат:** —; игровая реализация не принята.

## IDEA-002-029 — Погода и укрытие роя

**Статус:** backlog · **Приоритет:** P2 · **Объём:** M.

**Задача:** В сильный дождь огоньки собираются ниже под подходящим навесом растительности либо временно не выходят. Ночной фонарь не перекрашивает рой.

**Внутренние блокеры:** [IDEA-002-023](03-fireflies.md#idea-002-023), [IDEA-002-171](18-ecology.md#idea-002-171), [IDEA-002-172](18-ecology.md#idea-002-172).

**Приёмка:**

- Новый дождь не переносит группу через каменную стену.
- После улучшения погоды рой возвращается постепенно в рамках прежней квоты.

**Подтверждения / результат:** —; игровая реализация не принята.

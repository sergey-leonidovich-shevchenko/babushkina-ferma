# Звук названий — задание для будущей реализации TITLE

Сейчас только спецификация; файлы не заказаны и не подключены. При запуске TITLE-14 исполнитель передаёт этот контекст Music Agent по AGENTS.md.

## Общее

Короткие one-shot, без loop. Начало совпадает с первым видимым раскрытием орнамента, спокойный хвост затихает вместе с ним. Название полностью понятно при mute. Частота — один звук на реальный показ; отменённая очередь молчит, повторный вход по умолчанию без музыкальной фразы. Один местный акцент, не новая тема деревни. Не перебивает диалог, атаку, предупреждение или боевую музыку.

Формат мастера WAV PCM 48 kHz/24 bit stereo, без срезанного хвоста, peak ≤ −6 dBFS; финальная игровая громкость после прослушивания в текущем миксе, а не по одной пиковой цифре. Длины ниже — гипотезы. Проверить mono/наушники/тихую громкость, отсутствие щелчка при отмене (короткий fade до 80 ms). Не ставить лимитер на весь игровой звук ради титра.

|---|---|---|
| Домашняя деревня | Сухая деревянная нота, мягкий щипок струны; тёплый, без сигнала награды | 0,9 с / 2 |

| Подкоренье | Лёгкий древесный скрип и низкий щипок; без тревожного треска падающего дерева | 1,3 с / 2 |
| Соляная Пристань | Натяжение каната и короткая волна; без крика чайки поверх речи | 1,2 с / 2 |
| Бродячий Двор | Шелест ткани и глухой деревянный щелчок; без рекламной фанфары | 1,0 с / 2 |

| Супербосс | Более долгий резонанс без дополнительной громкости и длинного оркестрового crescendo | 1,6 с / 2 |

Интерьеры/районы используют самый тихий короткий материал родителя либо тишину. Не производить 52 разных файла на 52 строки каталога. Особые боссы могут получить индивидуальный акцент в собственном эпике, сохраняющем общую длительность вступления TITLE.

Music owner не перезапускает трек на повторном входе. Существующая музыка сражения начинается только по commit владельца боя. Если общий микшер поддерживает мягкий duck, пробовать −3 dB на 0,8 с; иначе обходиться без duck, не создавать вторую систему микширования. Повторные skip/cancel не оставляют сниженный уровень. Замена устройства, пауза и mute не возобновляют старый звук.

Приёмка: 20 быстрых переходов/skip, фокус, диалог, вход к боссу, повтор после смерти, mute и настройки UI/SFX. У каждого фактического файла — автор, лицензия/происхождение, длина, peak и место использования; проверенные файлы и результат слуховой пробы прикладываются к TITLE-14, а не к этой постановке.

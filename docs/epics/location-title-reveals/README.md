# TITLE — Названия мест и представление боссов

**Согласованный эпик по прямому поручению пользователя 28 октября 2026. Не IDEA.** Сейчас подготовлен дизайн; игровой эффект ещё не реализован. [Карточки](TASKS.md) · [Каталог мест](PLACE_CATALOG.md) · [Каталог встреч](BOSS_CATALOG.md) · [Приёмка](ACCEPTANCE.md) · [Wiki](../../../wiki/articles/location-title-reveals.md).

При входе игрок получает короткий запоминающийся титр: название по центру верхней трети экрана, небольшой местный орнамент и при необходимости одна строка подзаголовка. Каждое поселение узнаётся по собственной пластике. У босса имя становится частью начала встречи. Ни один титр не выдаёт предмет, не открывает географию и не меняет сложность боя.

Текущее поручение разрешает **постановку**, а не начало игрового внедрения. TITLE-00 остаётся in_progress до независимого ревью текущего SHA и решения Team Lead. Все игровые этапы backlog; завершить REFACTOR-03, затем соблюдать остановку от 28 октября. Для начала реализации TITLE нужна новая прямая команда пользователя; VMAP-003 сохраняет приоритет первой карты. Каталог будущих мест и боссов не является разрешением их создавать.

## Что существует сейчас

Срез: `d609ab4fa6d82d6d013265183f018b8836abf7cc`. WorldSystem при путешествии меняет карту, пишет название в `game.message`, затем вызывает DiscoverySystem.show_location. Discovery показывает отдельную карточку «новое рядом» и сразу отмечает `location:<id>` просмотренным. Это работающие уведомления, но общего титра в верхней трети пока нет. Новый слой должен согласовать эти показы, а не добавить третий поверх двух прежних.

Источники: [WorldSystem](../../../scripts/systems/world_system.gd), [DiscoverySystem](../../../scripts/systems/discovery_system.gd), [GameLoop](../../../scripts/core/game_loop.gd), [SaveSystem](../../../scripts/systems/save_system.gd), [SaveValidation](../../../scripts/systems/save_validation_system.gd), [VillageRegionData](../../../scripts/systems/village_region_data.gd), [атлас](../../reports/world-atlas-2026-10/atlas-data.json). Последний — исторический снимок 19 октября; его не редактируем. Реестр TITLE различает 30 существующих карт, 20 будущих географических узлов атласа, будущий Инейный хребет и отдельную будущую границу фермы: **52 профиля**, а не 52 готовые новые локации. Весь мир/global исключён из географических титров.

Шесть домашних районов — одно нынешнее поселение. Речная переправа `village_river` не равна будущей деревне Ивовые Мостки. «Бабушкина ферма» — будущая именованная зона внутри overworld: не переименовываем всю карту «Деревня и гильдия».

## Сценарий игрока

1. Герой пересекает действительный вход в Ивовые Мостки. Когда переход успешно завершён и экран открыт, тонкая ивовая линия расходится из центра; целиком проявляются название и подпись «Деревня на тихой воде». Герой продолжает идти. Тихий водный акцент поддерживает показ.
2. Спустя три секунды титр исчезает. Название остаётся доступно на карте. При следующем визите — только короткое имя; проход к лавке не повторяет вступление деревни. Можно выбрать тихие повторные входы в настройках.
3. В святилище герой осознанно активирует алтарь. Владелец встречи сначала проверяет условия, затем удерживает безопасное начало: появляется имя Хранителя, орнамент собирается в каменную печать. Только после завершения или пропуска представления начинается существующий бой с видимым предупреждением атаки.
4. Уже агрессивный капитан на открытом корабле получает компактный титр без остановки игры. Полное представление разрешается только после отдельной приёмки настоящего безопасного начала этой встречи. Режиссура не даёт бесплатную неуязвимость посреди боя.

## Композиция и время

Якорь: X=50%, Y≈30% **полезной области экрана**, с учётом HUD, безопасных отступов и letterbox. Координаты экранные, не мировые; zoom камеры не увеличивает шрифт. При конфликте с предупреждением об атаке титр уступает место угрозе. Основное имя до двух строк, подзаголовок до одной; он необязателен. Полупрозрачная локальная подложка по контрасту, без затемнения всей игры.

Начальная гипотеза при 1152×648: имя 30–32 HUD px, подпись 14–16; ограниченная ширина около 64% полезного кадра. Подбор переноса, а не обрезание имени многоточием. Шесть локалей, длинные названия, CJK и текстовые масштабы проверяются отдельно. Анимация целой строки сохраняет shaping и работу screen reader; побуквенную печать не используем. Новые имена имеют локализуемые ключи; отсутствие перевода даёт проверенный fallback языка проекта, а не технический ID.

| Режим | Вход / чтение / выход | Итог | Поведение |
|---|---|---|---|
| Первое поселение | 0,35 / 2,10 / 0,55 с | 3,00 с | Движение продолжается |
| Основная область | 0,30 / 1,80 / 0,50 с | 2,60 с | Движение продолжается |
| Район или интерьер | 0,20 / 0,85 / 0,30 с | 1,35 с | Компактный титр |
| Повторный вход | 0,15 / 0,65 / 0,25 с | 1,05 с | Имя без подзаголовка |
| Полное представление босса | 0,45 / 1,85 / 0,50 с | 2,80 с | Только безопасное начало |
| Супербосс | 0,55 / 2,05 / 0,60 с | 3,20 с | Та же безопасная процедура |
| Встреча без безопасной сцены | 0,20 / 0,90 / 0,30 с | 1,40 с | Без блокировки управления |

Это стартовые параметры для нативной пробы, не подтверждённый баланс. Имя поднимается на 12–16 px с плавным торможением; орнамент раскрывается из центра, подпись отстаёт на 0,12 с. На выходе короткое затухание. Ни тряски камеры, ни белой вспышки, ни дождя частиц. Reduced motion убирает перемещение/раскрытие, оставляет спокойное появление текста с той же возможностью прочитать и пропустить.

## Одна очередь и один владелец

Discovery остаётся владельцем сведений о посещении. Новый координатор титров — **представление**, не второе хранилище прогресса. Производители переходов передают одно событие после успешного commit перехода: stable place ID, transition ID, причина прибытия, текущий контекст. Отказ двери/варпа событий не создаёт. Пещеры, интерьеры, обычное путешествие и будущие варпы подключаются к одному договору; координатор не угадывает вход по смене `game.message`.

Поток: `received → validated → waiting → entering → readable → leaving → complete`; возможны `coalesced / expired / cancelled`. Одновременно один титр, очередь максимум три. Приоритет: безопасное представление босса → основная область/поселение → район. Вытесненный вступлением босса титр места не проигрывается после победы задним числом. У события место и поколение перехода; при следующем переходе старое сбрасывается. Два вызова одной двери дают один показ и один звук.

Карта/инвентарь/диалог/обучение/пауза/F12/потеря фокуса приостанавливают часы представления или оставляют событие ожидающим. В обычном бою географический титр ждёт до 5 активных секунд, затем остаётся только тихое название в обычной навигации; не загораживает снаряды и не копится. Возврат фокуса не догоняет анимацию. Смерть, новая игра, успешная загрузка и смена карты отменяют старую transient-очередь; неудачная загрузка ничего не сбрасывает.

Повторный показ требует настоящего выхода из области и повторного входа. Для зон без загрузки: стартовая гипотеза 0,6 с устойчивого нахождения за границей и отступ 2 клетки от её линии, минимум 30 активных секунд между повторными титрами одного места. Для двери достаточно подтверждённого перехода, но cooldown сохраняется. Дрожание на границе, телепорт внутри того же места, меню и смена дня не создают нового входа. Возвращение после загрузки не считается переходом. Бродячий Двор сохраняет одно поселение при перемещении стоянки.

## Согласование с действующим HUD

Географический `game.message` не дублирует показанное имя; содержательные сообщения об отказе/награде сохраняются. Карточка Discovery для location объединяется с этим событием. Уникальная подсказка пещеры не исчезает: после титра доступна отложенная компактная помощь/журнал через прежнего владельца; обучение не отмечается завершённым только из-за анимации. Карточки предметов и NPC остаются собой; при скрытии их оставшееся время не сгорает. Квестовая речь, награда, HP босса и опасные предупреждения имеют собственные места HUD.

Настройки: «Названия мест: обычные / только первое посещение / компактные»; отдельный переключатель повторов, reduced motion и громкость UI. Отказ от украшений не скрывает текущее место на карте и имя активного босса у HP. Пропуск: после 0,25 с, только **новое нажатие после отпускания** кнопки входа; мышь/клавиатура/геймпад имеют одну семантику. Нельзя удержанным E случайно пропустить и сразу ударить. UI не ловит ввод обычного движения в географическом режиме.

## Безопасное начало босса

Владелец конкретной встречи проверяет доступность, отсутствие победы/другого старта и валидность арены. До установки `active / guardian_alive / boss_alive` он запрашивает представление. Режим существует только если принят общий modal/pause договор, останавливающий **всю боевую симуляцию**: героя, врагов, снаряды, прикреплённые статусы, часы мира и срочных поручений. UI-часы идут отдельно при фокусе; меню поверх держит оба процесса. Нынешний GameLoop обновляет часть подсистем до modal guard: одной проверки `modal_active` недостаточно, порядок обязан пройти TITLE-09. До этого полный режим запрещён.

Это остановка перед боем, не флаг защиты HURT и не изменение HP. Географические титры никогда её не включают. При complete/skip владелец один раз завершает постановку, очищает буфер атаки и запускает свою прежнюю встречу. Никаких бесплатных сбросов HP/добычи/ритуальных предметов. После освобождения управления первый удар следует существующему читаемому windup; положить урон в тот же кадр нельзя. При отмене до commit ресурс активации не расходуется; списание выполняется существующим владельцем ровно при принятом старте.

Пока нет общей безопасной сцены, допустим компактный неблокирующий режим. При загрузке уже идущей битвы — только текущий HUD/компактное имя, без повторного ритуала, паузы и сброса фазы. После поражения полный показ по умолчанию не повторяется. Смена фазы — существующее боевое предупреждение, не новое вступление. Побеждённая встреча имени повторно не показывает. Призванные существа/обычный cave_guardian/сюжетный слизень не наследуют вступление по одному имени вида.

## Сохранение и совместимость

У существующего `seen_discoveries` допускаются boolean-ключи. Новые пространства имён: `title:place:<stable_id>` и `title:boss:<encounter_id>`, реестр ограничен числом утверждённых профилей. Смотренность — не квестовый/боевой флаг. Записывать после 0,6 с действительно видимого полного имени либо явного пропуска; невидимый, вытесненный или отменённый титр не отмечать просмотренным. Координатор не переписывает прежние `location:<id>`.

Старый слот с посещённым `location:<id>` получает компактный повтор вместо каскада первых заставок. Новый слот получает обычный первый вход; неизвестные/неверно типизированные ключи проходят действующий валидатор, без сброса других tutorial/seen. В JSON нет таймера, очереди, node, callback, animation/material и pending-start. После загрузки владелец встречи восстанавливается по своим прежним правилам; TITLE не восстанавливает отложенный вызов старта. Миграция профиля использует явный alias старого ID; смена перевода/декора не стирает просмотренность.

## Границы первого полезного выпуска

Первый выпуск: один координатор, один экранный компонент, профили шести **нынешних** домашних районов, нормальный/короткий/reduced motion режимы, снятие дублей Discovery/message, старые слоты и доступность. Он не требует новых деревень, новых арен или новой музыки. Затем остальные 24 существующие карты; после отдельной приёмки безопасного старта — три действующих сценарных босса. Капитан/лесная цель остаются компактными до договора их владельцев. Будущие профили уже спроектированы, подключаются при создании соответствующего контента без новых общих TITLE-задач на один и тот же компонент.

Существующие VUI, VCAMERA, VCOMPAT и VPERF отвечают за свои общие контракты; TITLE их использует, не ставит им done. Освещение/тени мира не меняются. [Звуковое задание](AUDIO_BRIEF.md) готово для будущей передачи Music Agent; сейчас аудиопроизводство не запускается.

## Стоимость и риски

Польза — ориентация, узнаваемость деревень, вес начала встречи. Интерес — дизайнерская гипотеза; аудитория: исследователи мира, любители атмосферы и боссов. Малый будущий тест: 5–8 игроков после трёх входов называют место/различают повтор и первое посещение; ни один не получает урон из-за титра. Не выводим интерес из популярности другой игры, не требуем копировать чужое оформление.

Стоимость M для домашних названий, L для общего безопасного старта боссов из-за порядка GameLoop. Главные риски: скрытый тик яда/срочного квеста во время intro; повтор start/награды; путаница существующих районов и будущих деревень; переизбыток заставок; длинный перевод; постоянный redraw всего мира. Проверки и точные будущие критерии — [ACCEPTANCE](ACCEPTANCE.md). Это согласованный объём, а не новая оценка IDEA и не основание менять очередь реализации.

## VPERF-001 — Уточнить измерительный контракт

Статус: `backlog` · P0 · этап `foundation` · `engineering`

CPU, frame interval и GPU не смешиваются; mismatched host window отдельно отмечен; VSync и фокус записаны

Ветка: `codex/vperf-001-visual-task`.

Зависимости: VBASE-001.

Единый владелец пересечения: **OPT-01**. Эта карточка уточняет работу владельца, не закрывает его автоматически.

Исходники:

- [scripts/systems/runtime_maintenance_system.gd](../../../../scripts/systems/runtime_maintenance_system.gd)
- [scripts/systems/render_pacing_system.gd](../../../../scripts/systems/render_pacing_system.gd)
- [tools/water_audit.gd](../../../../tools/water_audit.gd)

Результат / новые пути (пока не существуют): `docs/reports/visual-overhaul/vperf-001/`.

Критерии:

- CPU, frame interval и GPU не смешиваются; mismatched host window отдельно отмечен; VSync и фокус записаны
- Сравнение выполнено при одинаковой камере; подтверждение связано с commit и конфигурацией, не только с зелёным автотестом.

Проверка:

- Сохранить raw интервалы, p50/p95/p99/max, память, draw calls и настройки; сравнить три повтора и длинный цикл, без заявления GPU времени по CPU.

Риск: Несогласованные масштаб, порядок слоёв или стоимость могут ухудшить соседние объекты; оценивать в игровой сцене.

Откат: Отдельный commit; предыдущий ресурс/профиль сохранить до приёмки, откатить ссылку или выключить флаг эффекта без изменения сохранений.

Оценка: [1, 3] рабочих дней, уверенность low. Рабочая гипотеза на одну карточку; уточнить по пилоту. Не календарное обещание.

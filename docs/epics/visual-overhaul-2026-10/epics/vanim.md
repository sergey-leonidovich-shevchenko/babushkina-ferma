Ветка: `codex/vanim-001-visual-task`.

Зависимости: VBASE-003.

Единый владелец пересечения: **UX-09**. Эта карточка уточняет работу владельца, не закрывает его автоматически.

Исходники:

- [scripts/systems/hero_visual_system.gd](../../../../scripts/systems/hero_visual_system.gd)
- [scripts/systems/resident_visual_system.gd](../../../../scripts/systems/resident_visual_system.gd)
- [scripts/systems/creature_visual_profile_system.gd](../../../../scripts/systems/creature_visual_profile_system.gd)

Результат / новые пути (пока не существуют): `docs/reports/visual-overhaul/vanim-001/`.

Критерии:

- Из экспорта 42 записей выделить 40 художественных единиц с общим набором курочек; отсутствующие действия помечены явно
- Сравнение выполнено при одинаковой камере; подтверждение связано с commit и конфигурацией, не только с зелёным автотестом.

Проверка:

- Перебрать каждый clip/direction/frame; проверить границы atlas и pivot; записать нативный разворот и сравнить контакт с gameplay.
- Перед commit/push выполнить TESTING.md; для runtime дополнительно нативный кадр/видео и профильные тесты.

Риск: Несогласованные масштаб, порядок слоёв или стоимость могут ухудшить соседние объекты; оценивать в игровой сцене.

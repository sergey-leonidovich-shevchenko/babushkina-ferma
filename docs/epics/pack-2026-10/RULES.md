# PACK — правила рюкзака и подбора

Требования пользователя от 18 октября 2026 года: одинаковые вещи объединяются; максимум **999** в слоте; тысячная единица идёт в следующий свободный слот; если места нет — неподходящий лут не магнитится. Числа ниже задают целевой договор, не описывают уже принятую реализацию.

## Стаки и места

| Область | Целевое поведение |
|---|---|
| Вместимость | 60 базовых ячеек; оплаченные уровни +12, максимум 108. Все доступны через прокрутку |
| Обычная одинаковая вещь | До 999 в одном слоте; пища, семена и ресурсы не получают самовольного другого лимита |
| Совместимость | Совпадают вид, качество и все существующие значимые свойства: эффекты, заряд, содержимое, привязка. Внешне похожие вещи с разными свойствами не смешиваются |
| Штучные вещи | Инструмент/снаряжение с индивидуальной прочностью, занятая банка с живностью и уникальный предмет — по одному экземпляру. Точный список и метаданные принимает PACK-01/02; старый запрет дублей пяти уникальных инструментов сохраняется |
| Долив | Сначала совместимые неполные стаки по стабильному порядку ячеек, затем новые слоты |
| Следующий слот | Соседний справа, если свободен; иначе следующий свободный по порядку сетки с переходом через конец. Занятые места не сдвигаются и не заменяются |
| Пустота | Нулевая запись каталога не занимает место. Нулевая стопка освобождает слот |
| Быстрая панель | Ссылка на реальный предмет/стак с понятным восстановлением после объединения; не десять бесплатных мест |
| Экипировка | Ссылка на штучную вещь в сумке; один владелец, один набор свойств, пометка «надето» |

Новая модель хранит несколько стаков вида и их реальные свойства; прежний общий счётчик становится согласованным представлением доступных вещей. Изменение суммы напрямую не должно обходить лимит. Только один владелец проводит приём, расход, разделение, слияние, перенос и замены; качество/прочность не генерируются заново при сортировке и поднятии с земли.

## Примеры, которые должны работать буквально

| До / действие | Свободные ячейки | Результат |
|---|---:|---|
| 10 дерева + подобрать 5 того же дерева | 0 | Один слот, 15 дерева |
| 998 дерева + подобрать 1 | 0 | Один слот, 999 дерева |
| 999 дерева + подобрать 1 | 1 | Два слота: 999 и 1 |
| 990 дерева + подобрать 20 | 1 | Два слота: 999 и 11 |
| 990 дерева + рядом выпало 20 | 0 | Летят/подбираются 9; 11 лежат на исходной земле |
| 999 дерева + рядом 1 дерево | 0 | Дерево не притягивается; касание не удаляет его |
| 5 дерева + рядом яблоко, сумка полна | 0 | Наличие дерева не создаёт место для яблока; яблоко лежит |
| Обычные яблоки + серебряное яблоко | 0 | Несовместимое качество не смешивается; предмет остаётся |
| Стак 500 + явно отделить 100 | 1 | 400 и 100; общий итог 500, свойства одинаковы |
| Выбросить 100 из 500 | Любое | В сумке 400, на земле 100; при уничтожении на земле ничего не создаётся |

## Магнит и изменение сумки

1. Начало захвата только в радиусе **2 × 48 = 96 мировых единиц**, на той же карте, для свободной разрешённой добычи. Сначала без мутаций вычисляется, сколько примет сумка. Нулевой ответ запрещает движение, резерв и событие успешного подбора.
2. Если помещается часть, только эта часть получает полёт и отдельную устойчивую мировую запись; остаток остаётся у исходной опоры. Сумма обеих частей равна прежнему стеку. Вместо каждого нового кадра с отколом нужен один учтённый переход.
3. Место/свободная часть стака учитываются для уже захваченных вещей: два летящих стека не обещают одну последнюю ячейку или одни девять свободных единиц. Резерв — намерение, не вещь в рюкзаке. До контакта обе части принадлежат миру.
4. При контакте переносится только подтверждённое количество, точно один раз; резерв и мировая часть закрываются вместе. При отказе предмет остаётся у последней допустимой опоры и перестаёт летать вокруг героя.
5. Явное действие игрока с рюкзаком имеет приоритет. Если покупка, крафт или перенос делают резерв невозможным, затронутые полёты безопасно прекращаются и освобождают резерв. Герой видит лежащий предмет, а не вечное преследование. Новый захват автоматически начинается, когда снова появится место.
6. Пауза/рюкзак останавливают полёт вместе с миром. Телепорт и смена карты не переносят привязанный лут в новую комнату; позиция/остаток сохраняются на исходной карте. Правила догоняния, стен и воды остаются у общего владельца движения VTREE-018.
7. Свободная добыча подбирается только автоматически: отдельной команды «Взять» и ручного обхода блокировки нет. После освобождения места подбор возобновляется сам, если герой рядом. Неизвестный вид и недопустимый уникальный дубль лежат; декоративные щепки/листья и живые животные не превращаются в лут.
8. Переполненная сумка не создаёт сообщение каждый кадр. На подходе допускается короткий знак «Нет места» и причина по запросу; повтор подавляется до изменения вместимости либо нового подхода. «Получено ×N» появляется только на реально принятую часть через общий VTREE-019.

## Выброс, уничтожение и защита

В карточке вещи отдельные команды **«Выбросить…»** и **«Уничтожить…»**. Обе предлагают 1 / количество / весь выбранный стак. Число ограничено фактическим доступным остатком; удержание клавиши и двойное подтверждение не повторяют операцию. Выбрасывание целого стака не означает «все такие вещи из всех ячеек».

Выброс сначала ищет доступную землю перед героем и рядом с ним у действующего владельца навигации. Если точки нет, вещи остаются в сумке. Только затем списание и создание мировой записи происходят вместе. Вода, закрытая стена, чужая карта и недоступная высота не становятся местом выпадения. Позиция, качество, прочность и количество сохраняются.

Собственный выброс не притягивается автоматически, пока герой не выйдет дальше 96 от его опоры и не подойдёт снова. Перезагрузка в той же точке защиту не снимает. После выхода из радиуса и возвращения вещь снова подбирается автоматически. Игроку не нужна отдельная кнопка подбора. Обычная добыча и оставшиеся части другого стека не получают эту блокировку случайно.

Уничтожение требует отдельного подтверждения с иконкой, локализованным именем, качеством, количеством и понятной окончательностью. Cancel/Escape/закрытие не меняют вещи. Подтверждённое уничтожение не создаёт мировой лут, награду или материалы переработки. Исследование/разбор остаются своими существующими механиками. Drag за край окна не уничтожает вещь и не подтверждает диалог сам.

Избранный/закреплённый предмет защищён от массового переноса, выброса и уничтожения до явного снятия защиты. Сюжетные и зарезервированные вещи имеют собственные разрешения и понятную причину недоступности. Защита не выводится только из цвета редкости или текущей категории. Для надетого предмета нужна явная команда «Снять и выбросить/уничтожить» с единой передачей и пересчётом характеристик; обычный клик не рвёт ссылку экипировки. Последний необходимый для текущего прогресса инструмент не уничтожается без доступного принятого способа восстановления, проверенного в PACK-10.

## Другие источники вещей

- Сундук/шкаф: обычный перенос принимает вмещающуюся часть, оставшееся лежит в исходном хранилище. Быстрые команды и поиск используют те же правила; избранное и резерв не расходуются. У сундука остаётся собственная вместимость; улучшение рюкзака её не меняет.
- Крафт/покупка/бартер/замена: сначала вычисляется **весь результат после расхода входов**. Освободившееся ингредиентом место можно занять выходом. Затем всё действие принимается целиком или отклоняется без списания монет/ресурсов. Запрещена половина оплаченного рецепта. Изменение максимума партий заранее видно.
- Асинхронный станок: готовый результат остаётся у своего производителя до успешного забора, новая очередь не стирает незабранное. Рюкзак не становится обязательным местом выдачи в момент окончания таймера.
- Урожай/рыбалка/враг: непоместившийся результат остаётся сохраняемой доступной добычей либо у исходного производителя согласно его договору. Нельзя сначала удалить источник, затем потерять отказанный результат.
- Сюжет/ежи/музей/награда: физический остаток ждёт у единственного источника; получение и сюжетный флаг/срок выдачи фиксируются только для фактически принятого результата. Важная непредметная запись квеста не требует искусственного свободного слота.

## Сохранения и старая переполненная сумка

Сохранить реальные стаки, их свойства, стабильные ссылки панели/экипировки, уровень, блокировку собственного выброса, остатки мирового лута. Временные резервы при загрузке либо восстанавливаются с проверкой той же карты/доступной ёмкости, либо безопасно снимаются с остающимся в мире лутом. Сам резерв никогда не является основанием повторно начислить вещь.

Миграция не обрезает старые 5000 дерева до 999 и не выбрасывает лишние виды из-за нового ограничения 60. Сначала создаются совместимые стаки по 999, затем доступные места. При размещении приоритет имеют надетые и обязательные для текущего прогресса вещи: ссылки экипировки не уводятся в недоступный запас, характеристики не теряются. Не поместившееся сохраняется в явно отмеченном разделе **«Из старого сохранения»**, откуда можно только забрать в освободившиеся обычные ячейки. Новые обычные выдачи не могут класть туда вещи. Этот запас не участвует в крафте, продаже и экипировке, пока не перенесён в рюкзак; это путь возврата старого имущества, не бесконечная рабочая сумка. Повтор загрузки не дублирует его.

Полезная добыча и собственные выбросы не удаляются по таймеру декоративных частиц. Для больших скоплений используются общий пространственный поиск, ограничение работы за кадр и безопасное объединение только совместимых свободных записей без особого владельца награды/резерва. Слияние не снимает защиту собственного выброса. Визуальное скрытие далёкого лута не удаляет его из сохранения.

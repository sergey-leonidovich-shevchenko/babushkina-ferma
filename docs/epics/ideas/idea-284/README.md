# IDEA-284 — Шесть тюков — уложить груз перед дорогой

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-284.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Разместить шесть известных тюков на схеме телеги, закрепить хрупкий груз и проверить результат тремя понятными дорожными пробами.

Группа «Дороги и путешествия». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `home` должны быть приняты отдельно.

IDEA-166 управляет торговым караваном, PACK считает слоты/стаки, IDEA-275 проверяет честность весов. Здесь размещение известного груза и крепление перед дорогой, без торговли, скрытой массы и веса каждого предмета героя.

Небольшая локальная модель проверяет удовольствие от логистики раньше больших караванных систем. Стоимость 3/5, риск 3/5 — отдельные гипотезы, не сроки.

# IDEA-219 — Ледник — сохранить зимний холод для летнего стола

**proposed / запланированное предложение**, не выполненная механика. Группа «Артель и мастерские». [Подробный дизайн](../../../../wiki/articles/IDEA-219.md) · [Карточки](TASKS.md).

Зима может давать собственную долгую хозяйственную цель. Редкий летний десерт — приятный результат подготовки, при этом обычная еда продолжает храниться без порчи и холодильника.

## Первый выпуск

Один ларь, один безопасный зимний источник, запас 12, три понятных рецепта и запасной летний обмен. Без глобальной термодинамики и новых скоропортящихся предметов.

## Владение, условия и границы

icehouse-ID, stored-count, harvest-season-count, next-melt-day и claimed-exchange-key. Единый календарь считает срок; кухня владеет уже зарезервированным льдом. Лёд в ларе и в queued inputs не считается одновременно.

После VMAP-003; игровой календарь, кухня, PACK и общая модель станка. Первая заготовка с разрешённой безопасной кромки зимой; северная экспедиция не блокер.

IDEA-171 тратит тепло героя в холодном районе; текущие fermenter/preserver готовят за секунды и не портят пищу. Ледник хранит ограниченный сезонный ресурс, а не вводит общий decay еды или необходимость согревать усадьбу.

## Этапы

1. Согласовать сезонный запас без порчи обычной еды
2. Наполнить один утеплённый ледник
3. Показать и сохранить дату таяния
4. Приготовить три холодных блюда и летний обмен
5. Принять два сезона и интерес к заготовке

## Оценка и порядок

P3 / L; польза 3, интерес 4, соответствие 5, связи 5, ценность 82/100, стоимость 4, риск 4. Знакомость не проверена, уверенность — гипотеза. Четверо из пяти игроков предсказывают оставшийся запас, трое хотят зимнюю заготовку без уникального бафа; иначе убрать пассивное таяние.

Расширение: Позже разовая артельная зимняя доставка и праздничный десерт для Общего Котла. Работники не добывают лёд бесконечно и не обязаны каждый день обслуживать ларь.

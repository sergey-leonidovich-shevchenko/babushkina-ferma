# IDEA-297 — Сани без лошади — добровольный спуск по северному склону

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-297.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

Спуститься на деревянных санях по одному авторскому снежному маршруту: выбирать полосу и торможение, заранее видеть препятствия и иметь безопасный сход в каждом участке.

Группа «Дороги и путешествия». 5 предметных будущих этапов, все backlog. Первый полезный выпуск — frost_sled_lane; Три полосы ×120 рядов, четыре укрытия и площадки 12×8 на обоих концах. Геометрия/рабочая зона принадлежит IDEA-297-02, родитель frost требует отдельной готовности.

IDEA-162 — забота о ездящем ослике, IDEA-183 — поездка пассажиром, IDEA-280 — речная эстафета из открытого PR22. Здесь самостоятельное управление скоростью на одном заранее видимом склоне; нет животного, расписания рейса или переброски управления напарнику.

Новое движение дорого и требует сохранности контроллера. Сначала схема и один учебный сегмент, затем полный склон; до готовности севера карточки не ready. Стоимость 5/5 и риск 4/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

# IDEA-288 — Вверх по ступеням — провести косяк через рыбью лестницу

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-288.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Настроить три небольших бассейна и два затвора так, чтобы группа рыб постепенно прошла к верхней воде без сильного сброса и высушивания нижней чаши.

Группа «Мир и природа». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `ivy` должны быть приняты отдельно.

IDEA-176 разводит рыбу в питомнике, 193 поливает канавками, 220 обсуждает распределение воды, IDEA-002 рисует косяки. Здесь локальная дискретная миграция группы между чашами; нет размножения, новой водной экономики или общего спора о правах.

Сильное наблюдаемое последствие, но нужен ограниченный водный owner и ясное отличие от питомника. Стоимость 5/5, риск 4/5 — отдельные гипотезы, не сроки.

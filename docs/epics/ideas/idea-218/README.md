# IDEA-218 — Слушать камень — найти полость по трём откликам

**proposed / запланированное предложение**, не выполненная механика. Группа «Большие занятия и тайны долины». [Подробный дизайн](../../../../wiki/articles/IDEA-218.md) · [Карточки](TASKS.md).

Исследование подземелья может вознаграждать внимательность, а не только боевую силу. Игрок сам делает вывод и чувствует себя исследователем, даже если пользуется текстовым описанием звука.

## Первый выпуск

Учебный образец, одна ниша, три фиксированных отклика, одна историческая записка и обычный декоративный камень; без обязательного сюжетного ключа.

## Владение, условия и границы

room-ID, трёхбитная маска услышанного, выбранная версия, opened и запись-контейнер у WORLD-04. Аудиоплеер временный. CaveLayout хранит авторскую геометрию и не доверяет координатам из текста дневника.

После VMAP-003; CaveLayout, действующий доступ к комнате, одноразовый контейнер WORLD-04, журнал исследования. Авторская ниша в уже открытой комнате, без новой процедурной геологии.

ECHO повторяет движения героя, IDEA-187 вращает замок, RELIC восстанавливает предмет, IDEA-199 читает приметы маршрута. Здесь эксперимент с тремя откликами стены и одним выводом. Не сканер всех руд и не генератор любого прохода UNDERWAY.

## Этапы

1. Написать честный контраст трёх каменных откликов
2. Поставить три авторские точки и безопасную нишу
3. Сохранить наблюдения и выбранную версию
4. Открыть один тайник и запись мастера
5. Принять загадку со звуком и без него

## Оценка и порядок

P3 / L; польза 3, интерес 5, соответствие 5, связи 4, ценность 85/100, стоимость 4, риск 3. Знакомость не проверена, уверенность — гипотеза. Четверо из пяти игроков выбирают нужную точку с отключённым звуком по тем же наблюдениям; трое хотят вторую загадку.

Расширение: Две дополнительные комнаты с иным материалом и тройкой признаков, затем возможная связка с RELIC-основанием. Не расширять в универсальную геофизику до пробы понимания.

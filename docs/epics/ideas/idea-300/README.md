# IDEA-300 — Король у ворот — асимметричная настольная игра жителей

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-300.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

Сыграть за короля с двумя защитниками против четырёх стражей: вывести короля к одним из четырёх ворот, читать захваты и менять сторону после партии.

Группа «Игровые механики». 5 предметных будущих этапов, все backlog. Первый полезный выпуск — copper_board_alcove; 10×8 клеток, один стол; UI поле 7×7 с семью фигурами. Геометрия/рабочая зона принадлежит IDEA-300-03, родитель copper требует отдельной готовности.

065 соединяет канавки костяшками на 4×4, 196 строит колоду карт. Новый цикл — открытая асимметричная позиция/движение/захват семи фигур; он не переименовывает одну из прежних игр и не создаёт ставочный лут.

Нужна отдельная проверка интереса и правил, прежде чем делать соперников/турнир. Не приоритетнее удобного журнала и одной личной истории. Стоимость 4/5 и риск 4/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

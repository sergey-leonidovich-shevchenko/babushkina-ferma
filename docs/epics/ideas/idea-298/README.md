# IDEA-298 — Комната наоборот — наблюдать мир через камеру-обскуру

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-298.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

В тёмной палатке настроить отверстие и экран, узнать знакомую пристань в перевёрнутой проекции и помочь мастеру объяснить наблюдение без магического изменения мира.

Группа «Большие занятия и тайны долины». 4 предметных будущих этапов, все backlog. Первый полезный выпуск — salt_obscura_tent; 12×10 клеток палатки; внутри одна панель 256×256 и три авторских объекта снаружи. Геометрия/рабочая зона принадлежит IDEA-298-02, родитель salt требует отдельной готовности.

IDEA-119 — зарисовки натуралиста, IDEA-267 — портрет по чужим словам, IDEA-282 — выбор слоя росписи. Здесь настройка источника/экрана и перевёрнутая проекция известных объектов; нет художественного копирования, реставрации или чтения скрытого мира.

Небольшое добровольное открытие с сильной графической обратной связью; сначала бумажный опыт, потом ограниченный render target. Стоимость 4/5 и риск 3/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

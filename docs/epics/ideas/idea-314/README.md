# IDEA-314 — Шаг навстречу — выучить парный деревенский танец

**Предложение proposed; игровой реализации нет.** Все игровые этапы backlog. Реализация после VMAP-003, отдельного одобрения и перечисленных зависимостей; текущая очередь03→07→06→первой overworld сохраняется.

**Группа:** Истории и жители. **Приоритет/сложность:** P2/L.

Разучить с жительницей короткую фигуру: подойти, отойти, сменить сторону и сделать совместный поклон. Игрок выбирает удобный темп и видит согласие партнёра.

**Польза:** Делает знакомство телесным и запоминающимся без обязательной романтики. Освоенное движение можно повторить на обычной площади, а не только ждать годового праздника.

# IDEA-243 — Две песни о мосте — история без всеведущего ответа

**proposed; не реализовано.** Группа «Истории и жители». 4 собственных карточек backlog, без сборного дневного эпика. [Статья](../../../../wiki/articles/IDEA-243.md) · [Задачи](TASKS.md).

Два жителя хранят несовпадающие семейные версии старого события. Игрок разделяет наблюдаемые факты и воспоминания и выбирает честную музейную подпись, сохраняя неопределённость.

## Первый полезный выпуск

Две семейные версии, три осмотра и две честные таблички плюс возможность отложить. Дальше — ещё один голос только после проверки, что игрок не воспринимает неопределённость как недоделку.

## Собственный результат и внешние владельцы

RELIC восстанавливает конкретные древности; CASE проверяет факты дел; IDEA-180 переводит язык. Новый цикл не создаёт четвёртое расследование с “3/3 = виновный”. В PR №6 Северина хранит частную семейную тайну: здесь обе женщины заранее разрешают публиковать именно свои версии, приватные сведения не добываются.

Новый предлагаемый наружный карман old_moon_gauge, «Старый лунный водомер», 18×14 клеток от village_river. Это небольшой тупик с одним входом, старой опорой и тремя видимыми отметками. Не новый короткий путь и не переписывание восьми глав main. Место вводит IDEA-243-02; его нет в игре.

Постановка диалогов из PR №6 принята в main; игровая IDEA-232-04 остаётся backlog и теперь формально блокирует использующие её этапы. Принятие документации не реализует адаптер. Приоритет VMAP-003 сохраняется; предложения ещё не одобрены.

## Этапы

1. Проверить две песни и предел доказуемого: Принять авторскую таблицу: три наблюдения, две семейные версии, две таблички.
2. Подготовить карман старого лунного водомера: Один вход 18×14, три осмотра, безопасный путь и крупные карточки деталей.
3. Связать голоса с одной музейной подписью: Два разговора, раздельные источники, согласие, предпросмотр и один commit подписи.
4. Принять историю моста без правильной семьи: F243-01…06, журнал/музей/слоты, малая проба.

# IDEA-290 — Флаг не просьба наугад — береговая переписка четырьмя сигналами

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-290.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Принять и передать короткий видимый код между берегом и ожидающей лодкой, сверив значение и полномочие отправителя; намеренная ложная тревога имеет понятное последствие.

Группа «Истории и жители». 5 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `salt` должны быть приняты отдельно.

IDEA-272 в PR22 освещает путь перевозчику, 245 учит три жеста, 271 поддерживает легенду посыльного. Здесь опубликованный код/сверка адресата/подтверждение приёма; нет маршрута света, расшифровки неизвестного языка или переодевания.

Сильная связь речи с видимым действием; протокол и намерение стоит проверить раньше анимаций далёких лодок. Стоимость 4/5, риск 4/5 — отдельные гипотезы, не сроки.

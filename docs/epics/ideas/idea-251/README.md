# IDEA-251 — Одолжить свой топор — сосед пользуется той же вещью и возвращает её

**proposed; не реализовано.** Группа «Предметы и снаряжение». 5 собственных карточек backlog, без сборного дневного эпика. [Статья](../../../../wiki/articles/IDEA-251.md) · [Задачи](TASKS.md).

Добровольно дать жителю запасной инструмент на короткое дело, увидеть его в работе и получить обратно тот же экземпляр; долг хранится явно, а полный рюкзак не уничтожает возврат.

## Первый полезный выпуск

Один добровольный заём простого запасного axe, наблюдаемая работа, досрочный запрос и автоматический возврат без износа. После приёмки — другой вид инструмента и отдельная история; никаких случайных потерь вещи ради драмы.

## Собственный результат и внешние владельцы

В текущем InventorySystem есть kind axe и экипировка hands; общей идентичности каждого такого экземпляра для займа ещё нет. IDEA-221 уже назначила единый instance-record, IDEA-207 возвращает семена урожаем, IDEA-225 в PR №2 арендует чужой станок. Здесь возврат того же личного инструмента, не семенной кредит, деньги или аренда станка. PACK владеет автоматическим подбором и вместимостью.

Один сосед в village_orchard, один незачарованный запасной axe и один активный заём. Уникальные награды, квестовые предметы, экипированный/закреплённый любимым инструмент и последний доступный топор исключены. До принятия общей identity/transfer из IDEA-221 реализация недоступна.

Разговоры используют опубликованный адаптер IDEA-232-04 из PR №6 после его принятия. Его отсутствие в main обозначено внешним условием игровых карточек, а не замаскировано копией движка. Приоритет VMAP-003 сохраняется; предложения ещё не одобрены.

## Этапы

1. Принять таблицу владения запасным топором: Контракт player/loan/return_ready, фильтр допустимости, due и макет выбора.
2. Передать один допустимый экземпляр Терентию: Общая транзакция owner, фильтр запасного axe и сохранение loan-record.
3. Показать чужую работу и вычислить возврат по игровому дню: Одна небоeвая сцена, next-day 18:00, recall и внешний якорь return_ready.
4. Вернуть тот же топор автоматическим подбором PACK: Радиус две клетки, реальная вместимость, стойка и уведомление после transfer.
5. Принять заём через все слоты и повторы: F251-01…06, сбои transfer, смерть героя, старый save и малая проба.

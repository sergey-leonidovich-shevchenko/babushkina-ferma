# IDEA-286 — Держи нить — воздушный змей над соляным берегом

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-286.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Собрать хвост и длину привязи, затем удержать бумажную птицу в наблюдаемом ветре, выбирая натяжение вместо частого нажатия кнопки.

Группа «Игровые механики». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `salt` должны быть приняты отдельно.

IDEA-101 — праздник ветровых лент, 184 — равновесный мобиль, 216 — ветряной орган, 259 в PR13 — разведка вороном. Здесь управляемый привязанный змей; он не открывает карту, не заменяет птицу и не нужен для фестиваля.

Сначала проверить удовольствие от самого управления; новая физика/камера ради одной игрушки не оправданы. Стоимость 4/5, риск 3/5 — отдельные гипотезы, не сроки.

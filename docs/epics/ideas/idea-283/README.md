# IDEA-283 — Не до синего дерева — составить дорогу, которую поймёт другой

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-283.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Составить маршрут из понятных ориентиров и проверить его глазами путника: двусмысленное указание можно исправить до настоящего отправления.

Группа «Дороги и путешествия». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `home` должны быть приняты отдельно.

IDEA-191 планирует дела героя, IDEA-199 ведёт к кладу, IDEA-205 показывает ферму группе. Здесь формальная проверка понятности чужому путнику: ориентир+действие+проверка, без эскорта и поиска сокровища.

Даёт деревне практическую жизнь и дешёвую бумажную проверку до сложной NPC-интеграции. Стоимость 4/5, риск 3/5 — отдельные гипотезы, не сроки.

# IDEA-217 — Плавучий огород — четыре грядки у спокойного берега

**proposed / запланированное предложение**, не выполненная механика. Группа «Ферма и земледелие». [Подробный дизайн](../../../../wiki/articles/IDEA-217.md) · [Карточки](TASKS.md).

Берег хочется обжить, а растения — выбирать по среде, а не только по цене семян. Плавучие грядки дают маленькую самостоятельную ветвь фермерства и красивое место возвращения.

## Первый выпуск

Четыре плота в одной авторской бухте, один новый обычный вид, три стадии и один конечный урожай; без лодки, штормового разрушения и свободного строительства посреди реки.

## Владение, условия и границы

raft-ID, authored-zone-ID, grid-position, crop-ID и growth/care-stage у единого владельца грядок. WaterLayout только проверяет место. Качание/частицы не сохраняются; старый слот получает пустой список.

После VMAP-003 и отдельного принятия берегового размещения; WorldFarming/CropCatalog, WaterLayout, PACK, опубликованный навигационный контракт. Координаты пилота выбираются после фиксации первой карты, сегодня не размещаются.

IDEA-193 ведёт воду к наземным грядкам, IDEA-176 разводит рыбу, IDEA-117 строит лодку. Здесь закреплённый контейнер с отдельным допустимым водным растением; нет плавания, осушения реки, новых каналов или второго питомника.

## Этапы

1. Разметить единственную безопасную бухту
2. Зарегистрировать водяную зелень и её уход
3. Построить четыре закреплённых плота
4. Выдать урожай и сохранить зимнюю грядку
5. Принять берег вместе с рыбалкой и проходами

## Оценка и порядок

P3 / L; польза 3, интерес 4, соответствие 5, связи 5, ценность 82/100, стоимость 4, риск 4. Знакомость не проверена, уверенность — гипотеза. Четверо из пяти игроков без подсказки находят законный подход, трое хотят оставить плот ради собственного берегового сада.

Расширение: После баланса — декоративный лотос и обмен с речным садовником. Взаимодействие с рыбами вводится отдельным контрактом, чтобы не умножать продукцию двух систем.

Приоритет VMAP-003 и исходные владельцы соседних планов сохраняются. Все карточки backlog; подготовка этого документа не закрывает игровую реализацию. [Отчёт обзора](../../../reports/creative/2026-10-23/README.md).

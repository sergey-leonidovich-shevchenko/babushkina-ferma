# IDEA-316 — Три голоса площади — собрать добровольный ансамбль

**Предложение proposed; игровой реализации нет.** Все игровые этапы backlog. Реализация после VMAP-003, отдельного одобрения и перечисленных зависимостей; текущая очередь 03 → 07 → 06 → первая overworld сохраняется.

**Группа:** Истории и жители. **Приоритет/сложность:** P2/L.

Познакомиться с тремя взрослыми музыкантами, послушать их короткие партии и собрать один двенадцатидольный проход, где каждому остаётся место.

**Польза:** Жители становятся слышимыми участниками совместного дела. Игрок слышит, как отдельная партия меняет целое, может пробовать без музыкального образования и возвращаться ради своего звучания.

**Проба:** Пять участников создают два различимых варианта;4/5 понимают роль ответа, 3/5 меняют схему ради звучания без нового приза. Для неслышащих проверить полноценность визуальной схемы.

**Расширение:** После хороших stems — одно приглашённое совместимое соло. Неограниченный редактор аудио, сетевой концерт и разведение исполнителей не входят.

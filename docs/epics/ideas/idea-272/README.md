# IDEA-272 — До следующего огня — световая дорожка для перевозчика

**proposed, не реализовано.** Группа «Дороги и путешествия», 4 собственных будущих карточки backlog. [Подробный дизайн](../../../../wiki/articles/IDEA-272.md) · [Задачи](TASKS.md).

Перевозчик знает путь, но не решается пройти тёмный промежуток. Игрок собирает цепочку трёх устойчивых источников света; после совместного прохода житель сам начинает пользоваться дорогой.

## Первый полезный выпуск

Один участок, три опоры, два законченных финала и один последующий проход NPC. Расширение — другие жители с собственными причинами; универсального лечения страха и массовой ночной навигации нет.

## Владелец и отличие

IDEA-233 — срочное сопровождение раненого с врагами; IDEA-171 — холод и тепло героя; IDEA-260 — передача фонарной службы. Здесь неизменяемая физическая тропа становится понятной конкретному NPC по связности света. Нет таймера смерти и общей шкалы психики.

Общий игровой адаптер IDEA-232-04 ещё backlog и блокирует использующие его этапы. Бумажный этап 01 имеет самостоятельную приёмку. Отдельные межэпиковые зависимости смотрите в TASKS. Не менять чужой owner состояния, всё игровое после VMAP-003/одобрения.

## Предметные этапы

1. **IDEA-272-01 — Нарисовать три опоры и оба равноправных финала.** Бумажная схема связности с шестью закрытиями прохода.
2. **IDEA-272-02 — Связать опоры с фактическим светом и остановкой Остена.** Один световой маршрут и общий диалог; загрузка у safe anchor.
3. **IDEA-272-03 — Открыть выбранный последующий распорядок.** Один дневной либо ночной проход без героя, без выдачи предметов.
4. **IDEA-272-04 — Принять связность и уважительный тон.** F272-01…06, native light/occlusion и малая проба.

# IDEA-302 — Склад одного шага — раздвинуть ящики, думая о пути назад

**Предложение, не реализовано.** [Статья](../../../../wiki/articles/IDEA-302.md) · [Этапы](TASKS.md) · [Места](../../../../wiki/articles/new-pursuits-register.md).

Небольшая пространственная головоломка: герой толкает учебные ящики по клеткам, освобождая нужные места. Ошибку можно отменить, а не оплачивать потерянным грузом.

Группа «Игровые механики»; 4 будущих этапов backlog. Первый выпуск: camp_push_store, помост 12×10; учебное поле 7×7 внутри UI/локальной сцены. Один владелец геометрии IDEA-302-02. Родитель camp требует готовности.

Обычные Nav и движение есть; физического толкания содержимого сундуков нет. ECHO записывает действия двойника, IDEA-284 укладывает фигуры груза в площадь, PACK хранит настоящие вещи. Здесь состояние доступности клеток после последовательных толчков. Учебные ящики не контейнеры и не второй инвентарь.

Один законченный маленький стенд даст ранний ответ об интересе; системной физики грузов не требует. Стоимость 3/5, риск 3/5 — гипотезы. Игровые блокеры: VMAP-003, IDEA-232-04; ни одна карточка не ready автоматически.

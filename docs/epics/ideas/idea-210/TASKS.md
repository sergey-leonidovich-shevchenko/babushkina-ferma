# Раскол по прожилке — добыть целый каменный блок

**Свой эпик IDEA-210.** [Паспорт](README.md) · [Дизайн](../../../../wiki/articles/IDEA-210.md). Группа «Артель и мастерские». Игровая реализация не выполнена; все 6 этапов — будущие.

**Контракт интеграции:** Автоматический подбор и полная сумка в этой статье — будущий контракт PACK-02/03/05/06/17. Сам раскол не добавляет отдельную сетку сумки или обход общего владельца выдачи.

**Внешние условия:** VMAP-003, отдельное одобрение идеи и зависимости паспорта. Числа дизайна — гипотезы для малой пробы. Первая карточка не становится Ready из-за высокого рейтинга.

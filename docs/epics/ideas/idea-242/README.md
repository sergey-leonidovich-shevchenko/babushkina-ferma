Постановка диалогов из PR №6 принята в main; игровая IDEA-232-04 остаётся backlog и теперь формально блокирует использующие её этапы. Принятие документации не реализует адаптер. Приоритет VMAP-003 сохраняется; предложения ещё не одобрены.

## Этапы

1. Принять три операции Беренды на бумажном стенде: Разметить две опоры, три жеста и таблицу переходов, включая перехват.
2. Собрать рабочую точку с двусторонним подтверждением: Один эпизод захвата и перехвата, шаг 0…2, пауза и загрузка.
3. Показать две ручки и память о совместной работе: Предпросмотр wide/narrow, единственная финальная бочка и последующая реплика.
4. Принять помощь Беренде в реальной деревне: Шесть сценариев, оба направления подхода, звук off и малая проба.

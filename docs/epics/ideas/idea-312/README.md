# IDEA-312 — Нос ведёт к дому — искать вместе с обученной собакой

**Предложение proposed; игровой реализации нет.** Все игровые этапы backlog. Реализация после VMAP-003, отдельного одобрения и перечисленных зависимостей; текущая очередь03→07→06→первой overworld сохраняется.

**Группа:** Мир и природа. **Приоритет/сложность:** P2/L.

Дать собаке понюхать знакомую вещь, читать её поведение у развилок и вместе найти потерянную дорожную сумку. Игрок решает, где возобновить след и когда дать собаке передышку.

**Польза:** У поиска появляется живой напарник и понятная обратная связь. Интерес — замечать изменение поведения и уточнять маршрут, а не непрерывно смотреть на стрелку к готовой награде.

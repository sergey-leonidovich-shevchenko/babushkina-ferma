# IDEA-289 — Тень указывает полдень — калибровка солнечных часов

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-289.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Сопоставить несколько подписанных положений тени с делениями, развернуть циферблат и получить работающую деревенскую отметку времени вместо магической перемотки суток.

Группа «Большие занятия и тайны долины». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `copper` должны быть приняты отдельно.

IDEA-174 собирает ночной звёздный атлас, 158 планирует погоду, 096 — босс времени. Здесь дневная калибровка одного прибора по наблюдениям; нет астрономии всего мира, бафа времени или перемотки квестовых дедлайнов.

Ограниченный прибор полезен для атмосферы дня; сначала исключить ожидание как пустую повинность. Стоимость 4/5, риск 3/5 — отдельные гипотезы, не сроки.

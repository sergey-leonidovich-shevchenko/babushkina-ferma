# Семенная библиотека — взять пакет и вернуть часть своего урожая

**Свой эпик IDEA-207.** [Паспорт](README.md) · [Дизайн](../../../../wiki/articles/IDEA-207.md). Группа «Ферма и земледелие». Игровая реализация не выполнена; все 5 этапов — будущие.

Попробовать незнакомую обычную культуру без покупки большого запаса, а затем вернуть библиотеке небольшой новый пакет. Это мягкая взаимопомощь и повод разнообразить огород; пропуск сезона не становится долговой ловушкой.

**Контракт интеграции:** Конечные стаки и расчёт вместимости здесь — зависимость от открытых PACK-02/03/05/11, а не возможность нынешнего inventory_system: текущий ensure_item_slot добавляет слоты. Библиотека не реализует свою отдельную вместимость. Пилотные пары item-ID: seeds→carrot, cabbage_seeds→cabbage, wheat_seeds→wheat; из них показываются только пригодные по действующему сезонному каталогу. Если пригодны два вида, третье место не заполняется выдуманной культурой.

**Внешние условия:** VMAP-003, отдельное одобрение идеи и зависимости паспорта. Числа дизайна — гипотезы для малой пробы. Первая карточка не становится Ready из-за высокого рейтинга.

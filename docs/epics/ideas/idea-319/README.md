# IDEA-319 — Листоплан над уступом — короткий полёт с читаемым ветром

**Предложение proposed; игровой реализации нет.** Все игровые этапы backlog. Реализация после VMAP-003, отдельного одобрения и перечисленных зависимостей; текущая очередь03→07→06→первой overworld сохраняется.

**Группа:** Дороги и путешествия. **Приоритет/сложность:** P3/XL.

Одолжить лёгкое крыло из большого листа и пройти ограниченный воздушный маршрут между тремя опорами. Выбирать полосу потока и безопасно садиться, сохраняя возможность отказаться.

**Польза:** Показывает знакомый склон сверху и даёт освоение движения в воздухе. Первый маршрут — самостоятельная прогулка с наблюдаемым выбором, без обещания полёта через весь мир.

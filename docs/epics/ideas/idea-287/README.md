# IDEA-287 — Ниже ряби — составить фарватер по собственным промерам

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-287.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

С берега промерить авторский участок воды мерной линией, связать наблюдения в карту глубин и выбрать проход для лодки с заданной осадкой.

Группа «Дороги и путешествия». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `ivy` должны быть приняты отдельно.

IDEA-117 строит собственную лодку, 183 даёт паром по расписанию, 199 ищет клад. Здесь девять промеров/проверка осадки; нет управления лодкой, затонувшего приза или нового глобального водного физического мира.

Небольшая авторская маска даёт содержательное исследование без собственной системы судоходства. Стоимость 4/5, риск 4/5 — отдельные гипотезы, не сроки.

# IDEA-231 — Лагерные смены — враги с понятным распорядком: задачи

[Паспорт](README.md) · [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-231.md)

**Первый выпуск:** Один лагерь/три актёра/два окна, бытовая смена, обычная тревога и один добровольный обход. Не глобальный распорядок всех монстров и не вражеская экономика.

**Контракт состояния:** CampSchedule у encounter-ID: три устойчивых actor-ID, routine-phase и author-anchor. CombatSystem владеет HP/агро/смертью, WorldClock временем, LootContainer добычей. Мёртвый актёр не воскрешается на следующей смене.

**Внешние условия:** После VMAP-003; CombatSystem, игровой календарь, авторские cardinal-пути и приёмка скрытности 118 для тихого варианта. Бой и обычный подход доступны без перка; новый график не создаёт отдельного владельца агро. Указание класса/плана не означает готовую зависимость. Новая система не дублирует владельцев соседних эпиков.

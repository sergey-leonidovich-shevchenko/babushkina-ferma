# IDEA-231 — Лагерные смены — враги с понятным распорядком

**Предложение, P3 / L, группа «Бой и бестиарий».** [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-231.md) · [Карточки](TASKS.md).

В одном необязательном вражеском лагере наблюдать смену караула, готовку и уход сборщика, выбирая удобное окно для прохода. Локация должна восприниматься обитаемой. Наблюдение за бытовым распорядком даёт альтернативный способ подготовиться к опасному месту и понять роли врагов.

## Первый выпуск

Один лагерь/три актёра/два окна, бытовая смена, обычная тревога и один добровольный обход. Не глобальный распорядок всех монстров и не вражеская экономика.

## Владение, условия и границы

CampSchedule у encounter-ID: три устойчивых actor-ID, routine-phase и author-anchor. CombatSystem владеет HP/агро/смертью, WorldClock временем, LootContainer добычей. Мёртвый актёр не воскрешается на следующей смене.

После VMAP-003; CombatSystem, игровой календарь, авторские cardinal-пути и приёмка скрытности 118 для тихого варианта. Бой и обычный подход доступны без перка; новый график не создаёт отдельного владельца агро.

IDEA-118 задаёт укрытие, отвлечение и подозрение одного дозорного. Бестиарий 073 задаёт боевую роль. Здесь только календарный выбор мирного занятия/точки возврата трёх уже существующих актёров; обнаружение/атаки остаются у тех систем.

## Этапы

1. Составить две смены и безопасные приметы лагеря
2. Привязать график к трём устойчивым актёрам
3. Отдать приоритет тревоге и поиску
4. Провести законные пути смены
5. Показать быт без бесконечного производства
6. Принять бой, обход и бюджет трёх актёров

## Оценка и порядок

Польза 4, интерес 5, соответствие 5, связи 5, ценность 94/100; стоимость 4, риск 4; знакомость не проверена для точной механики. Уверенность — гипотеза. Четверо из пяти игроков замечают одну примету до смены; трое выбирают обход, понимая доступность обычного боя.

Расширение: Ещё один лагерь с иной схемой после проверки боя, сохранений и реального бюджета. Ночной сон, провиант и нападения других фракций отдельно согласуются.

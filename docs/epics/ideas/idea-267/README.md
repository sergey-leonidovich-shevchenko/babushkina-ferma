# IDEA-267 — Портрет по памяти — нарисовать человека, которого герой не видел

**proposed, не реализовано.** Группа «Дом и трофеи», 4 собственных будущих карточки backlog. [Подробный дизайн](../../../../wiki/articles/IDEA-267.md) · [Задачи](TASKS.md).

Житель просит составить портрет близкого по рассказу и честно отделить уверенные детали от догадок. Ценность — узнаваемая привычка и совместное воспоминание, а не попадание в секретную правильную картинку.

## Первый полезный выпуск

Три слоя, два свидетеля и один показ на стене. Далее больше заказчиков и реальные подарочные картины только через общий owner/Inventory; не превращать систему в обязательный редактор всех NPC.

## Владелец и отличие

IDEA-119 — зарисовки наблюдаемой природы, IDEA-200 вышивка, IDEA-243 противоречивые истории и IDEA-121 трофеи. Здесь комбинаторный визуальный портрет отсутствующего человека: автор согласует изображение и степень уверенности. Нет проверки личности/полицейского фоторобота.

Общий игровой адаптер IDEA-232-04 ещё backlog и блокирует использующие его этапы. Бумажный этап 01 имеет самостоятельную приёмку. Отдельные межэпиковые зависимости смотрите в TASKS. Не менять чужой owner состояния, всё игровое после VMAP-003/одобрения.

1. **IDEA-267-01 — Написать воспоминания и восемь читаемых композиций.** Три слоя/два варианта, две памяти платка, описания для чтения.

3. **IDEA-267-03 — Согласовать одну версию и оставить на стене.** author/displayed versions, реплики и альбом без инвентаря.
4. **IDEA-267-04 — Принять портрет и честную неопределённость.** F267-01…06, все 8 композиций и читательская проба.

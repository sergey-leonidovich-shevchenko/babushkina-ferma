# IDEA-299 — С кем знакома долина — журнал только услышанных связей

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-299.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

Записывать знакомые связи жителей с источником и датой: кто у кого учился, кто помогал и кто о ком рассказал. Видеть только то, что герой действительно узнал, и различать слух от наблюдения.

Группа «Игровые механики». 5 предметных будущих этапов, все backlog. Первый полезный выпуск — village_acquaintance_desk; 10×8 клеток у стойки; собственный раздел дневника без новой обязательной карты. Геометрия/рабочая зона принадлежит IDEA-299-03, родитель home требует отдельной готовности.

IDEA-127 — отношения героя, IDEA-204 — доставка новости, IDEA-237 — приватная тайна, CASE — установление фактов дела. Здесь UI знаний игрока с provenance и неизвестными связями; он не симулирует отношения и не подтверждает истинность слуха.

Станет особенно полезно по мере роста NPC; первый выпуск нужен после нескольких принятых историй, а не вместо разработки этих историй. Стоимость 4/5 и риск 4/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

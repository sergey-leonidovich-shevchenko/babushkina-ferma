# IDEA-216 — Ветряной орган — собрать музыку своего двора

**proposed / запланированное предложение**, не выполненная механика. Группа «Дом и трофеи». [Подробный дизайн](../../../../wiki/articles/IDEA-216.md) · [Карточки](TASKS.md).

Хочется не просто поставить дорогую декорацию, а услышать собственный двор. Понятный опыт со звуком даёт авторство без обязательного музыкального образования.

## Первый выпуск

Один орган, пять нот, восемь долей, пробный мех, один погодный запуск и тихий мьют; без MIDI, пользовательских аудиофайлов и обязательной награды.

## Владение, условия и границы

instrument-ID, recipe-revision, note-indices, gate-grid и muted. Момент проигрывания временный, не восстанавливается из save как старый порыв. Общие настройки звука принадлежат SettingsSystem.

После VMAP-003; отдельный простой погодный профиль порывов, аудиобюджет и настройки громкости. VillageGroundClock/PostMotionFrame — только пример владения временем. Не читать GPU и не добавлять мировую CFD-симуляцию ради пяти труб.

IDEA-120 — ручная свирель и запоминаемые мелодии, IDEA-184 — равновесный мобиль без музыкальной настройки, VILLAGE — бытовая подвеска. Новое — конструирование слышимой пятинотной схемы заслонок с пробным мехом. Праздник ветра IDEA-101 может позднее показать готовую композицию.

## Этапы

1. Определить пять нот и отдельный погодный триггер
2. Собрать редактор заслонок пять на восемь
3. Изготовить и сохранить один дворный инструмент
4. Проиграть порыв с ограниченной полифонией
5. Принять звучащий двор и доступное отключение

## Оценка и порядок

P3 / L; польза 2, интерес 5, соответствие 5, связи 4, ценность 79/100, стоимость 4, риск 3. Знакомость не проверена, уверенность — гипотеза. Трое из пяти игроков делают второй вариант ради звучания; все могут заглушить орган одним понятным действием.

Расширение: После проверки — обмен чистыми схемами с мастером и праздничный дуэт двух авторских инструментов с тем же общим бюджетом голосов.

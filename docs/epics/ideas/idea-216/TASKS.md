# IDEA-216 — Ветряной орган — собрать музыку своего двора: задачи

[Паспорт](README.md) · [Игровой дизайн и шесть сценариев](../../../../wiki/articles/IDEA-216.md)

Один орган, пять нот, восемь долей, пробный мех, один погодный запуск и тихий мьют; без MIDI, пользовательских аудиофайлов и обязательной награды.

**Контракт состояния:** instrument-ID, recipe-revision, note-indices, gate-grid и muted. Момент проигрывания временный, не восстанавливается из save как старый порыв. Общие настройки звука принадлежат SettingsSystem.

**Внешние условия:** После VMAP-003; отдельный простой погодный профиль порывов, аудиобюджет и настройки громкости. VillageGroundClock/PostMotionFrame — только пример владения временем. Не читать GPU и не добавлять мировую CFD-симуляцию ради пяти труб. Одобрение IDEA-216 необходимо отдельно. Эти карточки не входят в очередь текущего визуального переноса. Связанные источники не становятся вторыми владельцами.

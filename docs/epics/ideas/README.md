90 отдельных эпиков, 469 будущих карточек. Диапазон 222…231 отдельно опубликован в открытом PR №2 и здесь не импортирован повторно. У каждой механики свой владелец, тематическая группа, подробный первый выпуск, оценка и предметные задачи. Дата относится к обзору, а не объединяет игровые эпики. Все предложения остаются в прежних статусах; курс первой overworld до VMAP-003 сохраняется.

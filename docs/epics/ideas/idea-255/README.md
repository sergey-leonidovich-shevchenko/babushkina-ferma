# IDEA-255 — Под белой крышей — убежище, где враги соблюдают перемирие

**proposed; не реализовано.** Группа «Истории и жители». 5 будущих карточек backlog. [Полный дизайн](../../../../wiki/articles/IDEA-255.md) · [Задачи](TASKS.md).

Создать место, где человек из враждебной стороны впервые разговаривает без оружия. Игрок решает, уважать ли общий договор, предложить обмен сведениями или уйти. Это даёт альтернативу немедленному убийству и показывает цену работающего нейтралитета.

## Первый выпуск

Одна комната на дороге, хозяйка Мелга, раненый противник Борда и преследователь Фейн. Один договор, три разрешённых мирных исхода; убежище не даёт бессмертие в открытом мире и не лечит бесконечно.

## Границы и зависимости

IDEA-181 меняет отношение лагеря, 239 принимает сдачу, PR №2 IDEA-224 планирует выздоровление путника. Здесь локальный договор места между уже враждебными сторонами, без рекрутинга и медицинского производства. HURT владеет уроном и 1…5 с передышки; она не растягивается посещением. Общая диалоговая сессия IDEA-232-04 должна владеть паузой. Принятые QA видимости VFOLIAGE-010 не являются допуском новых боевых правил.

Предлагается white_roof, «Белая крыша», 16×12, боковой тупик будущего междеревенского пути, один закрываемый вход и две внешние безопасные точки ухода. Ни торговый маршрут, ни короткий путь не перекрываются.

## Этапы

1. Принять правила комнаты и три добровольных выхода — Матрица consent/outcome, безопасная ветка отказа, граница без глобальной фракционной амнистии.
2. Поставить Белую крышу и два внешних якоря — Один закрытый вход, доступный обход и отдельные точки ухода; ни одной обязательной дороги через комнату.
3. Провести допуск через общего владельца боя — Проверка active combat на переходе, отсутствие лечения/сброса HURT, запрет действий без расхода.
4. Развести Борду и Фейна по написанному договору — Диалог, добровольная записка, расписания отхода и один сохранённый результат.
5. Принять перемирие и попытки использовать порог в бою — F255-01…06 плюс стрелы/посох/два спутника; HURT и основной маршрут неизменны.

## Оценка

Польза 3, интерес 5, соответствие 4, связи 5 (шкала 1–5); ценность 83/100; стоимость 5, риск 5. P3 / XL, дизайнерская гипотеза. На читке четверо из пяти понимают договор до входа и последствия нарушения; трое предпочитают выслушать Борду без обещания материальной выгоды.

Все F255-01…06 и пробы только запланированы. Реализация после REFACTOR-01→02→03→06, VMAP-003 и отдельного одобрения; подготовительный дизайн не требует будущего игрового адаптера.

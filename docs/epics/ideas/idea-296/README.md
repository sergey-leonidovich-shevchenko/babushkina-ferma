# IDEA-296 — Два дома после одного — помочь паре разъехаться по согласию

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-296.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

Знакомая пара просит помощи с раздельным бытом. Можно поддержать пробное проживание порознь, окончательный разъезд или отказаться от посредничества; счастливый финал не обязан означать примирение.

Группа «Отношения и семья». 4 предметных будущих этапов, все backlog. Первый полезный выпуск — village_two_doors; 14×10 клеток общего дворика и двух фасадных дверей; без двух новых интерьеров в первом выпуске. Геометрия/рабочая зона принадлежит IDEA-296-02, родитель home требует отдельной готовности.

IDEA-145 соединяет новую пару письмами/дорогой; IDEA-252 делит наследство; IDEA-203 обустраивает комнату. Здесь уже существующие взрослые партнёры выбирают раздельный быт и сохраняют право не мириться. Вещи — пять NPC-owned маркеров, не имущественная мини-игра о смерти.

Небольшая сцена даёт отношениям редкую честную развилку; главное — сначала принять тон и ясность согласия, потом менять распорядки. Стоимость 4/5 и риск 4/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

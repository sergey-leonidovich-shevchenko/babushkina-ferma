# IDEA-214 — Сырная клеть — выбрать характер выдержанной партии: задачи

[Паспорт](README.md) · [Игровой дизайн и шесть сценариев](../../../../wiki/articles/IDEA-214.md)

Одна клеть на две полки, две корки, три стадии, один переворот и выдача варианта без преимущества продажи. Три образца знакомят без вложения ресурсов.

**Контракт состояния:** batch-ID, inputs, rind-ID, start-day, flipped, stage, claimed. Каждая полка содержит только ссылку на свою партию; вариант выдачи определяется этим паспортом. Сохранять числовые/строковые данные, не текстуру среза.

**Внешние условия:** После VMAP-003; PACK-транзакции, ProductionQueue для исходного сыра, игровой календарь, общая модель вариантов предмета. Настройка партии — отдельный малый владелец, а не смена всех производственных очередей на дни. Одобрение IDEA-214 необходимо отдельно. Эти карточки не входят в очередь текущего визуального переноса. Связанные источники не становятся вторыми владельцами.

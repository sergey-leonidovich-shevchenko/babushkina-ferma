# IDEA-214 — Сырная клеть — выбрать характер выдержанной партии

**proposed / запланированное предложение**, не выполненная механика. Группа «Артель и мастерские». [Подробный дизайн](../../../../wiki/articles/IDEA-214.md) · [Карточки](TASKS.md).

Молоко хочется превращать в собственный узнаваемый продукт, а не каждый раз нажимать один рецепт. Игрок выбирает вкус и срок, наблюдает срез и решает, когда партия готова для его стола.

## Первый выпуск

Одна клеть на две полки, две корки, три стадии, один переворот и выдача варианта без преимущества продажи. Три образца знакомят без вложения ресурсов.

## Владение, условия и границы

batch-ID, inputs, rind-ID, start-day, flipped, stage, claimed. Каждая полка содержит только ссылку на свою партию; вариант выдачи определяется этим паспортом. Сохранять числовые/строковые данные, не текстуру среза.

После VMAP-003; PACK-транзакции, ProductionQueue для исходного сыра, игровой календарь, общая модель вариантов предмета. Настройка партии — отдельный малый владелец, а не смена всех производственных очередей на дни.

IDEA-157 придумывает вкусовой рецепт, IDEA-175 формирует мёд от цветов, нынешний fermenter производит готовый aged_cheese. Отличие — одно сохраняемое сырное колесо, две реальные манипуляции и решение о снятии. Не добавлять вторую общую систему качества всей еды.

## Этапы

1. Связать опыт с существующим сыром без замены рецепта
2. Заложить две партии по смете
3. Провести три стадии и один переворот
4. Показать срез и выдать выбранные две порции
5. Принять вкус, сохранность и отсутствие денежного цикла

## Оценка и порядок

P3 / L; польза 3, интерес 4, соответствие 5, связи 5, ценность 82/100, стоимость 4, риск 4. Знакомость не проверена, уверенность — гипотеза. Трое из пяти игроков выбирают вторую корку ради вкуса, а не ожидаемой прибыли; все отличают опыт от старого рецепта 40 секунд.

Расширение: После проверки экономики — любимые сорта конкретных работников и дегустационная выставка. Надбавки торговли и новые ингредиенты отдельно балансируются, не входят в MVP.

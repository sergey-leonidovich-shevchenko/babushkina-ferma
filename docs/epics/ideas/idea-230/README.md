# IDEA-230 — Облик поверх снаряжения — одежда по своему вкусу

**Предложение, P2 / L, группа «Предметы и снаряжение».** [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-230.md) · [Карточки](TASKS.md).

Выбрать дорожную шляпу и накидку для внешнего вида, сохраняя реальные характеристики надетого снаряжения. Любимая одежда не должна становиться бесполезной только из-за нового шлема с лучшей защитой. Игрок выражает характер героя, продолжая пользоваться найденными вещами.

## Первый выпуск

Одна шляпа и накидка как отдельные косметические образцы, коллекция, два ключа вида и полная регрессия всех нынешних действий героя.

## Владение, условия и границы

CosmeticCollection: unlocked-style-IDs и два selected-style-key. EquipmentState владеет настоящими предметами/статами; HeroVisual читает композицию. Никаких runtime-текстур в JSON и второго применения item effects.

После VMAP-003; HeroVisual и полный реестр штатных действий/ракурсов, оборудование у InventoryState, PACK и отдельная коллекция открытых косметических образцов. Первый выпуск — два новых специально косметических образца, не переработка всех нынешних доспехов.

IDEA-164 сохраняет реальные комплекты экипировки, IDEA-156 окрашивает ткань, IDEA-121 выставляет трофей. Здесь два независимых ключа отображения; перестановка визуального образа не снимает броню и не пересчитывает перки.

## Этапы

1. Разделить оборудование и два косметических ключа
2. Открывать образец одной передачей в коллекцию
3. Подготовить две одежды на всех штатных кадрах
4. Собрать понятный гардероб и сохранение вида
5. Принять внешний вид без изменения боя

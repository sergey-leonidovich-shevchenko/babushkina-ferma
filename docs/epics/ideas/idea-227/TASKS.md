# IDEA-227 — Договор трёх поставок — заранее планировать небольшой сбыт: задачи

[Паспорт](README.md) · [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-227.md)

**Первый выпуск:** Один покупатель и товар, три фиксированных окна, целые передачи и честный безопасный отказ; без гарантии прибыли, будущих цен рынка и автоматической доставки.

**Контракт состояния:** ContractState получает отдельный конечный multi-delivery-record: agreement-ID, item/price/start-day, три shipment-state и последний день нового предложения. Склад/монеты изменяет общая транзакция, не UI календаря.

**Внешние условия:** После VMAP-003; ContractState, календарь, Shop prices, PACK и одна доступная сезонная культура/ремесленный продукт. Выбирать только товар с достаточным сроком получения в текущем сезоне. Указание класса/плана не означает готовую зависимость. Новая система не дублирует владельцев соседних эпиков.

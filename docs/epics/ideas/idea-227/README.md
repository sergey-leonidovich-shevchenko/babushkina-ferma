# IDEA-227 — Договор трёх поставок — заранее планировать небольшой сбыт

**Предложение, P2 / L, группа «Торговля и услуги».** [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-227.md) · [Карточки](TASKS.md).

Один покупатель договаривается о трёх небольших поставках известного продукта в течение игровой недели. Хозяйству полезна небольшая предсказуемая цель между разовыми поручениями. Игрок может спланировать посадку или производство, заранее зная объём и цену, и спокойно отказаться от следующего окна.

## Первый выпуск

Один покупатель и товар, три фиксированных окна, целые передачи и честный безопасный отказ; без гарантии прибыли, будущих цен рынка и автоматической доставки.

## Владение, условия и границы

ContractState получает отдельный конечный multi-delivery-record: agreement-ID, item/price/start-day, три shipment-state и последний день нового предложения. Склад/монеты изменяет общая транзакция, не UI календаря.

После VMAP-003; ContractState, календарь, Shop prices, PACK и одна доступная сезонная культура/ремесленный продукт. Выбирать только товар с достаточным сроком получения в текущем сезоне.

Ежедневные farmer/hunter/miner — разовые задания с дневной сменой. IDEA-166 возит товары караваном, IDEA-154 проводит сделку, IDEA-195 копит деньги. Здесь заранее известный конечный график из трёх личных передач, без перевозчика и аванса.

## Этапы

1. Выбрать товар и честные окна поставок
2. Сохранить конечный договор в ContractState
3. Передать целую партию за одну выплату
4. Показать неделю и безопасный пропуск
5. Принять график, цены и добровольность

## Оценка и порядок

Польза 4, интерес 4, соответствие 5, связи 5, ценность 88/100; стоимость 3, риск 4; знакомость не проверена для точной механики. Уверенность — гипотеза. Четверо из пяти игроков понимают три окна и безопасный пропуск; трое добровольно планируют под договор ранее невыбранный продукт.

Расширение: После экономики — выбор из двух сезонных продуктов и собственный сформированный договор артели. Качество/происхождение товара подключаются только после единого instance/variant-контракта.

# IDEA-258 — Держится на узле — сплести сеть под задачу рыбака

**proposed; не реализовано.** Группа «Артель и мастерские». 4 будущих карточек backlog. [Полный дизайн](../../../../wiki/articles/IDEA-258.md) · [Задачи](TASKS.md).

Дать рыбацкому ремеслу отдельное спокойное занятие: игрок связывает узлы, видит нагрузку и исправляет слабое место. Рыбачка Кея заказывает сеть не по редкости сырья, а по понятному способу использования.

## Первый выпуск

Один заказ, поле 3×3 узла, два написанных решения — лёгкая сеть для малька и крепкий край для коряг. Конечная вещь принадлежит Кее; герой получает один декоративный образец, который не ловит рыбу автоматически.

## Границы и зависимости

IDEA-176 разводит рыбу, 185 лепит силуэт, 202 реставрирует мебель, 242 держит вещь вдвоём с мастером. Здесь топологическая сетка с исправимой проверкой нагрузки, без QTE и второго производственного инвентаря. CAMP/InventorySystem владеют нитями, но в пилоте используются учебные нити Кеи без списания. Новый бонус рыбалки не вводится раньше согласования с действующей Fishing-системой.

Рабочий стол на будущем речном причале 8×6 клеток; отдельной карты нет. Стол соблюдает три разрешённых ракурса.

## Этапы

1. Принять две схемы сети и понятную проверку нагрузки — 12 рёбер, две маски, три примера ошибки и инструкция для клавиатуры.
2. Собрать учебное поле и сохраняемый черновик — 9 узлов, undo/reset/preview, валидатор маски без расхода нитей Кеи.
3. Принять заказ и показать сеть у лодки — Одна подтверждённая форма, поздняя реплика Кеи и одна декоративная выдача.
4. Принять две схемы без ловкости и скрытых затрат — F258-01…06, восстановление draft и малая проба чтения нагрузки.

## Оценка

Польза 2, интерес 4, соответствие 5, связи 4 (шкала 1–5); ценность 73/100; стоимость 3, риск 3. P3 / L, дизайнерская гипотеза. Пятеро пробуют бумажные узлы; четверо понимают причину первой ошибки, трое добровольно делают вторую форму без нового приза.

Все F258-01…06 и пробы только запланированы. Реализация после REFACTOR-01→02→03→06, VMAP-003 и отдельного одобрения; подготовительный дизайн не требует будущего игрового адаптера.

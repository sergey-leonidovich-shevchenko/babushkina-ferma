# IDEA-260 — Когда погаснет последний фонарь — передать деревенскую службу

**proposed; не реализовано.** Группа «Истории и жители». 4 будущих карточек backlog. [Полный дизайн](../../../../wiki/articles/IDEA-260.md) · [Задачи](TASKS.md).

Показать, что у важного жителя есть жизнь после работы. Старый фонарщик Семер хочет уйти на покой, и герой помогает выбрать устойчивый способ сохранить вечернее освещение. Итог виден в расписании и манере нового хранителя, а не только в записи «задание выполнено».

## Первый выпуск

Семер и два взрослых кандидата, три уличных фонаря, две пробные смены и одна согласованная разделённая смена. Критические услуги доступны во всех ветках; без героя Семер продолжает службу без наказания деревне.

## Границы и зависимости

IDEA-197 учит взрослого ремеслу, 146 оплачивает работников игрока, 198 добровольно держит ночную вахту, 249 избирает распорядителя. Здесь передача постоянной общественной роли с конечным расписанием и выходом прежнего NPC на покой. WORLD-03/NpcMovementSystem остаётся владельцем расписания; роль читает quest-outcome, не создаёт нового NPC на каждый день. Свет VLIGHT не заменять бутафорским глобальным buff.

Улица будущих Ивовых Мостков и один боковой двор Семера; новой карты нет. Три светильника — предлагаемый будущий контент после VMAP-003, не переделка принятой overworld сегодня.

## Этапы

1. Описать условия преемников и незакрывающиеся услуги — Таблица rota, два согласия и независимость старых миссий от должности.
2. Показать две добровольно начатые пробные смены — Три фонаря, два кандидата, ясные окна без срока на реальных часах.
3. Передать роль через общий resolver расписания — Один rota-outcome, anchors, safe fallback и сохранённая личность Семера.
4. Принять жизнь после должности и старые задания — F260-01…06, миграция/пропуск и малая проба замечаемости смены.

## Оценка

Польза 3, интерес 4, соответствие 5, связи 5 (шкала 1–5); ценность 82/100; стоимость 4, риск 4. P3 / L, дизайнерская гипотеза. После двух макетных посещений четверо из пяти называют, кто теперь зажигает свет и чем занят Семер; трое рады возвращению к нему без новой награды.

Все F260-01…06 и пробы только запланированы. Реализация после REFACTOR-01→02→03→06, VMAP-003 и отдельного одобрения; подготовительный дизайн не требует будущего игрового адаптера.

# IDEA-308 — Как ходил тот, кого нет — собрать ископаемого по устройству тела

**Предложение, не реализовано.** [Статья](../../../../wiki/articles/IDEA-308.md) · [Этапы](TASKS.md) · [Места](../../../../wiki/articles/new-pursuits-register.md).

Собрать скелет вымышленного древнего животного, сравнивая суставы и опоры, и выбрать честную подпись экспоната. Готовая форма должна объяснять движение, а не только совпасть с силуэтом.

Группа «Большие занятия и тайны долины»; 4 будущих этапов backlog. Первый выпуск: copper_fossil_frame, двор 14×12, один демонстрационный каркас; UI из 10 крупных элементов. Один владелец геометрии IDEA-308-02. Родитель copper требует готовности.

RELIC собирает археологические предметы, IDEA-278 сохраняет порядок слоя раскопа,119 делает зарисовки. Здесь другой предмет исследования: строение тела и две независимые опоры вывода о движении. Первый набор уже у Озары; новый раскоп/музей или замена RELIC не обязательны.

Можно проверить на бумажных деталях прежде новой карты или большого музея; научный вывод требует хорошего контента. Стоимость 4/5, риск 4/5 — гипотезы. Игровые блокеры: VMAP-003, IDEA-232-04; ни одна карточка не ready автоматически.

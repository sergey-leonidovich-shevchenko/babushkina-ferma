# IDEA-229 — Обменный круг — договориться о трёх разных желаниях

**Предложение, P3 / M, группа «Торговля и услуги».** [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-229.md) · [Карточки](TASKS.md).

В небольшой группе жителей получить желаемую вещь через понятные обмены, заранее узнав, что ценит каждый. Не каждое решение должно сводиться к числу монет. Короткая обменная история вознаграждает внимание к потребностям и даёт повод познакомить уже известных жителей.

## Первый выпуск

Один авторский круг внутри деревни, три NPC, собственный короткий путь и один декоративный финал; без случайного товарного рынка.

## Владение, условия и границы

BarterStory хранит chain-ID, раскрытые желания и redeemed-step-ID/final-claimed. Общий InventoryTransaction владеет каждым обменом; журнал лишь показывает связи. Шесть конечных связей максимум, без генератора рыночных циклов.

После VMAP-003; PACK-02/03/05/11, единая транзакция обмена и три доступных взрослые NPC. Все точки одного уже открытого поселения, без искусственного бега между тремя дальними деревнями.

IDEA-145 переносит любовные письма/подарки, IDEA-154 продаёт за монеты, IDEA-186 проводит аукцион. Здесь конечная предметная цепочка с двумя разрешёнными путями и заранее понятными желаниями; доставка письма не становится торговлей.

## Этапы

1. Написать три желания и два пути к финалу
2. Проводить каждый обмен по точной вместимости
3. Показать раскрытые связи и сохранить финал
4. Принять короткий и полный обменные пути

## Оценка и порядок

Польза 3, интерес 4, соответствие 5, связи 5, ценность 82/100; стоимость 3, риск 3; знакомость 2/5: частичное сходство. Уверенность — гипотеза. Четверо из пяти игроков видят короткий путь своим материалом; трое выбирают длинный ради историй, а не потому что UI его навязал.

Расширение: Ещё две истории с другими потребностями и отправка одного обычного товара почтой 179 после её принятия; каждая история отдельно защищена от бесконечного обмена.

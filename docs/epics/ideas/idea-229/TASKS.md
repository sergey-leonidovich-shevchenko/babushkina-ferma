# IDEA-229 — Обменный круг — договориться о трёх разных желаниях: задачи

[Паспорт](README.md) · [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-229.md)

**Первый выпуск:** Один авторский круг внутри деревни, три NPC, собственный короткий путь и один декоративный финал; без случайного товарного рынка.

**Контракт состояния:** BarterStory хранит chain-ID, раскрытые желания и redeemed-step-ID/final-claimed. Общий InventoryTransaction владеет каждым обменом; журнал лишь показывает связи. Шесть конечных связей максимум, без генератора рыночных циклов.

**Внешние условия:** После VMAP-003; PACK-02/03/05/11, единая транзакция обмена и три доступных взрослые NPC. Все точки одного уже открытого поселения, без искусственного бега между тремя дальними деревнями. Указание класса/плана не означает готовую зависимость. Новая система не дублирует владельцев соседних эпиков.

# IDEA-261 — Кто первым найдёт зарубку — дружеский соперник на поиске

**proposed; не реализовано.** Группа «Дороги и путешествия». 5 будущих карточек backlog. [Полный дизайн](../../../../wiki/articles/IDEA-261.md) · [Задачи](TASKS.md).

Добавить человека, который хочет того же открытия и действует по понятным правилам. Собиратель Нив становится соперником на одной добровольной прогулке, затем возможным знакомым. Проигрыш оставляет историю и следующий разговор, не отбирая ключи главного сюжета.

## Первый выпуск

Один Нив, одна местная зарубка, две равноценные тропы и три исхода: герой первым, Нив первым, договорились искать вместе. Награда — маленькая памятная печать с разной подписью, одинаковая полезность.

## Границы и зависимости

IDEA-199 ищет клад по приметам, 189 проходит выбранный поход, 248 показывает жизнь NPC без героя, 232 вводит сроки опасного спасения. Здесь добровольное соревнование с заранее видимым стартом и честным движением соперника; без смерти и скрытого таймера до согласия. WORLD-03/NpcMovementSystem — движения, один общий clock-owner, 232-04 — разговор. UNDERWAY и варпы нельзя использовать как неопределённую телепортацию соперника.

Один предлагаемый боковой маршрут 24×16 в будущей лесной зоне, два обхода вокруг валуна и один безопасный выход. Нужна отдельная геометрическая карточка, не новый глобальный мир.

## Этапы

1. Принять честные правила гонки и три непроигрышных финала — Согласие, joint при равенстве, отсутствие главного ключа и явная отмена.
2. Разметить два пути и читаемый маршрут Нива — Карман 24×16, 28/40 клеток как гипотеза, точки видимых пауз и безопасный выход.
3. Провести Нива по одному simulation tick с героем — Сегменты/паузы/save, offscreen без телепорта и без догоняющей скорости.
4. Принять зарубку один раз и написать встречу после — Atomic inspect, три подписи печати одинаковой полезности и один reward claim.
5. Принять гонку на разных билдах и после отмены — F261-01…06, равный tick, старый слот, пауза и будущая малая проба честности.

## Оценка

Польза 3, интерес 5, соответствие 5, связи 5 (шкала 1–5); ценность 88/100; стоимость 4, риск 4. P3 / L, дизайнерская гипотеза. Пятеро проходят бумажные пути; четверо объясняют, почему Нив оказался первым, трое готовы повторить с другим маршрутом без более сильного приза.

Все F261-01…06 и пробы только запланированы. Реализация после REFACTOR-01→02→03→06, VMAP-003 и отдельного одобрения; подготовительный дизайн не требует будущего игрового адаптера.

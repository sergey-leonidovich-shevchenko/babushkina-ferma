# IDEA-256 — Садовый доктор — спасти одно дерево по признакам

**proposed; не реализовано.** Группа «Ферма и земледелие». 4 будущих карточек backlog. [Полный дизайн](../../../../wiki/articles/IDEA-256.md) · [Задачи](TASKS.md).

Дать наблюдению за растением практический смысл: осмотреть симптомы, проверить гипотезу, подобрать уход и увидеть изменение. История садовницы Тавы открывает добровольное занятие без глобальных эпидемий и наказания за каждый пропущенный день.

## Первый выпуск

Одна сюжетная груша на участке Тавы, две возможные причины одинакового увядания, три наблюдения и одна проверяемая мера. Неудачный уход можно исправить; обычные сады игрока не получают новую болезнь.

## Границы и зависимости

OrchardSystem уже ведёт рост/плодовый цикл. IDEA-066 и 163 — сорта и севооборот, CASE — причинный вывод по уликам, 197 — обучение ремесленника. Здесь ограниченная диагностика и изменение состояния одного сюжетного дерева. Общая сущность дерева и календарь не дублируются; диагноз — quest-overlay над существующим node. VFOLIAGE-010 требует видимости нового силуэта, но не доказывает читаемость симптомов.

Один предлагаемый участок 10×8 у будущего Подкоренья, без отдельной карты: дерево в земле, канава и маленькая подпорка. Существующую overworld сегодня не редактировать.

## Этапы

1. Написать две причины и проверяемые симптомы груши — Матрица наблюдение→гипотеза→мера→отклик без скрытого броска после загрузки.
2. Поставить сюжетную грушу поверх общего дерева — Один node и overlay, три осмотра, канава/подвязка, существующий рост не переписан.
3. Провести уход и отклик следующего дня — Мера, due_day, needs_revision/stable, карточка ухода с общей выдачей без фарма.
4. Принять ошибочный диагноз и повторную проверку — F256-01…06, обе причины, десять дней отсутствия и читка понятности.

## Оценка

Польза 4, интерес 4, соответствие 5, связи 5 (шкала 1–5); ценность 88/100; стоимость 4, риск 3. P3 / L, дизайнерская гипотеза. Пятеро проходят макет двух деревьев: четверо выбирают проверку по признакам, а не угадывают средство; трое возвращаются посмотреть результат без обещания урожая.

Все F256-01…06 и пробы только запланированы. Реализация после REFACTOR-01→02→03→06, VMAP-003 и отдельного одобрения; подготовительный дизайн не требует будущего игрового адаптера.

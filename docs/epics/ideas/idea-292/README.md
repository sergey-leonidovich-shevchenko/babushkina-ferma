# IDEA-292 — Первое небо — показать поверхность жителю Подкоренья

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-292.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

Спокойно провести взрослого жителя, впервые решившего увидеть небо, через три разные освещённые площадки; маршрут и момент возвращения выбираются вместе с ним.

Группа «Истории и жители». 4 предметных будущих этапов, все backlog. Первый полезный выпуск — root_first_sky; 18×12 клеток; три открытые остановки и обратный проход. Геометрия/рабочая зона принадлежит IDEA-292-02, родитель root требует отдельной готовности.

IDEA-233 — спасение раненого под сроком, IDEA-247 — управление маленьким телом, IDEA-259 — разведка вороном. Здесь добровольный бессрочный первый выход взрослого NPC, без лечения, смены управляемого тела и обязательного боя.

Один небольшой участок даёт сильное последствие и использует уже выбранные расписания; сначала проверить речь и остановки. Стоимость 4/5 и риск 3/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

# Поединки памяти — вернуться к уже побеждённому противнику

**Свой эпик IDEA-211.** [Паспорт](README.md) · [Дизайн](../../../../wiki/articles/IDEA-211.md). Группа «Бой и бестиарий». Игровая реализация не выполнена; все 7 этапов — будущие.

Любимый бой можно повторить и освоить лучше, даже если сюжетная арена уже закрыта. Игрок получает личный вызов без новой добычи, повторной выдачи квестовой награды и обязательной гонки за рейтингом.

**Внешние условия:** VMAP-003, отдельное одобрение идеи и зависимости паспорта. Числа дизайна — гипотезы для малой пробы. Первая карточка не становится Ready из-за высокого рейтинга.

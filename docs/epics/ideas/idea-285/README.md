# IDEA-285 — Ведро по цепочке — добровольная школа деревенских пожарных

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-285.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

В безопасном учебном дворе научиться перекрывать путь огню, подавать воду по короткой цепочке и сохранять выход прежде, чем гасить самый яркий очаг.

Группа «Игровые механики». 5 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `home` должны быть приняты отдельно.

TRAP-28 (IDEA-031) — готовая короткая огненная струя, IDEA-274 обсуждает шум, IDEA-146 нанимает работников. Здесь локальная задача на распространение/пресечение и передачу воды; не глобальная катастрофа, не автоферма и не новый вид прямого урона.

Сначала доказать ограниченность и понятность; высокий интерес не оправдывает опасность мирового распространения. Стоимость 5/5, риск 5/5 — отдельные гипотезы, не сроки.

# IDEA-281 — Не повторяй зов — болотный двойник чужого голоса

**proposed, не реализовано.** Группа «Бой и бестиарий», 4 собственных будущих карточки backlog. [Подробный дизайн](../../../../wiki/articles/IDEA-281.md) · [Задачи](TASKS.md).

В тростнике слышен знакомый голос, но зовущий не знает общего воспоминания и оставляет неправильные следы. Игрок может выявить подражателя по независимым признакам, отогнать его светом или принять короткий бой.

## Первый полезный выпуск

Один враг, две проверки, один безопасный край, три исхода и одинаковая необязательная находка. Затем отдельные authored вариации, не случайное заражение всех NPC мира.

## Владелец и отличие

IDEA-081 охотится на свет, IDEA-084 стреляет по запомненной точке, IDEA-245 говорит жестами, IDEA-271 проверяет легенду героя. Здесь ложный NPC-зов от ограниченного врага; проверку проводит игрок, и два независимых признака всегда доступны без слуха.

Общий игровой адаптер IDEA-232-04 ещё backlog и блокирует использующие его этапы. Бумажный этап 01 имеет самостоятельную приёмку. Отдельные межэпиковые зависимости смотрите в TASKS. Не менять чужой owner состояния, всё игровое после VMAP-003/одобрения.

## Предметные этапы

1. **IDEA-281-01 — Написать два признака, три исхода и правила честного зова.** Фраза/отпечаток/записка и safe схема, все ветви к одной надписи.
2. **IDEA-281-02 — Собрать распознавание и мирный обход.** Один spawn,clue_mask,brazier и safe bypass для спутников.
3. **IDEA-281-03 — Подключить повторника к Combat и HURT.** Один рывок с телеграфом и три исхода у единого owner.
4. **IDEA-281-04 — Принять честную угрозу и равноправные финалы.** F281-01…06, отдельный native AI/light бюджет и проба.

# IDEA-220 — Сход у старой ивы — договориться о воде

**proposed / запланированное предложение**, не выполненная механика. Группа «Истории и жители». [Подробный дизайн](../../../../wiki/articles/IDEA-220.md) · [Карточки](TASKS.md).

Хочется менять жизнь деревни словами и пониманием, а не всегда приносить 20 брёвен. Разные приемлемые договоры дают видимое авторство без единственного «доброго» ответа.

## Первый выпуск

Одна история, два заранее проверенных приемлемых договора, три дня наблюдаемого нового быта и один пересмотр. Никакого глобального суда, фракционной морали и войны за ресурсы.

1. Написать нужды и два равноправных договора
2. Дать два разговора и проверяемые наблюдения
3. Собрать стол схода с предпросмотром
4. Переключить расписания и три дня последствий
5. Принять компромисс в живой деревне

# IDEA-215 — Чайный стол — разговор, которому можно дать время

**proposed / запланированное предложение**, не выполненная механика. Группа «Отношения и семья». [Подробный дизайн](../../../../wiki/articles/IDEA-215.md) · [Карточки](TASKS.md).

Дружба через повторяющийся подарок быстро становится таблицей. Чайная встреча даёт спокойное совместное занятие, где важнее внимание к словам, чем стоимость предмета.

## Первый выпуск

Один стол, два взрослые знакомые, четыре короткие истории, три вкусовых профиля и отсутствие предметной награды. Дружеская сцена без обязательного брака.

## Владение, условия и границы

meeting-ID, NPC-ID, week-key, offered-profile, served, story-ID и завершённые истории. Отношения остаются у общего владельца, сцена резервирует два места лишь временно. Расход и served фиксируются вместе.

После VMAP-003; текущие VillageLife/Dialogue, отношения IDEA-127 при её реализации, atomic inventory для расходников. Пилот может работать с двумя нынешними взрослыми жителями без брака и без нового дома.

IDEA-129 описывает свидания, IDEA-144 три вечера пары, IDEA-157 авторские блюда, IDEA-206 домашние ароматы. Здесь новая маленькая игра слушания для дружеской встречи: выбор настоя и темы, без нового романа, рецептурного редактора или пассивного запаха комнаты.

## Этапы

1. Написать четыре истории с открытыми предпочтениями
2. Пригласить гостя и занять два доступных места
3. Подать чай по подтверждённой смете
4. Сохранить разговор в общей дружбе
5. Принять добровольную встречу без приза

## Оценка и порядок

P3 / L; польза 3, интерес 5, соответствие 5, связи 4, ценность 85/100, стоимость 4, риск 3. Знакомость не проверена, уверенность — гипотеза. Трое из пяти игроков запоминают одну привычку гостя и хотят позвать второго ради разговора, а не очков.

Расширение: Позже приглашение двух гостей и уважительное обсуждение их разных привычек. Семейные варианты подключаются к существующим стадиям; чай не становится ежедневной обязанностью супруга.

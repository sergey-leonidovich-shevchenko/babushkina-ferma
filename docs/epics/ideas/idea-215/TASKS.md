# IDEA-215 — Чайный стол — разговор, которому можно дать время: задачи

[Паспорт](README.md) · [Игровой дизайн и шесть сценариев](../../../../wiki/articles/IDEA-215.md)

Один стол, два взрослые знакомые, четыре короткие истории, три вкусовых профиля и отсутствие предметной награды. Дружеская сцена без обязательного брака.

**Контракт состояния:** meeting-ID, NPC-ID, week-key, offered-profile, served, story-ID и завершённые истории. Отношения остаются у общего владельца, сцена резервирует два места лишь временно. Расход и served фиксируются вместе.

**Внешние условия:** После VMAP-003; текущие VillageLife/Dialogue, отношения IDEA-127 при её реализации, atomic inventory для расходников. Пилот может работать с двумя нынешними взрослыми жителями без брака и без нового дома. Одобрение IDEA-215 необходимо отдельно. Эти карточки не входят в очередь текущего визуального переноса. Связанные источники не становятся вторыми владельцами.

# IDEA-291 — Деревянный журавль — оживить игрушку тремя кулачками

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-291.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Составить короткую механическую последовательность: три кулачка задают наклон, крыло и клюв деревянной птицы, а общий оборот показывает, получается ли задуманный жест.

Группа «Артель и мастерские». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `root` должны быть приняты отдельно.

IDEA-184 балансирует мобиль, 216 собирает ветряной орган, 242 помогает мастеру вдвоём, 146 автоматизирует выпуск товаров. Здесь логика трёх дискретных кулачковых дорожек и одного оборота; нет фабрики/работников, сочинения музыки или новой машины добычи.

Сначала бумажная схема и удовольствие от причинности, затем ограниченная сценка вместо сложного физического механизма. Стоимость 4/5, риск 3/5 — отдельные гипотезы, не сроки.

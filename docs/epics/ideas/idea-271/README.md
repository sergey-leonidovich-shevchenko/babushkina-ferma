## Предметные этапы

1. **IDEA-271-01 — Написать легенду, две проверки и честную альтернативу.** Два факта, предупреждения, одинаковый сюжетный факт обеих ветвей.
2. **IDEA-271-02 — Подготовить двор и отдельный слой роли.** Новая область, ворота/полка/закрытая граница, appearance без статов.
3. **IDEA-271-03 — Провести проверку и ограниченный допуск.** Check_mask, warnings, token/zone, возврат к подготовке.
4. **IDEA-271-04 — Прочитать запись, вернуть форму и поддержать честный запрос.** Read_once, returned, один итог, честная ветвь после пробуждения.

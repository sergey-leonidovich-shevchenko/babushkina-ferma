# IDEA-321 — Приказы деревянному жуку — придумать короткую программу

**Предложение proposed; игровой реализации нет.** Все игровые этапы backlog. Реализация после VMAP-003, отдельного одобрения и перечисленных зависимостей; текущая очередь 03 → 07 → 06 → первая overworld сохраняется.

**Группа:** Игровые механики. **Приоритет/сложность:** P2/L.

Выложить несколько понятных карточек-команд, запустить деревянного жука на маленьком поле и понять, почему он остановился. Решать задачу последовательностью, а не прямым управлением.

**Польза:** Даёт добровольную логическую игру с наблюдаемой причиной ошибки. Программа остаётся собственным решением игрока; можно возвращаться ради более понятного маршрута без наград за скорость.

# IDEA-245 — Договориться без общего языка — три жеста у тростникового причала

**proposed; не реализовано.** Группа «Истории и жители». 4 собственных карточек backlog, без сборного дневного эпика. [Статья](../../../../wiki/articles/IDEA-245.md) · [Задачи](TASKS.md).

Общение с приезжей через показ предметов и три выученных жеста: игрок наблюдает, предлагает смысл и подтверждает понимание обеих сторон перед обменом.

## Первый полезный выпуск

Три знака и демонстрационный обмен с полноценной помощью переводчицы. Затем один настоящий обмен известными товарами, когда приняты общий торговый commit и PACK; ещё один язык требует нового самостоятельного решения об объёме.

## Собственный результат и внешние владельцы

IDEA-180 уже владеет древними письменами, IDEA-154 — подтверждением сделки. Здесь современный живой собеседник и три наблюдаемых действия, без нового алфавита. IDEA-068 речной быт задаёт направление, но MVP помещён у существующего village_river; новая деревня ради одного перевода не нужна.

Одна приезжая, три жеста, одна сценическая корзина с яблоками. Первый обмен только демонстрационный: квестовые корзины меняют место в сцене, рюкзак и деньги героя не затрагиваются. Настоящий торговый обмен — позднее через IDEA-154, без собственной транзакции.

Разговоры используют опубликованный адаптер IDEA-232-04 из PR №6 после его принятия. Его отсутствие в main обозначено внешним условием игровых карточек, а не замаскировано копией движка. Приоритет VMAP-003 сохраняется; предложения ещё не одобрены.

## Этапы

1. Проверить три жеста Шиу на статичных карточках: Контексты двух корзин, пять читателей, подписи и путь переводчицы.
2. Ввести состояния понимания и безопасный повтор: Один авторский разговор с unknown/observed/hypothesis/confirmed.
3. Провести взаимное подтверждение двух корзин: Сценический preview и совпадение направлений без личного инвентаря.
4. Принять разговор без языка с доступным переводом: F245-01…06, reduced motion, клавиатура, длинные субтитры.

## Оценка и будущая проба

P3 / L; польза 3/5, интерес 5/5, соответствие 5/5, связи 4/5, ценность 85/100. Стоимость 4/5 и риск 4/5 раздельны. Знакомость: 3/5 в пределах описанного сравнения. Позволяет учиться понимать другого человека без принудительного перевода всей игры. Нужны хорошая анимация и безопасный способ исправить догадку.

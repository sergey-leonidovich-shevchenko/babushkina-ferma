# IDEA-293 — Звезда вместо молота — помочь подмастерью выбрать своё ремесло

Предложение **не реализовано**. [Полная статья](../../../../wiki/articles/IDEA-293.md) · [Задачи](TASKS.md) · [Места](../../../../wiki/articles/new-horizons-register.md).

Подмастерье хочет уйти из кузницы к наблюдениям неба. Герой помогает показать обеим сторонам реальную работу и согласовать будущую жизнь, не решая её за ученицу.

Группа «Истории и жители». 4 предметных будущих этапов, все backlog. Первый полезный выпуск — copper_apprentice_terrace; 14×10 клеток; рабочая дверь, стол эскизов и открытая площадка. Геометрия/рабочая зона принадлежит IDEA-293-02, родитель copper требует отдельной готовности.

IDEA-197 учит выбранного подмастерья, IDEA-266 проверяет кузнечный урок, IDEA-174 — личный звёздный атлас. Новый цикл — право взрослой ученицы отказаться от ожидаемой профессии и согласовать публичный переход; ученический XP не является целью.

Содержательная история без нового ремесленного движка; сначала проверить добровольность обеих ветвей и поздний распорядок. Стоимость 4/5 и риск 3/5 — гипотезы. Первая бумажная задача не принимает игровой цикл; реализация после VMAP-003, одобрения и IDEA-232-04.

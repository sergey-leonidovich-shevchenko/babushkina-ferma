# Домашние ароматы — смешивать запах с понятным характером

**Свой эпик IDEA-206.** [Паспорт](README.md) · [Дизайн](../../../../wiki/articles/IDEA-206.md). Группа «Артель и мастерские». Игровая реализация не выполнена; все 5 этапов — будущие.

Из знакомых трав и масла можно составить запах для дома: травяной, древесный или тёплый пряный. Игрок исследует сочетания и выбирает настроение комнаты; сама игра передаёт запах описаниями и реакциями, не требует чувствовать несуществующий аромат через экран.

**Контракт интеграции:** Композиции разных revision и хранение результата при полной сумке требуют принятых PACK-02/03/05/17. Сегодняшний inventory_system ещё не является подтверждением конечных стаков по 999.

**Внешние условия:** VMAP-003, отдельное одобрение идеи и зависимости паспорта. Числа дизайна — гипотезы для малой пробы. Первая карточка не становится Ready из-за высокого рейтинга.

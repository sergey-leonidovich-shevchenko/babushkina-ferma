# IDEA-222 — Грамоты доверия — получить поручительство за разные поступки

**Предложение, P2 / M, группа «Истории и жители».** [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-222.md) · [Карточки](TASKS.md).

Один мастер принимает рекомендации разных жителей вместо покупки очередного порога репутации. Игроку хочется, чтобы разные занятия подтверждали его место в долине. Поручительство делает рыбалку, ремесло и помощь людям равноправными способами знакомства с закрытым ремесленным кругом.

## Первый выпуск

Один круг, три подтверждения, два достаточных и один необязательный разговор мастера. Никакой войны фракций, сброса репутации или закрытия обычных перков.

## Владение, условия и границы

TrustDocument у журнала: circle-ID, proof-kind→source-event-ID и granted. ContractState и mission_states остаются владельцами исходных фактов; грамота их не переписывает.

После VMAP-003 и одобрения; текущие mission_states, ContractState, журнал и диалоги. Первые привязки: завершённый farmer-контракт и mission side_fisher («Уха для переправы» Варвары). Третий путь — показ выбранного собственного ремесленного образца, точный recipe-ID сверяется в первой карточке.

IDEA-181 меняет враждебность одного лагеря; IDEA-197 обучает подмастерья; нынешняя гильдия считает заказы. Здесь один постоянный документ доступа, получаемый двумя из трёх независимых свидетельств, без новой глобальной шкалы фракций.

## Этапы

1. Привязать три свидетельства к настоящим фактам
2. Сохранить постоянную грамоту без предметного ключа
3. Показать условия и безопасно осмотреть образец
4. Открыть один разговор ремесленного двора
5. Принять три пути и старые сохранения

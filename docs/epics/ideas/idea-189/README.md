# Путь малого огня — добровольный поход с выбранным условием

**Эпик IDEA-189 · Истории и жители · P2 / M.** [Открыть в Wiki](#/development/epics/idea-189--IDEA-189) · [Полный дизайн](../../../../wiki/articles/IDEA-189.md) · [Карточки](TASKS.md).

Знакомая безопасная дорога становится маленьким приключением: донести огонёк через три старых очага, заранее выбрав необязательное условие. Ценность — история старой службы долины и собственное решение пройти путь внимательнее, а не новый обязательный способ передвижения.

## Первый законченный результат

Один добровольный маршрут по трём существующим безопасным очагам и одно заранее выбранное условие без варпа. Огонёк — состояние этой истории, не новый рабочий тип факела. Награда — разовая история, не нарастающий урон.

## Состояния и ответственность

journey-ID, route-ID, условие, множество visited-hearth-ID и завершение. Каждый очаг имеет свой ID и порядок из сценария; три нажатия одного очага не заменяют маршрут. Прерывание сохраняет или завершает проход по заранее объявленному правилу.

## Сквозной сценарий

Герой читает длину пути и условие, подтверждает начало и посещает три знакомых очага. Если решает воспользоваться варпом, заранее видит, что условие прекращается без штрафа вещам. Позже может повторить прогулку, но история выдаётся один раз.

## Зависимости и границы

Игровой этап: VMAP-003. Статусы зависимостей читаются из их прежних карточек. Художественные эталоны, сетка 24, единицы WorldProjection и три предметных вида сохраняются. Старые операции не получают второго владельца. Одобрение, оценка и созданные карточки не означают принятую реализацию.

## Оценка и будущая проба

Польза 1/5, интерес 4/5, соответствие 5/5, связи 4/5, расчётная ценность 67/100. Стоимость 2/5 и риск 2/5 — отдельные ограничения. Это дизайнерская гипотеза, не статистика спроса.

Знакомая дорога получает смысл при малом объёме, но условие легко сделать искусственным. Для кого: Исследователи и любители тихого лора.

Проба: Игрок добровольно выбирает ограничение без варпа и после пути может пересказать смысл трёх очагов.

## Будущая приёмка

1. Начать путь, пройти три известных узла по порядку: одна история и одна памятная награда.
2. Посетить третий узел первым: прогресс объяснён, бесплатного завершения нет.
3. Выбрать варп на середине: можно прекратить прогулку и штатно переместиться, вещи не теряются.
4. Сохранить между узлами и загрузить: прежний порядковый узел и тот же огонёк.
5. Стоять на паузе, переждать дождь, погасить декоративный огонь: нет скрытого таймера или невосстановимой неудачи.
6. Повторить путь и пройти сюжет без него: нет повторного сильного лута, обязательная история Лунной поляны остаётся доступной.

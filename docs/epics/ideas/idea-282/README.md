# IDEA-282 — Не счищай последнюю строчку — сохранить две жизни настенной росписи

Самостоятельное предложение, **не реализовано**. [Полный дизайн](../../../../wiki/articles/IDEA-282.md) · [Карточки](TASKS.md) · [Реестр площадок](../../../../wiki/articles/resident-workshops-register.md).

Расчистить неподвижную роспись по маленьким пробам, сохранив важную для жителей позднюю надпись либо открыв более древний слой после обсуждения.

Группа «Большие занятия и тайны долины». 4 предметных этапов backlog; первый — бумажная проба, затем геометрия и собственный ограниченный цикл. Игровая часть ждёт VMAP-003, одобрения и общего адаптера IDEA-232-04. Новая геометрия/владелец родителя `salt` должны быть приняты отдельно.

RELIC собирает переносимые осколки, IDEA-202 чинит мебель, IDEA-278 в PR22 хранит порядок раскопа. Здесь неподвижная поверхность с двумя ценными эпохами и локальной необратимой фиксацией только после предпросмотра.

Сильное видимое последствие в одном ограниченном месте; сначала проверить понятность необратимого шага. Стоимость 4/5, риск 3/5 — отдельные гипотезы, не сроки.

# IDEA-226 — Гибкая ремесленная смета — выбрать разрешённую замену сырья

**Предложение, P2 / L, группа «Артель и мастерские».** [Полный дизайн и шесть сценариев](../../../../wiki/articles/IDEA-226.md) · [Карточки](TASKS.md).

У отдельного чертежа выбрать один из допустимых материалов и заранее увидеть точный расход, свойства и внешний вариант. Одна отсутствующая мелочь не должна всегда останавливать творческую стройку, если у ремесла есть понятная альтернативная техника. Игрок видит разумный компромисс, а не скрытое автоматическое расходование редкого сырья.

## Первый выпуск

Два чертежа, одна группа×два варианта, единая смета/возврат и честный вид предмета. Без замены входов старых слотов, зелий, уникальных ключей и боевого снаряжения.

## Владение, условия и границы

RecipeVariantResolver выдаёт immutable recipe-revision, choice-ID, resolved_inputs и output-variant. ProductionPlan/Queue читают один результат; новый резолвер не хранит склад и не исполняет производство. Save партии содержит выбранную ревизию и точный резерв.

После VMAP-003; единая смета ProductionPlan/Queue, PACK и паспорт варианта предмета. MVP — два отдельно принятых новых декоративных чертежа; существующие рецепты и их сохранённые очереди не переписываются.

IDEA-157 меняет вкусовой рецепт блюда; IDEA-156 красит ткань; FARM-08 считает цепочку и побочные выходы. Здесь один вход группы материалов у конкретного чертежа, с явным выбором до резерва; это не глобальная автозамена всей древесины.

## Этапы

1. Согласовать два декоративных чертежа и допустимые входы
2. Нормализовать одну точную смету варианта
3. Считать цепочку по выбранным входам
4. Резервировать и возвращать именно выбранный состав
5. Показать выбор и декоративный результат
6. Принять старые слоты и малую пробу сметы

## Оценка и порядок

Польза 5, интерес 4, соответствие 5, связи 5, ценность 94/100; стоимость 4, риск 5; знакомость не проверена для точной механики. Уверенность — гипотеза. Четверо из пяти игроков предсказывают точный возврат после смены превью и отмены; никто не ожидает скрытого усиления предмета.

Расширение: После принятия — отдельные одобренные чертежи с реальными компромиссами веса/вида. Каждый новый вход имеет самостоятельную проверку экономики и миграции.

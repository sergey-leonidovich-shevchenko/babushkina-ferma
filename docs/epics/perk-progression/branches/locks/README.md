# PERK-LOCKS — Замки и ловкость рук

Согласованная тематическая ветвь PERK. Собственные задачи здесь не копируют прежние способности. [Общий договор](../../README.md) · [Все узлы Wiki](../../../../../wiki/articles/character-perks.md) · [Карточки](TASKS.md).

Владелец: Новый владелец замка/взятия + Inventory.

Условия: Подлинные ключевые двери, охрана и владение предметом; нет обхода сюжета. После VMAP-003 и перечисленных в карточках блокеров.

Каждый новый ранг стоит одно общее очко; выбранная ветвь не запрещает другие. Текущие способности сохраняются, новый эффект нельзя купить до его реализации. Числа — стартовые настройки баланса, не измеренная популярность.

| Узел | Ранги / доступ | Поведение |

Приёмка: ключевая дверь, обычный замок, уже открытый сундук, защищённый предмет и прерванное действие; покупка/сброс/пауза/старый слот и отсутствие перка. Эти сценарии ещё не выполнены. Польза и стоимость оцениваются в общем паспорте; не создавать отдельные XP/кошелёк/инвентарь ради этой ветви.

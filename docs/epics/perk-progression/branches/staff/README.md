# PERK-STAFF — Владение посохом

Согласованная тематическая ветвь PERK. Собственные задачи здесь не копируют прежние способности. [Общий договор](../../README.md) · [Все узлы Wiki](../../../../../wiki/articles/character-perks.md) · [Карточки](TASKS.md).

Владелец: WeaponSystem / SpellSystem.

Условия: moon_staff как нынешний класс оружия; отдельная школа без второй шкалы заряда. После VMAP-003 и перечисленных в карточках блокеров.

Каждый новый ранг стоит одно общее очко; выбранная ветвь не запрещает другие. Текущие способности сохраняются, новый эффект нельзя купить до его реализации. Числа — стартовые настройки баланса, не измеренная популярность.

Приёмка: не тот класс оружия, пустая мана, стена, промах и смена экипировки в действии; покупка/сброс/пауза/старый слот и отсутствие перка. Эти сценарии ещё не выполнены. Польза и стоимость оцениваются в общем паспорте; не создавать отдельные XP/кошелёк/инвентарь ради этой ветви.

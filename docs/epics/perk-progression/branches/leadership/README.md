# PERK-LEADERSHIP — Лидерство

Согласованная тематическая ветвь PERK. Собственные задачи здесь не копируют прежние способности. [Общий договор](../../README.md) · [Все узлы Wiki](../../../../../wiki/articles/character-perks.md) · [Карточки](TASKS.md).

Владелец: SkillSystem / CompanionSystem.

Условия: Команды и инвентарь спутника остаются базовыми; новые перки не дают третьего спутника. После VMAP-003 и перечисленных в карточках блокеров.

Каждый новый ранг стоит одно общее очко; выбранная ветвь не запрещает другие. Текущие способности сохраняются, новый эффект нельзя купить до его реализации. Числа — стартовые настройки баланса, не измеренная популярность.

Приёмка: один/два спутника, ждать/защищать, узкий проход, потеря цели и отказ direct; покупка/сброс/пауза/старый слот и отсутствие перка. Эти сценарии ещё не выполнены. Польза и стоимость оцениваются в общем паспорте; не создавать отдельные XP/кошелёк/инвентарь ради этой ветви.

# PERK-BACKPACK — Рюкзак и поход

Согласованная тематическая ветвь PERK. Собственные задачи здесь не копируют прежние способности. [Общий договор](../../README.md) · [Все узлы Wiki](../../../../../wiki/articles/character-perks.md) · [Карточки](TASKS.md).

Владелец: InventoryState / PACK / CAMP.

Условия: Вместимость один раз через PACK, стаки 999, никакого обязательного ручного подбора. После VMAP-003 и перечисленных в карточках блокеров.

Каждый новый ранг стоит одно общее очко; выбранная ветвь не запрещает другие. Текущие способности сохраняются, новый эффект нельзя купить до его реализации. Числа — стартовые настройки баланса, не измеренная популярность.

| Узел | Ранги / доступ | Поведение |
|---|---|---|
| Укладка рюкзака · планируется · [PERK-BACKPACK-01](../../../../../wiki/articles/character-perks.md) · `carry_packing` | 4 / 4,8,13,18 | Четыре ранга дают доступ к уже согласованным уровням 72/84/96/108 слотов вместо базы 60. Эффективный уровень = max(купленный, ранг), не сумма. |
| Разгрузочный пояс · планируется · [PERK-BACKPACK-02](../../../../../wiki/articles/character-perks.md) · `carry_belt` | 1 / 6 | Две дополнительные ссылки быстрого доступа к уже лежащим вещам; не создают слоты рюкзака и не обходят cooldown расходника. |
| Ровный груз · планируется · [PERK-BACKPACK-03](../../../../../wiki/articles/character-perks.md) · `carry_load` | 1 / 11 | Штраф скорости при переносе явно помеченного крупного груза/волокуши меньше на 25%; обычной сумке новый вес/штраф не добавляется. |
| Беречь огонь · планируется · [PERK-BACKPACK-04](../../../../../wiki/articles/character-perks.md) · `carry_firecare` | 1 / 6 | Время горения обычного расходуемого походного факела больше на 25%; поясной фонарь остаётся у CAMP, вечный свет не создаётся. |

Приёмка: все пять вместимостей, купленный уровень выше/ниже ранга, полный рюкзак и отмена сброса; покупка/сброс/пауза/старый слот и отсутствие перка. Эти сценарии ещё не выполнены. Польза и стоимость оцениваются в общем паспорте; не создавать отдельные XP/кошелёк/инвентарь ради этой ветви.

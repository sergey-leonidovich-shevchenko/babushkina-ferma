# PERK-SPEECH — Торговля и речь

Согласованная тематическая ветвь PERK. Собственные задачи здесь не копируют прежние способности. [Общий договор](../../README.md) · [Все узлы Wiki](../../../../../wiki/articles/character-perks.md) · [Карточки](TASKS.md).

Владелец: Merchant / Quest / FAIR.

Условия: Транзакция с подтверждением, недельный выкуп и запрет торговли без места сохраняются. После VMAP-003 и перечисленных в карточках блокеров.

Каждый новый ранг стоит одно общее очко; выбранная ветвь не запрещает другие. Текущие способности сохраняются, новый эффект нельзя купить до его реализации. Числа — стартовые настройки баланса, не измеренная популярность.

Приёмка: перекупка, недельный выкуп, повтор вложения в лавку, полный рюкзак и старое подтверждение; покупка/сброс/пауза/старый слот и отсутствие перка. Эти сценарии ещё не выполнены. Польза и стоимость оцениваются в общем паспорте; не создавать отдельные XP/кошелёк/инвентарь ради этой ветви.

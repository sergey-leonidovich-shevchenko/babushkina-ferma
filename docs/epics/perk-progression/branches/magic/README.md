# PERK-MAGIC — Боевая магия

Согласованная тематическая ветвь PERK. Собственные задачи здесь не копируют прежние способности. [Общий договор](../../README.md) · [Все узлы Wiki](../../../../../wiki/articles/character-perks.md) · [Карточки](TASKS.md).

Владелец: SpellSystem / CombatSystem.

Условия: Три действующих заклинания и поэтапно новые стихии; эффект не выдаётся до появления владельца. После VMAP-003 и перечисленных в карточках блокеров.

Каждый новый ранг стоит одно общее очко; выбранная ветвь не запрещает другие. Текущие способности сохраняются, новый эффект нельзя купить до его реализации. Числа — стартовые настройки баланса, не измеренная популярность.

|---|---|---|
| Мана · работает сейчас · `skill:mana` | прежние / прежний доступ | Сохранить нынешние запас/восстановление маны и влияние ручного ранга на три заклинания; не делать новую mana-копию. |

Приёмка: отмена, нехватка маны, вторичная цель, устойчивая цель и два заклинания за один шаг; покупка/сброс/пауза/старый слот и отсутствие перка. Эти сценарии ещё не выполнены. Польза и стоимость оцениваются в общем паспорте; не создавать отдельные XP/кошелёк/инвентарь ради этой ветви.

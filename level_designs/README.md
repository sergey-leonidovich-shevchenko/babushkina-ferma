# Черновики конструктора уровней

Эта папка предназначена для JSON-экспортов и PNG-превью встроенного конструктора.

1. Откройте игру и нажмите `F12` либо кнопку `КОНСТРУКТОР` в панели `F10`.
2. Создайте или импортируйте текущую локацию, расставьте элементы и добавьте подписи.
3. Нажмите `ЭКСПОРТ`.
4. Передайте разработчику имена созданных `.json` и `.png` файлов из этой папки.

JSON хранит точные пути спрайтов, срезы атласов, координаты, размеры, слои,
повороты, отражения, коллизии, исходные runtime-объекты и авторские заметки.

## Основной рабочий процесс

- `НОВЫЙ` очищает холст, а `ИМПОРТИРОВАТЬ ТЕКУЩУЮ ЛОКАЦИЮ` превращает видимые игровые объекты в голубые редактируемые референсы.
- Выберите группу стрелками вверху панели. Колесо мыши прокручивает её содержимое.
- Спрайт можно перетащить из каталога на карту. Обычный щелчок по строке и затем по карте тоже работает.
- Для атласа выберите размер среза кнопкой `СРЕЗ`, а кадр — клавишами `,` и `.`.
- Щёлкните объект на карте, чтобы выбрать и перетянуть его. `D` создаёт копию, `Delete` удаляет, `Q` поворачивает, `X/Y` отражают, `[` и `]` меняют масштаб.
- `Page Up/Page Down` переносят объект между слоями. Кнопка `КОЛЛИЗИЯ` фиксирует дизайнерское намерение сделать его непроходимым.
- `N` подписывает выбранный объект, `O` добавляет пояснение. Если объект не выбран, эти клавиши редактируют название и общий замысел уровня.
- `Ctrl+Z`, `Ctrl+Y` и `Ctrl+Shift+Z` отменяют и повторяют операции. `WASD` или стрелки двигают камеру.

## Сохранение и передача

`СОХР.` оставляет рабочую копию в `user://level_designs`; `ЗАГР.` по кругу открывает сохранённые и экспортированные варианты. `ЭКСПОРТ` создаёт в этой папке два файла с одинаковым именем:

- `.json` — точная машиночитаемая схема уровня;
- `.png` — чистое превью без панели, сетки и рамок выбора.

Оба файла можно передать Codex вместе с пояснением. По JSON будут однозначно видны исходная локация, желаемые координаты, выбранные ресурсы, срезы атласов и ваши подписи; PNG даст быстрый визуальный ориентир.
